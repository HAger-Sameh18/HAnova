Lesson 6 : Backgrounds and Borders

1. CSS Backgrounds — خلفيات CSS

تستخدم CSS للتحكم في خلفيات عناصر HTML، مثل تحديد لون الخلفية، أو إضافة صورة للخلفية، أو التحكم في حجم الصورة ومكانها وطريقة تكرارها.

تساعد خصائص Background — الخلفية على تحسين شكل صفحات الويب وإعطاء العناصر مظهرًا أكثر تنظيمًا.

2. Background Color — لون الخلفية

تستخدم الخاصية background-color لتحديد لون خلفية العنصر.

body { background-color: #1e293b; }

في المثال السابق تم تحديد لون خلفية الصفحة باستخدام Hex Color.

3. Background Color with Color Name — استخدام اسم اللون

يمكن تحديد لون الخلفية باستخدام اسم لون معروف.

div { background-color: blue; }

سيؤدي الكود السابق إلى جعل خلفية العنصر باللون الأزرق.

4. Background Image — صورة الخلفية

تستخدم الخاصية background-image لإضافة صورة كخلفية للعنصر.

body { background-image: url("background.jpg"); }

يتم استخدام الدالة url() لتحديد مسار الصورة التي سيتم استخدامها كخلفية.

5. Background Image URL — مسار صورة الخلفية

يجب كتابة مسار الصورة بشكل صحيح داخل url() حتى يستطيع المتصفح الوصول إليها.

div { background-image: url("../images/bg.jpg"); }

يمكن أن يكون المسار للصورة داخل نفس المجلد أو داخل مجلد آخر حسب تنظيم ملفات المشروع.

6. Background Repeat — تكرار الخلفية

بشكل افتراضي قد تتكرر صورة الخلفية إذا كانت أصغر من مساحة العنصر. ويمكن التحكم في ذلك باستخدام الخاصية background-repeat.

div { background-repeat: no-repeat; }

القيمة no-repeat تمنع تكرار صورة الخلفية.

7. Repeat Background — تكرار الصورة

يمكن أيضًا تحديد طريقة تكرار صورة الخلفية.

div { background-repeat: repeat; }

القيمة repeat تسمح بتكرار الصورة أفقيًا ورأسيًا.

8. Repeat-x and Repeat-y — التكرار الأفقي والرأسي

يمكن التحكم في اتجاه تكرار الخلفية باستخدام: repeat-x أو repeat-y.

div { background-repeat: repeat-x; }

القيمة repeat-x تجعل الصورة تتكرر أفقيًا فقط.

div { background-repeat: repeat-y; }

القيمة repeat-y تجعل الصورة تتكرر رأسيًا فقط.

9. Background Size — حجم الخلفية

تستخدم الخاصية background-size للتحكم في حجم صورة الخلفية.

div { background-size: cover; }

القيمة cover تجعل الصورة تغطي مساحة العنصر بالكامل مع الحفاظ على نسبة أبعادها، وقد يتم قص جزء من الصورة.

10. Contain — احتواء صورة الخلفية

يمكن استخدام القيمة contain مع background-size لجعل الصورة تظهر بالكامل داخل العنصر.

div { background-size: contain; }

في هذه الحالة يتم الحفاظ على نسبة أبعاد الصورة، وقد تظهر مساحة فارغة إذا كانت أبعاد العنصر مختلفة عن أبعاد الصورة.

11. Background Position — موضع الخلفية

تستخدم الخاصية background-position لتحديد مكان ظهور صورة الخلفية داخل العنصر.

div { background-position: center; }

القيمة center تضع الصورة في منتصف العنصر.

12. Common Background Positions — أشهر مواضع الخلفية

يمكن استخدام قيم مختلفة لتحديد مكان الصورة، مثل:

  • center — المنتصف.
  • top — أعلى العنصر.
  • bottom — أسفل العنصر.
  • left — اليسار.
  • right — اليمين.
div { background-position: top right; }

13. Background Attachment — تثبيت الخلفية

تستخدم الخاصية background-attachment للتحكم في طريقة تحرك صورة الخلفية عند تمرير الصفحة.

body { background-attachment: fixed; }

القيمة fixed تجعل الخلفية ثابتة بالنسبة لنافذة العرض أثناء التمرير.

14. Background Shorthand — اختصار خصائص الخلفية

يمكن كتابة عدة خصائص للخلفية في سطر واحد باستخدام الخاصية background.

div { background: #1e293b url("background.jpg") center / cover no-repeat; }

يساعد هذا الاختصار على تقليل عدد الأسطر المستخدمة في كتابة CSS.

15. CSS Borders — حدود CSS

تستخدم CSS لإضافة حدود حول عناصر HTML. ويمكن التحكم في سمك الحدود ونوعها ولونها وشكل زواياها.

16. Border Property — خاصية Border

تستخدم الخاصية border لإضافة حد حول العنصر.

div { border: 2px solid #6c63ff; }

في المثال السابق: 2px تحدد سمك الحد، وsolid تحدد نوعه، و#6c63ff تحدد لونه.

17. Border Width — سمك الحدود

تستخدم الخاصية border-width لتحديد سمك الحدود.

div { border-width: 5px; }

18. Border Style — نوع الحدود

تستخدم الخاصية border-style لتحديد شكل الحدود.

div { border-style: solid; }

من أشهر أنواع الحدود:

  • solid — خط متصل.
  • dashed — خط متقطع.
  • dotted — نقاط.
  • double — خط مزدوج.
  • none — بدون حدود.

19. Border Color — لون الحدود

تستخدم الخاصية border-color لتحديد لون الحدود.

div { border-color: #6c63ff; }

20. Border Radius — تدوير زوايا الحدود

تستخدم الخاصية border-radius لتدوير زوايا العنصر.

div { border-radius: 15px; }

كلما زادت قيمة border-radius أصبحت زوايا العنصر أكثر استدارة.

21. Rounded Circle — إنشاء دائرة

يمكن استخدام قيمة 50% مع border-radius لإنشاء شكل دائري عندما يكون العنصر مربعًا.

div { width: 150px; height: 150px; border-radius: 50%; }

22. Individual Borders — تحديد كل حد بشكل منفصل

يمكن التحكم في كل جانب من جوانب الحدود بشكل منفصل.

div { border-top: 3px solid blue; border-right: 3px solid green; border-bottom: 3px solid red; border-left: 3px solid purple; }

في المثال السابق تم تحديد حدود مختلفة للجهات الأربع.

23. Border Top, Right, Bottom and Left — اتجاهات الحدود

يمكن استخدام الخصائص التالية للتحكم في كل جانب:

  • border-top — الحد العلوي.
  • border-right — الحد الأيمن.
  • border-bottom — الحد السفلي.
  • border-left — الحد الأيسر.

24. Border Shorthand — اختصار الحدود

يمكن كتابة سمك الحد ونوعه ولونه في سطر واحد.

div { border: 3px solid #6c63ff; }

وهذا هو الأسلوب الأكثر استخدامًا عندما نريد نفس الحدود في جميع الجهات.

25. Background and Border Together — الخلفية والحدود معًا

يمكن استخدام خصائص الخلفية والحدود معًا للحصول على تصميم متكامل.

.box { background-color: #1e293b; border: 3px solid #6c63ff; border-radius: 15px; padding: 20px; }

في المثال السابق تم تحديد لون الخلفية والحدود وتدوير الحواف وإضافة مساحة داخلية للعنصر.

26. Complete Background Example — مثال كامل على الخلفية

body { background-color: #1e293b; background-image: url("background.jpg"); background-repeat: no-repeat; background-position: center; background-size: cover; }

يجمع المثال السابق بين عدة خصائص للتحكم في صورة خلفية الصفحة.

27. Complete Border Example — مثال كامل على الحدود

.box { border-width: 3px; border-style: solid; border-color: #6c63ff; border-radius: 20px; }

في المثال السابق تم التحكم في سمك ونوع ولون الحدود بالإضافة إلى تدوير زوايا العنصر.

28. Important Background Properties — أهم خصائص الخلفيات

  • background-color — لون الخلفية.
  • background-image — صورة الخلفية.
  • background-repeat — تكرار الخلفية.
  • background-size — حجم الخلفية.
  • background-position — موضع الخلفية.
  • background-attachment — طريقة تثبيت الخلفية.
  • background — اختصار خصائص الخلفية.

29. Important Border Properties — أهم خصائص الحدود

  • border-width — سمك الحدود.
  • border-style — نوع الحدود.
  • border-color — لون الحدود.
  • border-radius — تدوير زوايا العنصر.
  • border — اختصار خصائص الحدود.
  • border-top — الحد العلوي.
  • border-right — الحد الأيمن.
  • border-bottom — الحد السفلي.
  • border-left — الحد الأيسر.

30. Try It Yourself — جرب بنفسك

قم بإنشاء عنصر <div> وأضف إليه لون خلفية وصورة خلفية وحدودًا.

حاول تغيير background-size وbackground-position وbackground-repeat ولاحظ تأثير كل خاصية.

جرب أيضًا تغيير نوع الحدود بين solid وdashed وdotted ثم قم بتغيير قيمة border-radius.

Lesson 3 : Colors, Text and Fonts

1. CSS Colors — ألوان CSS

تستخدم CSS للتحكم في ألوان عناصر صفحة الويب، مثل لون النص ولون الخلفية ولون الحدود. ويمكن تحديد الألوان بعدة طرق مختلفة.

من أشهر طرق كتابة الألوان في CSS: Color Names، Hexadecimal، RGB، وRGBA.

2. Color Property — خاصية Color

تستخدم الخاصية color لتحديد لون النص داخل العنصر.

h1 { color: blue; }

في المثال السابق سيتم تغيير لون النص الموجود داخل h1 إلى اللون الأزرق.

3. Color Names — أسماء الألوان

يمكن كتابة اللون في CSS باستخدام اسمه مباشرةً. وتحتوي CSS على العديد من أسماء الألوان المعروفة.

h1 { color: red; } p { color: green; }

في المثال السابق تم استخدام أسماء الألوان red و green.

4. Hexadecimal Colors — ألوان Hexadecimal

يمكن تحديد الألوان باستخدام نظام Hexadecimal أو ما يسمى Hex Color.

يبدأ اللون السداسي عشر عادةً بالرمز # ويتكون من ستة أرقام أو حروف.

h1 { color: #6c63ff; }

في المثال السابق تم استخدام اللون #6c63ff لتحديد لون النص.

5. RGB Colors — ألوان RGB

RGB هي اختصار لـ Red, Green, Blue. ويعتمد نظام RGB على دمج الألوان الأحمر والأخضر والأزرق للحصول على ألوان مختلفة.

يتم تحديد قيمة كل لون من خلال رقم يتراوح عادةً من 0 إلى 255.

h1 { color: rgb(108, 99, 255); }

6. RGBA Colors — ألوان RGBA

RGBA تشبه RGB، ولكنها تضيف قيمة رابعة تسمى Alpha للتحكم في درجة الشفافية.

قيمة Alpha تكون بين 0 و1. حيث يمثل 0 الشفافية الكاملة، بينما يمثل 1 اللون بدون شفافية.

p { color: rgba(108, 99, 255, 0.7); }

7. Background Color — لون الخلفية

تستخدم الخاصية background-color لتحديد لون خلفية العنصر.

body { background-color: #1e293b; }

في المثال السابق تم تحديد لون خلفية الصفحة.

8. Text Color — لون النص

يمكن استخدام الخاصية color لتغيير لون النصوص داخل عناصر HTML.

p { color: white; }

سيؤدي الكود السابق إلى جعل النص الموجود داخل الفقرات باللون الأبيض.

9. Text Alignment — محاذاة النص

تستخدم الخاصية text-align لتحديد طريقة محاذاة النص داخل العنصر.

من أشهر القيم: left، center، right، وjustify.

h1 { text-align: center; }

في المثال السابق سيتم وضع النص في منتصف العنصر.

10. Text Decoration — زخرفة النص

تستخدم الخاصية text-decoration لإضافة أو إزالة زخرفة معينة من النص.

a { text-decoration: none; }

في المثال السابق تم إزالة الخط الموجود أسفل الرابط.

11. Text Transformation — تحويل حالة النص

تستخدم الخاصية text-transform للتحكم في حالة الأحرف الإنجليزية داخل النص.

القيمة uppercase تجعل الحروف الإنجليزية كبيرة.

p { text-transform: uppercase; }

12. Text Shadow — ظل النص

تستخدم الخاصية text-shadow لإضافة ظل إلى النص.

يمكن التحكم في اتجاه الظل وحجمه ودرجة التمويه ولونه.

h1 { text-shadow: 2px 2px 5px black; }

13. Font Family — نوع الخط

تستخدم الخاصية font-family لتحديد نوع الخط المستخدم في النص.

body { font-family: Arial, sans-serif; }

في المثال السابق تم تحديد Arial كخط أساسي، مع وضع sans-serif كخط بديل.

14. Font Size — حجم الخط

تستخدم الخاصية font-size لتحديد حجم النص.

h1 { font-size: 32px; }

في المثال السابق تم تحديد حجم الخط ليكون 32px.

15. Font Weight — سمك الخط

تستخدم الخاصية font-weight للتحكم في سمك الخط.

يمكن استخدام قيم مثل normal وbold أو استخدام أرقام مثل 400 و700.

h1 { font-weight: bold; }

16. Font Style — نمط الخط

تستخدم الخاصية font-style لتحديد نمط الخط، مثل جعل النص مائلًا.

p { font-style: italic; }

17. Line Height — ارتفاع السطر

تستخدم الخاصية line-height للتحكم في المسافة الرأسية بين أسطر النص.

تساعد هذه الخاصية على جعل النصوص الطويلة أكثر وضوحًا وسهولة في القراءة.

p { line-height: 1.8; }

18. Letter Spacing — المسافة بين الحروف

تستخدم الخاصية letter-spacing للتحكم في المسافة بين الحروف.

h1 { letter-spacing: 2px; }

19. Word Spacing — المسافة بين الكلمات

تستخدم الخاصية word-spacing للتحكم في المسافة بين الكلمات.

p { word-spacing: 5px; }

20. Combining Text and Font Properties — دمج خصائص النص والخط

يمكن استخدام أكثر من خاصية في نفس قاعدة CSS للحصول على تنسيق متكامل للنص.

h1 { color: #6c63ff; font-family: Arial, sans-serif; font-size: 32px; font-weight: bold; text-align: center; text-shadow: 2px 2px 5px black; }

  • text-transform — تحويل حالة النص.
  • text-shadow — إضافة ظل للنص.
  • font-family — تحديد نوع الخط.
  • font-size — تحديد حجم الخط.
  • font-weight — تحديد سمك الخط.
  • font-style — تحديد نمط الخط.
  • line-height — تحديد ارتفاع السطر.
  • letter-spacing — المسافة بين الحروف.
  • word-spacing — المسافة بين الكلمات.

22. Try It Yourself — جرب بنفسك

قم بإنشاء عنوان وفقرة باستخدام HTML، ثم استخدم CSS لتغيير لون النص وحجم الخط ونوعه ومحاذاته. حاول أيضًا إضافة ظل للنص وتغيير المسافة بين الحروف.

جرب استخدام أكثر من طريقة لكتابة الألوان مثل Color Name وHex وRGB ولاحظ الفرق بينها.

Lesson 10 : Responsive Design

1. What is Responsive Design? — ما هو التصميم المتجاوب؟

Responsive Design — التصميم المتجاوب هو أسلوب في تصميم مواقع الويب يجعل الصفحة تتكيف مع أحجام الشاشات والأجهزة المختلفة.

بمعنى أن الموقع يمكن أن يظهر بشكل مناسب على Desktop — الكمبيوتر وTablet — الجهاز اللوحي وMobile — الهاتف المحمول دون الحاجة إلى إنشاء صفحة منفصلة لكل جهاز.

2. Why Responsive Design? — لماذا نستخدم التصميم المتجاوب؟

تختلف أحجام شاشات الأجهزة التي يستخدمها الأشخاص للوصول إلى المواقع، لذلك يجب أن يكون تصميم الموقع قادرًا على التكيف مع هذه الأحجام.

  • تحسين تجربة المستخدم.
  • جعل الموقع مناسبًا للهواتف والأجهزة اللوحية.
  • منع ظهور المحتوى خارج حدود الشاشة.
  • تنظيم العناصر بشكل أفضل على الشاشات الصغيرة.
  • الحفاظ على سهولة استخدام الموقع على الأجهزة المختلفة.

3. Viewport — مساحة عرض الصفحة

Viewport — منفذ العرض هو المساحة التي يستطيع المستخدم رؤية صفحة الويب من خلالها على جهازه.

لذلك من المهم إضافة Viewport Meta Tag داخل صفحة HTML حتى يتم عرض الصفحة بشكل مناسب على الأجهزة المختلفة.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

تعني width=device-width أن عرض الصفحة يتوافق مع عرض شاشة الجهاز، بينما initial-scale=1.0 تحدد مستوى التكبير الأولي للصفحة.

4. Media Query — الاستعلامات الإعلامية

Media Query — الاستعلام الإعلامي هي إحدى أهم أدوات CSS المستخدمة في إنشاء التصميم المتجاوب.

تسمح لنا بتطبيق تنسيقات مختلفة عندما يكون عرض الشاشة أكبر أو أصغر من قيمة معينة.

@media (max-width: 600px) { body { font-size: 16px; } }

في المثال السابق يتم تطبيق التنسيق عندما يكون عرض الشاشة 600px أو أقل.

5. Max-width — أقصى عرض

تستخدم max-width لتطبيق تنسيق معين عندما لا يتجاوز عرض الشاشة قيمة محددة.

@media (max-width: 768px) { .container { width: 90%; } }

سيتم تطبيق هذه القاعدة عندما يكون عرض الشاشة 768px أو أقل.

6. Min-width — أقل عرض

تستخدم min-width لتطبيق تنسيق عندما يكون عرض الشاشة مساويًا أو أكبر من قيمة محددة.

@media (min-width: 768px) { .container { width: 80%; } }

7. Breakpoints — نقاط التوقف

Breakpoints — نقاط التوقف هي أحجام معينة للشاشة نستخدمها لتغيير شكل التصميم عندما يتغير حجم الجهاز.

يمكن استخدام Media Queries عند نقاط مختلفة مثل:

  • الشاشات الصغيرة جدًا.
  • الهواتف المحمولة.
  • الأجهزة اللوحية.
  • أجهزة الكمبيوتر.
  • الشاشات الكبيرة.

8. Mobile First — تصميم الهاتف أولًا

Mobile First — الهاتف أولًا هو أسلوب تصميم نبدأ فيه بتصميم الصفحة للشاشات الصغيرة، ثم نضيف التنسيقات اللازمة للشاشات الأكبر.

.container { width: 100%; } @media (min-width: 768px) { .container { width: 80%; } }

في المثال السابق يبدأ التصميم بعرض كامل مناسب للشاشات الصغيرة، ثم يتغير عند الشاشات الأكبر.

9. Flexible Width — العرض المرن

من الأفضل في التصميم المتجاوب استخدام قيم مرنة بدلًا من الاعتماد دائمًا على قيم ثابتة مثل 500px.

.container { width: 90%; }

استخدام النسبة المئوية يجعل العنصر يتكيف مع عرض الشاشة.

10. Percentage Units — النسبة المئوية

يمكن استخدام % لتحديد حجم العنصر بالنسبة إلى العنصر الأب.

.box { width: 50%; }

يعني ذلك أن عرض العنصر يساوي نصف عرض العنصر الأب.

11. Viewport Units — وحدات الشاشة

توفر CSS وحدات تعتمد على حجم الشاشة، ومن أهمها: vw وvh.

  • vw — نسبة من عرض نافذة المتصفح.
  • vh — نسبة من ارتفاع نافذة المتصفح.
.box { width: 50vw; height: 50vh; }

12. max-width — الحد الأقصى لعرض العنصر

تستخدم الخاصية max-width لمنع العنصر من أن يصبح أكبر من حجم معين.

img { width: 100%; max-width: 500px; }

يسمح هذا المثال للصورة بالتكيف مع المساحة المتاحة، ولكن لا يتجاوز عرضها 500px.

13. Responsive Images — الصور المتجاوبة

يجب أن تتكيف الصور مع حجم الشاشة حتى لا تتجاوز حدود العنصر أو تسبب ظهور شريط تمرير أفقي.

img { max-width: 100%; height: auto; }

تعني max-width: 100% أن الصورة لا تتجاوز عرض العنصر الأب، بينما تحافظ height: auto على تناسب أبعاد الصورة.

14. Responsive Text — النص المتجاوب

يجب أيضًا مراعاة حجم النص عند تصميم المواقع للشاشات الصغيرة. يمكن استخدام Media Queries لتغيير حجم الخط.

h1 { font-size: 36px; } @media (max-width: 600px) { h1 { font-size: 24px; } }

في الشاشات الصغيرة يصبح حجم العنوان أصغر حتى لا يأخذ مساحة كبيرة.

15. Responsive Navigation — قائمة التنقل المتجاوبة

يمكن استخدام Media Queries لتغيير طريقة عرض قائمة التنقل على الشاشات الصغيرة.

.nav { display: flex; justify-content: space-around; } @media (max-width: 600px) { .nav { flex-direction: column; align-items: center; } }

في الشاشات الكبيرة تظهر العناصر بجانب بعضها، بينما في الشاشات الصغيرة يمكن ترتيبها بشكل رأسي.

16. Flexbox and Responsive Design — Flexbox والتصميم المتجاوب

يعتبر Flexbox من أهم الأدوات المستخدمة لإنشاء تصميمات متجاوبة، لأنه يسمح بترتيب العناصر وتوزيع المساحات بينها بشكل مرن.

.container { display: flex; gap: 20px; flex-wrap: wrap; }

استخدام flex-wrap يسمح للعناصر بالانتقال إلى سطر جديد عندما لا تكون المساحة كافية.

17. Grid and Responsive Design — Grid والتصميم المتجاوب

يمكن أيضًا استخدام CSS Grid لإنشاء تخطيطات متجاوبة تحتوي على عدة أعمدة وصفوف.

.container { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } @media (max-width: 600px) { .container { grid-template-columns: 1fr; } }

في المثال السابق يتم عرض ثلاثة أعمدة على الشاشات الأكبر، بينما يصبح التخطيط بعمود واحد على الشاشات الصغيرة.

18. Responsive Cards — البطاقات المتجاوبة

يمكن إنشاء مجموعة من البطاقات بحيث تتكيف مع حجم الشاشة.

.cards { display: flex; gap: 20px; flex-wrap: wrap; } .card { flex: 1; min-width: 200px; }

عندما تقل المساحة المتاحة، يمكن أن تنتقل البطاقات إلى سطر جديد.

19. Overflow — المحتوى الزائد

Overflow — تجاوز المحتوى يحدث عندما يكون محتوى العنصر أكبر من المساحة المتاحة له.

يمكن التحكم في ذلك باستخدام الخاصية overflow.

.box { overflow: auto; }

تسمح القيمة auto للمتصفح بإظهار شريط تمرير عند الحاجة.

20. Horizontal Scrolling — التمرير الأفقي

يجب تجنب خروج العناصر خارج حدود الشاشة، لأن ذلك قد يؤدي إلى ظهور Horizontal Scrolling — تمرير أفقي غير مرغوب فيه.

* { box-sizing: border-box; } img { max-width: 100%; }

تساعد هذه القواعد في تقليل المشكلات الناتجة عن تجاوز المحتوى لعرض الشاشة.

21. Responsive Units — وحدات مناسبة للتصميم المتجاوب

  • % — النسبة المئوية.
  • vw — نسبة من عرض الشاشة.
  • vh — نسبة من ارتفاع الشاشة.
  • rem — وحدة تعتمد على حجم الخط الأساسي.
  • em — وحدة تعتمد على حجم خط العنصر الأب.
  • px — وحدة ثابتة تستخدم عندما نحتاج إلى قياس محدد.

22. Common Breakpoints — أمثلة على نقاط التوقف

يمكن اختيار نقاط التوقف حسب تصميم الموقع والمحتوى، وليس من الضروري الالتزام بأرقام محددة لكل مشروع.

@media (max-width: 600px) { /* Small screens */ } @media (min-width: 601px) and (max-width: 1024px) { /* Medium screens */ } @media (min-width: 1025px) { /* Large screens */ }

23. Responsive Layout Example — مثال على تصميم متجاوب

.container { width: 90%; margin: auto; display: flex; gap: 20px; } .box { flex: 1; padding: 20px; } @media (max-width: 600px) { .container { flex-direction: column; } .box { width: 100%; } }

في المثال السابق تظهر العناصر بجانب بعضها على الشاشات الكبيرة، بينما يتم ترتيبها فوق بعضها على الشاشات الصغيرة.

24. Mobile Responsive Example — مثال للهاتف

.content { width: 80%; margin: auto; font-size: 20px; } @media (max-width: 600px) { .content { width: 95%; font-size: 16px; } }

عند استخدام الموقع من الهاتف يتم زيادة المساحة المتاحة للمحتوى وتقليل حجم الخط ليتناسب مع الشاشة الصغيرة.

25. Tablet Responsive Example — مثال للجهاز اللوحي

@media (min-width: 601px) and (max-width: 1024px) { .container { width: 90%; } .box { font-size: 18px; } }

يمكن تخصيص تنسيقات معينة للأجهزة اللوحية باستخدام Media Query مناسبة.

26. Desktop Responsive Example — مثال للكمبيوتر

@media (min-width: 1025px) { .container { width: 80%; max-width: 1200px; margin: auto; } }

يمكن تحديد عرض مناسب للمحتوى على الشاشات الكبيرة حتى لا يصبح المحتوى ممتدًا بشكل مبالغ فيه.

27. Responsive Design with Flexbox — التصميم المتجاوب باستخدام Flexbox

.container { display: flex; justify-content: center; gap: 20px; flex-wrap: wrap; } .item { flex: 1; min-width: 250px; } @media (max-width: 600px) { .item { min-width: 100%; } }

يجمع المثال بين Flexbox وflex-wrap وMedia Query لإنشاء تخطيط متجاوب.

28. Best Practices — أفضل الممارسات

  • استخدم Viewport Meta Tag في صفحات HTML.
  • استخدم وحدات مرنة عندما يكون ذلك مناسبًا.
  • استخدم Media Queries لتغيير التصميم حسب حجم الشاشة.
  • تأكد من أن الصور لا تتجاوز عرض الشاشة.
  • استخدم Flexbox أو Grid لإنشاء تخطيطات مرنة.
  • اختبر الموقع على أحجام شاشات مختلفة.
  • تجنب الاعتماد على قيم ثابتة في كل أجزاء التصميم.

29. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة تحتوي على عدة عناصر بجانب بعضها باستخدام Flexbox.

بعد ذلك استخدم @media لجعل العناصر تظهر فوق بعضها عندما يصبح عرض الشاشة صغيرًا.

جرب أيضًا تغيير حجم الخط والعرض والمسافات عند استخدام الهاتف، ثم افتح الصفحة على أحجام مختلفة ولاحظ التغييرات.

30. Complete Responsive Example — مثال متكامل

* { box-sizing: border-box; } .container { width: 90%; max-width: 1200px; margin: auto; display: flex; gap: 20px; flex-wrap: wrap; } .box { flex: 1; min-width: 250px; padding: 20px; } img { max-width: 100%; height: auto; } @media (max-width: 600px) { .container { width: 95%; flex-direction: column; } .box { width: 100%; } }

يجمع المثال السابق مجموعة من أهم تقنيات التصميم المتجاوب، مثل Flexbox وMedia Queries وmax-width والوحدات المرنة.

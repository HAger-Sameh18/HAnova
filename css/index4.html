Lesson 2 : CSS Syntax and Selectors

1. What is CSS Syntax? — ما هي صياغة CSS؟

CSS Syntax — صياغة CSS هي الطريقة التي يتم بها كتابة قواعد CSS بشكل صحيح حتى يستطيع المتصفح فهمها وتطبيق التنسيقات على عناصر HTML.

تتكون قاعدة CSS الأساسية من Selector — المحدد ثم مجموعة من Declarations — التصريحات التي تحدد الخصائص والقيم التي نريد تطبيقها على العنصر.

h1 { color: blue; font-size: 30px; }

في المثال السابق: h1 هو المحدد، بينما color: blue; و font-size: 30px; هما التصريحات التي تحدد شكل العنصر.

2. Selector — المحدد

Selector — المحدد هو الجزء الذي يحدد عناصر HTML التي نريد تطبيق CSS عليها.

يمكن أن يكون المحدد اسم عنصر HTML أو Class أو ID أو مجموعة من المحددات الأخرى.

p { color: red; }

في المثال السابق تم استخدام p كمحدد، لذلك سيتم تطبيق اللون الأحمر على عناصر الفقرات.

3. Declaration — التصريح

Declaration — التصريح هو مجموعة تتكون من Property — الخاصية و Value — القيمة ويتم الفصل بينهما باستخدام علامة :.

color: blue;

في المثال السابق: color هي الخاصية، وblue هي القيمة.

4. Property and Value — الخاصية والقيمة

Property — الخاصية تحدد الشيء الذي نريد تغييره، بينما Value — القيمة تحدد القيمة التي نريد إعطاءها لهذه الخاصية.

color: purple; font-size: 25px;

في المثال السابق تم استخدام خاصيتين: color لتحديد اللون، وfont-size لتحديد حجم الخط.

5. Curly Brackets — الأقواس المعقوفة

تستخدم الأقواس المعقوفة { } لتحديد بداية ونهاية مجموعة التصريحات الخاصة بمحدد معين.

h1 { color: blue; font-size: 30px; }

تبدأ التصريحات بعد القوس { وتنتهي عند القوس }.

6. Semicolon — الفاصلة المنقوطة

يتم استخدام الفاصلة المنقوطة ; في نهاية كل تصريح CSS للفصل بين الخصائص والقيم المختلفة.

h1 { color: blue; font-size: 30px; text-align: center; }

يفضل كتابة الفاصلة المنقوطة بعد كل تصريح حتى يكون الكود منظمًا وواضحًا، وخاصة عند وجود أكثر من خاصية.

7. Element Selector — محدد العنصر

Element Selector — محدد العنصر يستخدم اسم عنصر HTML مباشرةً لتطبيق التنسيق على جميع العناصر التي تحمل نفس الاسم.

p { color: white; font-size: 18px; }

سيؤثر هذا الكود على جميع عناصر <p> الموجودة في الصفحة.

8. Class Selector — محدد الفئة

Class Selector — محدد الفئة يستخدم لتنسيق عنصر أو مجموعة من العناصر التي تحمل نفس قيمة class.

يتم كتابة النقطة . قبل اسم الـ Class في CSS.

.title { color: purple; }

ولتطبيق هذا الـ Class على عنصر HTML نكتب:

<h1 class="title"> Welcome </h1>

9. ID Selector — محدد ID

ID Selector — محدد المعرف يستخدم لتحديد عنصر معين باستخدام قيمة id.

يتم كتابة علامة # قبل اسم الـ ID في CSS.

#main-title { color: blue; }

ويتم استخدامه في HTML بالشكل التالي:

<h1 id="main-title"> Welcome </h1>

10. Universal Selector — المحدد العام

Universal Selector — المحدد العام يستخدم لتطبيق التنسيق على جميع عناصر الصفحة.

يتم تمثيله بالرمز *.

* { margin: 0; padding: 0; }

في المثال السابق يتم إزالة margin و padding الافتراضي من جميع عناصر الصفحة.

11. Grouping Selectors — تجميع المحددات

يمكننا تطبيق نفس التنسيق على أكثر من عنصر باستخدام Grouping Selectors — تجميع المحددات.

يتم الفصل بين المحددات باستخدام الفاصلة ,.

h1, h2, p { color: white; }

في المثال السابق سيتم تطبيق اللون الأبيض على عناصر h1 و h2 و p.

12. Descendant Selector — محدد العناصر التابعة

يستخدم Descendant Selector لتحديد عنصر موجود داخل عنصر آخر.

div p { color: red; }

في المثال السابق سيتم تطبيق التنسيق على عناصر p الموجودة داخل عناصر div.

13. Child Selector — محدد الابن المباشر

يستخدم Child Selector لتحديد العناصر التي تكون أبناء مباشرين لعنصر معين.

يتم استخدام الرمز > بين العنصر الأب والعنصر الابن.

div > p { color: yellow; }

هذا المحدد يختار عناصر p التي تكون أبناء مباشرين لعناصر div.

14. Multiple Selectors — المحددات المتعددة

يمكن استخدام أكثر من نوع من المحددات في نفس صفحة CSS، حسب العناصر التي نريد تنسيقها.

h1 { color: blue; } .title { font-size: 30px; } #main { background-color: black; }

15. CSS Comments — التعليقات في CSS

CSS Comment — تعليق CSS هو نص نكتبه داخل الكود لتوضيح وظيفة جزء معين من الكود، ولا يقوم المتصفح بتطبيقه كتدسيق.

تبدأ التعليقات في CSS باستخدام /* وتنتهي باستخدام */.

/* This is a CSS comment */ h1 { color: blue; }

16. Combining Selectors — دمج المحددات

يمكن دمج أكثر من محدد للوصول إلى عناصر محددة بشكل أكبر.

p.title { color: purple; }

في المثال السابق يتم تحديد عناصر p التي تحمل الـ Class المسمى title.

17. Selector Symbols — رموز المحددات

  • * — Universal Selector — المحدد العام.
  • . — Class Selector — محدد الفئة.
  • # — ID Selector — محدد المعرف.
  • , — Grouping Selectors — تجميع المحددات.
  • > — Child Selector — محدد الابن المباشر.
  • مسافة — Descendant Selector — محدد العناصر التابعة.

18. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة HTML تحتوي على عنوان وفقرة وعدة عناصر أخرى، ثم حاول استخدام أنواع مختلفة من المحددات لتغيير ألوانها وأحجامها.

جرب استخدام Element Selector و Class Selector و ID Selector و Universal Selector ولاحظ الفرق بينهم.

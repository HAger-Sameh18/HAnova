Lesson 7 : Display and Positioning

1. Display Property — خاصية Display

تستخدم الخاصية display لتحديد طريقة ظهور العنصر وكيفية وضعه بالنسبة إلى العناصر الأخرى داخل الصفحة.

تعتبر display من أهم خصائص CSS لأنها تتحكم في طريقة ترتيب العناصر والمساحة التي يشغلها كل عنصر.

2. Block Element — العنصر Block

العنصر الذي تكون قيمة display الخاصة به block يبدأ عادةً في سطر جديد ويأخذ المساحة المتاحة أفقيًا.

div { display: block; }

من أمثلة العناصر التي تكون Block بشكل افتراضي:

  • <div>
  • <p>
  • <h1>
  • <h2>

3. Inline Element — العنصر Inline

العنصر الذي تكون قيمة display الخاصة به inline يظهر داخل نفس السطر مع العناصر الأخرى، ويأخذ فقط المساحة التي يحتاج إليها محتواه.

span { display: inline; }

من أمثلة العناصر التي تكون Inline بشكل افتراضي:

  • <span>
  • <a>
  • <strong>

4. Inline-Block — العنصر Inline-Block

تجمع قيمة inline-block بين خصائص inline و block.

.box { display: inline-block; width: 200px; height: 100px; }

يسمح inline-block بظهور العناصر بجانب بعضها، مع إمكانية تحديد width وheight لها.

5. None — إخفاء العنصر

تستخدم القيمة none لإخفاء العنصر من الصفحة.

.hidden { display: none; }

عند استخدام display: none لا يظهر العنصر ولا يحجز مساحة له في تخطيط الصفحة.

6. Visibility — خاصية Visibility

تستخدم الخاصية visibility للتحكم في ظهور العنصر مع إمكانية الاحتفاظ بمساحته في الصفحة.

.hidden { visibility: hidden; }

الفرق الأساسي هو أن visibility: hidden يخفي العنصر ولكنه يحتفظ بمكانه، بينما display: none يخفي العنصر ويزيل مساحته من التخطيط.

7. Display Comparison — مقارنة قيم Display

  • block — يظهر في سطر جديد ويأخذ المساحة المتاحة.
  • inline — يظهر داخل نفس السطر ويأخذ مساحة المحتوى.
  • inline-block — يظهر بجانب العناصر مع إمكانية تحديد أبعاده.
  • none — يخفي العنصر ويزيل مساحته.

8. Position Property — خاصية Position

تستخدم الخاصية position لتحديد طريقة وضع العنصر داخل الصفحة.

ومن أهم قيمها:

  • static
  • relative
  • absolute
  • fixed
  • sticky

9. Static Position — الموضع Static

القيمة static هي القيمة الافتراضية لمعظم العناصر.

div { position: static; }

في الوضع static يتبع العنصر ترتيب الصفحة الطبيعي، ولا يتم تطبيق خصائص top وright وbottom وleft لتغيير موضعه.

10. Relative Position — الموضع Relative

تستخدم القيمة relative لوضع العنصر بالنسبة إلى موضعه الطبيعي في الصفحة.

.box { position: relative; left: 20px; top: 10px; }

يمكن تحريك العنصر باستخدام top وright وbottom وleft مع احتفاظه بمكانه الأصلي في تخطيط الصفحة.

11. Absolute Position — الموضع Absolute

تستخدم القيمة absolute لوضع العنصر بالنسبة إلى أقرب عنصر أب له لديه قيمة position مختلفة عن static.

.box { position: absolute; top: 20px; right: 30px; }

إذا لم يوجد عنصر أب مناسب، يتم تحديد موضع العنصر بالنسبة إلى مساحة الصفحة.

12. Parent and Child with Absolute — الأب والابن مع Absolute

من الشائع استخدام position: relative للعنصر الأب، ثم استخدام position: absolute للعنصر الابن.

.parent { position: relative; } .child { position: absolute; top: 10px; right: 10px; }

في هذه الحالة يتم تحديد موضع العنصر الابن بالنسبة إلى العنصر الأب.

13. Fixed Position — الموضع Fixed

تستخدم القيمة fixed لتثبيت العنصر بالنسبة إلى نافذة المتصفح.

.menu { position: fixed; top: 0; right: 0; }

يظل العنصر في نفس الموضع داخل نافذة المتصفح حتى عند تمرير الصفحة.

14. Sticky Position — الموضع Sticky

تستخدم القيمة sticky لجعل العنصر يتصرف بشكل طبيعي في البداية، ثم يثبت في موضع معين عند التمرير.

.menu { position: sticky; top: 0; }

في المثال السابق يظل العنصر في موضعه الطبيعي، وعند وصوله إلى أعلى نافذة المتصفح أثناء التمرير يمكن أن يثبت هناك.

15. Top, Right, Bottom and Left — تحديد موضع العنصر

تستخدم الخصائص التالية مع أنواع معينة من position للتحكم في موضع العنصر:

  • top — المسافة من الأعلى.
  • right — المسافة من اليمين.
  • bottom — المسافة من الأسفل.
  • left — المسافة من اليسار.
.box { position: relative; top: 20px; left: 30px; }

16. Z-Index — ترتيب العناصر

تستخدم الخاصية z-index لتحديد ترتيب العناصر التي تتداخل مع بعضها.

.box1 { position: absolute; z-index: 1; } .box2 { position: absolute; z-index: 2; }

عندما تتداخل العناصر، فإن العنصر الذي يمتلك قيمة z-index أعلى يظهر فوق العنصر الذي يمتلك قيمة أقل.

17. Overflow — المحتوى الزائد

تستخدم الخاصية overflow للتحكم في المحتوى الذي يتجاوز حدود العنصر.

.box { width: 300px; height: 100px; overflow: hidden; }

القيمة hidden تخفي الجزء من المحتوى الذي يتجاوز حدود العنصر.

18. Overflow Auto — التمرير التلقائي

يمكن استخدام القيمة auto لإظهار أشرطة التمرير عند الحاجة.

.box { width: 300px; height: 150px; overflow: auto; }

19. Overflow Scroll — أشرطة التمرير

تستخدم القيمة scroll لإظهار أشرطة التمرير للعنصر.

.box { overflow: scroll; }

20. Display and Positioning Together — استخدام Display و Position معًا

يمكن استخدام خصائص display وposition معًا للتحكم في طريقة عرض العناصر ومكانها.

.box { display: inline-block; position: relative; top: 10px; }

21. Difference Between Relative and Absolute — الفرق بين Relative و Absolute

  • relative يحرك العنصر من موضعه الطبيعي مع احتفاظه بمكانه في التخطيط.
  • absolute يخرج العنصر من التدفق الطبيعي للصفحة ويتم تحديد موضعه بالنسبة إلى أقرب أب مناسب.

22. Difference Between Fixed and Sticky — الفرق بين Fixed و Sticky

  • fixed يثبت العنصر بالنسبة إلى نافذة المتصفح.
  • sticky يبدأ كعنصر طبيعي ثم يمكن أن يثبت عند الوصول إلى موضع محدد أثناء التمرير.

23. Display Values — أهم قيم Display

  • block — عنصر Block.
  • inline — عنصر Inline.
  • inline-block — عنصر Inline-Block.
  • none — إخفاء العنصر.
  • flex — استخدام Flexbox.
  • grid — استخدام CSS Grid.

24. Position Values — أهم قيم Position

  • static — الوضع الافتراضي.
  • relative — الموضع النسبي.
  • absolute — الموضع المطلق.
  • fixed — الموضع الثابت.
  • sticky — الموضع اللاصق.

25. Try It Yourself — جرب بنفسك

قم بإنشاء عدة عناصر <div> وحاول تغيير قيمة display لكل عنصر إلى block وinline وinline-block.

بعد ذلك جرب استخدام position: relative وposition: absolute ولاحظ الفرق بينهما.

حاول أيضًا استخدام fixed وsticky مع تمرير الصفحة وملاحظة سلوك كل عنصر.

  • block = عنصر يظهر في سطر جديد.
  • inline = عنصر يظهر داخل نفس السطر.
  • inline-block = عنصر يظهر بجانب العناصر مع إمكانية تحديد أبعاده.
  • none = إخفاء العنصر وإزالة مساحته.
  • visibility: hidden = إخفاء العنصر مع الاحتفاظ بمكانه.
  • position = تحديد طريقة وضع العنصر.
  • static = الوضع الافتراضي.
  • relative = الموضع النسبي.
  • absolute = الموضع المطلق.
  • fixed = الموضع الثابت.
  • sticky = الموضع اللاصق.
  • top = تحديد المسافة من الأعلى.
  • right = تحديد المسافة من اليمين.
  • bottom = تحديد المسافة من الأسفل.
  • left = تحديد المسافة من اليسار.
  • z-index = التحكم في ترتيب العناصر المتداخلة.
  • overflow = التحكم في المحتوى الزائد.

Lesson 4 : CSS Box Model

1. What is the CSS Box Model? — ما هو CSS Box Model؟

CSS Box Model — نموذج الصندوق في CSS هو الطريقة التي يتعامل بها المتصفح مع كل عنصر HTML على أنه صندوق مستطيل له أبعاد ومساحات وحدود.

يساعدنا Box Model على فهم حجم العنصر والمسافات الموجودة حوله وداخله، وبالتالي التحكم في طريقة ظهوره وترتيبه داخل الصفحة.

2. Parts of the Box Model — أجزاء نموذج الصندوق

يتكون CSS Box Model من أربعة أجزاء أساسية:

  • Content — المحتوى
  • Padding — الحشو الداخلي
  • Border — الحدود
  • Margin — الهامش الخارجي

Content — المحتوى

هو النص أو الصورة أو أي محتوى موجود داخل العنصر.

Padding — الحشو الداخلي

هو المسافة بين المحتوى والحدود الداخلية للعنصر.

Border — الحدود

هو الخط الذي يحيط بالعنصر ويفصل بينه وبين الـ Margin.

Margin — الهامش الخارجي

هو المسافة الموجودة خارج حدود العنصر والتي تفصله عن العناصر الأخرى.

3. Content — المحتوى

Content — المحتوى هو الجزء الأساسي الموجود داخل العنصر، مثل النصوص والصور والعناوين والفيديوهات وغيرها من عناصر HTML.

div { width: 300px; height: 150px; }

في المثال السابق تم تحديد مساحة المحتوى باستخدام width وheight.

4. Width and Height — العرض والارتفاع

تستخدم الخاصية width لتحديد عرض العنصر، بينما تستخدم الخاصية height لتحديد ارتفاعه.

div { width: 300px; height: 150px; }

في هذا المثال يبلغ عرض العنصر 300px وارتفاعه 150px.

5. Padding — الحشو الداخلي

Padding — الحشو الداخلي هو المسافة بين محتوى العنصر وحدوده. ويستخدم لإعطاء مساحة داخلية حول المحتوى.

div { padding: 20px; }

في المثال السابق تم إضافة مسافة داخلية مقدارها 20px من جميع الجهات.

6. Padding on Each Side — الحشو لكل جانب

يمكن تحديد قيمة مختلفة للـ Padding لكل جانب من جوانب العنصر.

div { padding-top: 10px; padding-right: 20px; padding-bottom: 30px; padding-left: 40px; }

في المثال السابق تم تحديد Padding بشكل منفصل للجهات الأربع: الأعلى واليمين والأسفل واليسار.

7. Padding Shorthand — الاختصار في Padding

يمكن كتابة قيم Padding الأربع في سطر واحد بدلًا من كتابة كل خاصية بشكل منفصل.

div { padding: 10px 20px 30px 40px; }

يتم ترتيب القيم بالترتيب التالي: Top → Right → Bottom → Left.

8. Border — الحدود

Border — الحدود هو الخط الذي يحيط بمحتوى العنصر والـ Padding. ويمكن التحكم في سمكه ونوعه ولونه.

div { border: 2px solid blue; }

في المثال السابق تم إنشاء حد سمكه 2px ونوعه solid ولونه أزرق.

9. Border Width — سمك الحدود

تستخدم الخاصية border-width لتحديد سمك الحدود.

div { border-width: 3px; }

10. Border Style — نوع الحدود

تستخدم الخاصية border-style لتحديد شكل الحدود.

div { border-style: solid; }

من أشهر أنواع الحدود: solid، dashed، dotted، وdouble.

11. Border Color — لون الحدود

تستخدم الخاصية border-color لتحديد لون الحدود.

div { border-color: #6c63ff; }

12. Border Radius — تدوير الحواف

تستخدم الخاصية border-radius لتدوير زوايا العنصر.

div { border-radius: 15px; }

كلما زادت قيمة border-radius أصبحت الزوايا أكثر استدارة.

13. Margin — الهامش الخارجي

Margin — الهامش الخارجي هو المسافة الموجودة خارج حدود العنصر. ويستخدم لفصل العنصر عن العناصر الأخرى الموجودة حوله.

div { margin: 20px; }

في المثال السابق تم إضافة مسافة خارجية مقدارها 20px من جميع الجهات.

14. Margin on Each Side — الهامش لكل جانب

يمكن تحديد قيمة مختلفة للـ Margin لكل جانب.

div { margin-top: 10px; margin-right: 20px; margin-bottom: 30px; margin-left: 40px; }

15. Margin Shorthand — الاختصار في Margin

يمكن أيضًا كتابة قيم Margin الأربع في سطر واحد.

div { margin: 10px 20px 30px 40px; }

يتم ترتيب القيم بالترتيب: Top → Right → Bottom → Left.

16. Margin Auto — التوسيط باستخدام Auto

يمكن استخدام القيمة auto مع Margin لتوسيط عنصر له عرض محدد أفقيًا.

div { width: 500px; margin: 0 auto; }

في المثال السابق سيتم توسيط العنصر أفقيًا داخل العنصر الأب عندما تكون هناك مساحة كافية.

17. Box Sizing — طريقة حساب حجم العنصر

تستخدم الخاصية box-sizing لتحديد الطريقة التي يحسب بها المتصفح الحجم النهائي للعنصر.

* { box-sizing: border-box; }

عند استخدام border-box يتم احتساب الـ Padding والـ Border ضمن width وheight المحددين للعنصر.

18. Content-box — نموذج المحتوى

القيمة الافتراضية للخاصية box-sizing هي content-box.

div { box-sizing: content-box; width: 300px; padding: 20px; border: 5px solid black; }

في هذه الحالة يتم حساب الـ Padding والـ Border بالإضافة إلى عرض المحتوى، وبالتالي يمكن أن يصبح الحجم النهائي للعنصر أكبر من قيمة الـ width المحددة.

19. Border-box — نموذج الحدود

عند استخدام border-box يتم تضمين الـ Padding والـ Border داخل الحجم المحدد للعنصر.

div { box-sizing: border-box; width: 300px; padding: 20px; border: 5px solid black; }

لذلك يظل العرض الكلي للعنصر 300px مع احتساب الـ Padding والـ Border داخله.

20. Box Model Calculation — حساب حجم العنصر

عند استخدام content-box يمكن حساب العرض الكلي للعنصر باستخدام:

Total Width = Width + Left Padding + Right Padding + Left Border + Right Border

وبالمثل يمكن حساب الارتفاع الكلي باستخدام ارتفاع المحتوى بالإضافة إلى الـ Padding والـ Border العلوي والسفلي.

21. Complete Box Model Example — مثال كامل على Box Model

يمكن استخدام جميع أجزاء Box Model معًا في عنصر واحد.

div { width: 300px; padding: 20px; border: 3px solid #6c63ff; margin: 30px; box-sizing: border-box; }

في المثال السابق تم تحديد عرض العنصر، وإضافة Padding داخلي، وحدود حول العنصر، وMargin خارجي، مع استخدام border-box لحساب الحجم بطريقة أسهل.

22. Box Model Order — ترتيب أجزاء نموذج الصندوق

يمكن ترتيب أجزاء Box Model من الداخل إلى الخارج كالتالي:

  • Content — المحتوى.
  • Padding — الحشو الداخلي.
  • Border — الحدود.
  • Margin — الهامش الخارجي.

23. Important Box Model Properties — أهم خصائص Box Model

  • width — تحديد عرض العنصر.
  • height — تحديد ارتفاع العنصر.
  • padding — تحديد المسافة الداخلية.
  • border — إضافة حدود للعنصر.
  • border-radius — تدوير زوايا العنصر.
  • margin — تحديد المسافة الخارجية.
  • box-sizing — تحديد طريقة حساب حجم العنصر.

24. Try It Yourself — جرب بنفسك

قم بإنشاء عنصر <div> ثم حدد له عرضًا وارتفاعًا، وأضف إليه Padding وBorder وMargin.

حاول تغيير قيم هذه الخصائص ولاحظ كيف يتغير حجم العنصر والمسافات الموجودة حوله.

Quick Review — مراجعة سريعة

  • Box Model = نموذج الصندوق.
  • Content = المحتوى.
  • Padding = الحشو الداخلي.
  • Border = الحدود.
  • Margin = الهامش الخارجي.
  • width = عرض العنصر.
  • height = ارتفاع العنصر.
  • border-radius = تدوير الحواف.
  • box-sizing = طريقة حساب حجم العنصر.
  • content-box = الحجم يعتمد على المحتوى وتضاف إليه المساحات والحدود.
  • border-box = الـ Padding والـ Border يتم احتسابهما داخل الحجم المحدد.
  • ترتيب Box Model من الداخل للخارج: Content → Padding → Border → Margin.

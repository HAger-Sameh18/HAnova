Lesson 8 : Flexbox

1. What is Flexbox? — ما هو Flexbox؟

Flexbox هو نظام تخطيط في CSS يستخدم لترتيب العناصر داخل الحاوية بطريقة مرنة وسهلة.

يستخدم Flexbox بشكل كبير في تصميم صفحات الويب لترتيب العناصر أفقيًا أو رأسيًا والتحكم في المسافات والمحاذاة بينها.

كلمة Flex تشير إلى المرونة، لأن العناصر يمكنها التكيف مع المساحة المتاحة داخل الحاوية.

2. Flex Container — الحاوية المرنة

حتى نستخدم Flexbox، يجب أولًا جعل العنصر الأب Flex Container — حاوية مرنة باستخدام: display: flex;

.container { display: flex; }

بعد إضافة display: flex تصبح العناصر الموجودة داخل الحاوية Flex Items — عناصر مرنة.

3. Flex Items — العناصر المرنة

العناصر الموجودة مباشرة داخل Flex Container تسمى Flex Items.

<div class="container"> <div>Item 1</div> <div>Item 2</div> <div>Item 3</div> </div>

في المثال السابق يعتبر العنصر container هو الحاوية، بينما العناصر الثلاثة الموجودة بداخله هي Flex Items.

4. Flex Direction — اتجاه العناصر

تستخدم الخاصية flex-direction لتحديد الاتجاه الذي يتم فيه ترتيب العناصر.

.container { display: flex; flex-direction: row; }

القيمة row تجعل العناصر مرتبة في اتجاه أفقي.

5. Row — الاتجاه الأفقي

القيمة الافتراضية للخاصية flex-direction هي row.

.container { display: flex; flex-direction: row; }

يتم وضع العناصر بجانب بعضها على المحور الرئيسي Main Axis.

6. Column — الاتجاه الرأسي

يمكن ترتيب العناصر رأسيًا باستخدام القيمة column.

.container { display: flex; flex-direction: column; }

في هذه الحالة تظهر العناصر فوق بعضها من أعلى إلى أسفل.

7. Row Reverse and Column Reverse — عكس الاتجاه

يمكن عكس اتجاه العناصر باستخدام: row-reverse أو column-reverse.

.container { display: flex; flex-direction: row-reverse; }

تقوم row-reverse بعكس ترتيب العناصر أفقيًا.

.container { display: flex; flex-direction: column-reverse; }

تقوم column-reverse بعكس ترتيب العناصر رأسيًا.

8. Main Axis — المحور الرئيسي

Main Axis — المحور الرئيسي هو الاتجاه الأساسي الذي تتحرك فيه عناصر Flexbox.

عندما تكون قيمة flex-direction: row يكون المحور الرئيسي أفقيًا.

وعندما تكون القيمة flex-direction: column يكون المحور الرئيسي رأسيًا.

9. Cross Axis — المحور المتقاطع

Cross Axis — المحور المتقاطع هو المحور الذي يكون عموديًا على المحور الرئيسي.

فهم المحورين مهم جدًا عند استخدام justify-content وalign-items.

10. Justify Content — توزيع العناصر

تستخدم الخاصية justify-content للتحكم في توزيع العناصر على Main Axis.

.container { display: flex; justify-content: center; }

القيمة center تضع العناصر في منتصف المحور الرئيسي.

11. Justify Content Values — قيم Justify Content

  • flex-start — وضع العناصر في بداية المحور.
  • flex-end — وضع العناصر في نهاية المحور.
  • center — وضع العناصر في المنتصف.
  • space-between — توزيع المساحة بين العناصر.
  • space-around — إضافة مساحة حول العناصر.
  • space-evenly — توزيع المسافات بالتساوي.

12. Align Items — محاذاة العناصر

تستخدم الخاصية align-items لمحاذاة العناصر على Cross Axis.

.container { display: flex; align-items: center; }

القيمة center تجعل العناصر في منتصف المحور المتقاطع.

13. Align Items Values — قيم Align Items

  • stretch — تمديد العناصر حسب المساحة المتاحة.
  • flex-start — بداية المحور المتقاطع.
  • flex-end — نهاية المحور المتقاطع.
  • center — المنتصف.
  • baseline — المحاذاة حسب خط الأساس للنص.

14. Centering with Flexbox — توسيط العناصر باستخدام Flexbox

من أشهر استخدامات Flexbox وضع عنصر في منتصف الحاوية أفقيًا ورأسيًا.

.container { display: flex; justify-content: center; align-items: center; }

باستخدام الخاصيتين معًا يمكن الوصول إلى توسيط العناصر بسهولة داخل الحاوية.

15. Gap — المسافة بين العناصر

تستخدم الخاصية gap لتحديد المسافة بين عناصر Flexbox.

.container { display: flex; gap: 20px; }

في المثال السابق توجد مسافة مقدارها 20px بين العناصر.

16. Flex Wrap — التفاف العناصر

بشكل افتراضي تحاول عناصر Flexbox البقاء في صف واحد. ويمكن السماح لها بالانتقال إلى سطر آخر باستخدام flex-wrap.

.container { display: flex; flex-wrap: wrap; }

عندما لا توجد مساحة كافية، تنتقل العناصر إلى سطر جديد.

17. Flex Wrap Values — قيم Flex Wrap

  • nowrap — عدم التفاف العناصر، وهي القيمة الافتراضية.
  • wrap — السماح بانتقال العناصر إلى سطر جديد.
  • wrap-reverse — الالتفاف في الاتجاه المعاكس.

18. Align Content — محاذاة الصفوف

تستخدم الخاصية align-content للتحكم في توزيع الصفوف أو الأعمدة عندما تكون هناك عدة أسطر من عناصر Flexbox.

.container { display: flex; flex-wrap: wrap; align-content: center; }

تستخدم هذه الخاصية بشكل أساسي عندما يكون هناك أكثر من Flex Line.

19. Align Self — محاذاة عنصر واحد

تستخدم الخاصية align-self لتغيير محاذاة عنصر Flex واحد دون التأثير على باقي العناصر.

.item { align-self: flex-end; }

20. Flex Grow — نمو العنصر

تستخدم الخاصية flex-grow لتحديد قدرة العنصر على النمو واستغلال المساحة الإضافية داخل الحاوية.

.item { flex-grow: 1; }

يمكن أن تسمح هذه الخاصية لعنصر بالاستفادة من المساحة المتبقية داخل الحاوية.

21. Flex Shrink — تقليص العنصر

تستخدم الخاصية flex-shrink لتحديد قدرة العنصر على الانكماش عندما لا تكون المساحة المتاحة كافية.

.item { flex-shrink: 1; }

22. Flex Basis — الحجم الأساسي

تستخدم الخاصية flex-basis لتحديد الحجم الأساسي للعنصر قبل توزيع المساحة المتاحة.

.item { flex-basis: 200px; }

23. Flex Shorthand — اختصار Flex

يمكن استخدام الخاصية flex كاختصار للخصائص: flex-grow، flex-shrink، وflex-basis.

.item { flex: 1; }

24. Order — ترتيب العناصر

تستخدم الخاصية order لتغيير ترتيب ظهور عناصر Flexbox.

.item1 { order: 2; } .item2 { order: 1; }

العنصر الذي يمتلك قيمة order أصغر يظهر قبل العناصر التي تمتلك قيمة أكبر.

25. Flexbox Navigation Example — مثال على قائمة باستخدام Flexbox

.nav { display: flex; justify-content: space-around; align-items: center; gap: 15px; }

يمكن استخدام Flexbox بسهولة لإنشاء قوائم التنقل وترتيب الروابط بجانب بعضها.

26. Flexbox Cards Example — مثال على ترتيب العناصر

.container { display: flex; justify-content: center; gap: 20px; flex-wrap: wrap; } .card { width: 250px; padding: 20px; }

في المثال السابق يمكن ترتيب عدة عناصر بجانب بعضها، وعندما تقل المساحة يمكن أن تنتقل العناصر إلى سطر جديد بسبب استخدام flex-wrap.

27. Flexbox Properties for Container — خصائص الحاوية

  • display — تشغيل Flexbox.
  • flex-direction — تحديد اتجاه العناصر.
  • justify-content — توزيع العناصر على المحور الرئيسي.
  • align-items — محاذاة العناصر على المحور المتقاطع.
  • flex-wrap — التحكم في التفاف العناصر.
  • align-content — توزيع الصفوف.
  • gap — المسافة بين العناصر.

28. Flexbox Properties for Items — خصائص العناصر

  • order — تغيير ترتيب العنصر.
  • flex-grow — تحديد قدرة العنصر على النمو.
  • flex-shrink — تحديد قدرة العنصر على الانكماش.
  • flex-basis — تحديد الحجم الأساسي.
  • flex — اختصار خصائص Flex.
  • align-self — محاذاة عنصر منفرد.

29. Complete Flexbox Example — مثال كامل على Flexbox

.container { display: flex; flex-direction: row; justify-content: center; align-items: center; gap: 20px; flex-wrap: wrap; } .item { width: 200px; padding: 20px; }

يجمع المثال السابق بين مجموعة من خصائص Flexbox لإنشاء تخطيط مرن ومنظم للعناصر.

30. Try It Yourself — جرب بنفسك

قم بإنشاء حاوية تحتوي على ثلاثة أو أربعة عناصر، ثم استخدم display: flex لترتيبها بجانب بعضها.

جرب تغيير قيمة flex-direction بين row وcolumn ولاحظ الفرق.

بعد ذلك جرب justify-content وalign-items وgap وflex-wrap ولاحظ كيف تتغير أماكن العناصر.

Lesson 9 : Pseudo-classes and Effects

1. What is a Pseudo-class? — ما هي Pseudo-class؟

Pseudo-class — المحدد الوهمي هو كلمة مفتاحية يتم إضافتها إلى Selector في CSS لتحديد حالة معينة للعنصر.

تستخدم Pseudo-classes لتغيير شكل العنصر عندما تحدث حالة معينة، مثل مرور مؤشر الفأرة فوق العنصر أو الضغط عليه أو تحديد عنصر معين.

a:hover { color: red; }

في المثال السابق يتم تغيير لون الرابط عندما يمر مؤشر الفأرة فوقه.

2. Hover — عند مرور مؤشر الفأرة

تعتبر :hover من أشهر Pseudo-classes في CSS. وتستخدم عندما يمر مؤشر الفأرة فوق العنصر.

عند تحريك مؤشر الفأرة فوق الزر، يتم تطبيق التنسيق الموجود داخل :hover.

button:hover { background-color: #1e293b; color: white; }

3. Active — أثناء الضغط

تستخدم :active لتحديد حالة العنصر أثناء الضغط عليه.

يمكن استخدام هذه الحالة لإعطاء المستخدم تأثيرًا بصريًا عند الضغط على الزر.

button:active { transform: scale(0.95); }

4. Focus — حالة التركيز

تستخدم :focus عندما يكون العنصر في حالة تركيز، مثل حقل الإدخال الذي تم تحديده للكتابة بداخله.

عند الضغط على حقل الإدخال وبدء الكتابة بداخله، يمكن تطبيق التنسيق الموجود في :focus.

input:focus { border: 2px solid #6c63ff; }

5. Visited — الرابط الذي تمت زيارته

تستخدم :visited لتحديد الروابط التي سبق للمستخدم زيارتها.

يمكن للمتصفح تطبيق التنسيق على الرابط بعد زيارته.

a:visited { color: purple; }

6. Link — الرابط غير المزور

تستخدم :link لتحديد الروابط التي لم تتم زيارتها بعد.

a:link { color: blue; }

7. First-child — أول عنصر ابن

تستخدم :first-child لتحديد العنصر الذي يكون أول ابن داخل العنصر الأب.

p:first-child { color: red; }

في المثال السابق يتم تحديد عنصر p إذا كان هو أول عنصر ابن داخل العنصر الأب.

8. Last-child — آخر عنصر ابن

تستخدم :last-child لتحديد العنصر الذي يكون آخر ابن داخل العنصر الأب.

p:last-child { color: blue; }

9. Nth-child — تحديد عنصر حسب ترتيبه

تستخدم :nth-child() لتحديد عنصر بناءً على ترتيبه بين العناصر الأبناء.

li:nth-child(2) { color: #6c63ff; }

في المثال السابق يتم تحديد العنصر الثاني من عناصر li.

10. Odd and Even — العناصر الفردية والزوجية

يمكن استخدام odd وeven مع :nth-child() لتحديد العناصر الفردية والزوجية.

القيمة odd تحدد العناصر ذات الترتيب الفردي، بينما even تحدد العناصر ذات الترتيب الزوجي.

li:nth-child(odd) { background-color: #1e293b; } li:nth-child(even) { background-color: #5B4BDB; }

11. First-of-type — أول عنصر من نفس النوع

تستخدم :first-of-type لتحديد أول عنصر من نوع معين داخل العنصر الأب.

p:first-of-type { color: red; }

12. Last-of-type — آخر عنصر من نفس النوع

تستخدم :last-of-type لتحديد آخر عنصر من نوع معين داخل العنصر الأب.

p:last-of-type { color: blue; }

13. Not — عكس التحديد

تستخدم :not() لتحديد العناصر التي لا تطابق Selector معين.

p:not(.special) { color: white; }

في المثال السابق سيتم تطبيق التنسيق على عناصر p التي لا تحتوي على Class باسم special.

14. Empty — العنصر الفارغ

تستخدم :empty لتحديد العناصر التي لا تحتوي على محتوى أو عناصر أخرى بداخلها.

div:empty { display: none; }

15. Checked — العنصر المحدد

تستخدم :checked مع عناصر مثل checkbox وradio عندما يكون العنصر محددًا.

input:checked { accent-color: #6c63ff; }

16. Disabled — العنصر المعطل

تستخدم :disabled لتحديد العناصر التي تم تعطيلها.

button:disabled { opacity: 0.5; }

17. Enabled — العنصر المتاح

تستخدم :enabled لتحديد العناصر التي تكون متاحة للاستخدام.

input:enabled { background-color: white; }

18. CSS Transitions — الانتقالات

تستخدم خاصية transition لإنشاء انتقال تدريجي بين حالتين مختلفتين للعنصر.

بدلًا من تغيير اللون بشكل مفاجئ، تجعل transition التغيير يحدث تدريجيًا.

button { background-color: #6c63ff; transition: 0.5s; } button:hover { background-color: #1e293b; }

19. Transition Duration — مدة الانتقال

يمكن تحديد مدة الانتقال باستخدام transition-duration.

.box { transition-duration: 1s; }

في المثال السابق يستغرق الانتقال ثانية واحدة.

20. Transition Property — الخاصية التي يتم انتقالها

تستخدم transition-property لتحديد الخاصية التي نريد تطبيق الانتقال عليها.

.box { transition-property: background-color; }

21. Transform — التحويلات

تستخدم خاصية transform لتغيير شكل أو موضع العنصر بطريقة مرئية، مثل التكبير أو التدوير أو التحريك.

22. Scale — التكبير والتصغير

تستخدم scale() لتكبير أو تصغير العنصر.

القيمة 1.1 تجعل العنصر أكبر قليلًا من حجمه الأصلي.

.box:hover { transform: scale(1.1); }

23. Rotate — تدوير العنصر

تستخدم rotate() لتدوير العنصر بدرجة معينة.

.box:hover { transform: rotate(5deg); }

24. Translate — تحريك العنصر

تستخدم translate() لتحريك العنصر أفقيًا أو رأسيًا.

.box:hover { transform: translateY(-10px); }

في المثال السابق يتحرك العنصر إلى أعلى بمقدار 10px.

25. Combining Transform Functions — دمج التحويلات

يمكن دمج أكثر من Transform Function في نفس السطر.

.box:hover { transform: translateY(-5px) scale(1.05); }

في المثال السابق يتحرك العنصر إلى أعلى قليلًا ثم يكبر بنسبة بسيطة.

26. Transition with Transform — استخدام Transition مع Transform

يمكن دمج transition مع transform لإنشاء تأثيرات أكثر سلاسة.

.box { transition: transform 0.5s; } .box:hover { transform: scale(1.1); }

27. Opacity — الشفافية

تستخدم الخاصية opacity للتحكم في درجة شفافية العنصر.

قيمة 1 تعني أن العنصر ظاهر بالكامل، بينما قيمة 0 تعني أن العنصر شفاف تمامًا.

.box { opacity: 0.5; }

28. Opacity with Hover — الشفافية مع Hover

.image { opacity: 0.7; transition: 0.5s; } .image:hover { opacity: 1; }

في المثال السابق تصبح الصورة أكثر وضوحًا عند مرور مؤشر الفأرة عليها.

29. Box Shadow — ظل العنصر

تستخدم الخاصية box-shadow لإضافة ظل حول العنصر.

يمكن استخدام الظلال لإعطاء العناصر مظهرًا أكثر وضوحًا وإبرازها عن الخلفية.

.box { box-shadow: 0 0 15px #000000; }

30. Complete Hover Effect — تأثير Hover كامل

.card { background-color: #1e293b; border-radius: 15px; transition: 0.5s; } .card:hover { transform: translateY(-10px) scale(1.03); box-shadow: 0 0 20px #000000; }

يجمع المثال السابق بين hover وtransition وtransform وbox-shadow لإنشاء تأثير تفاعلي عند مرور مؤشر الفأرة.

31. Common Pseudo-classes — أشهر Pseudo-classes

  • :hover — عند مرور مؤشر الفأرة.
  • :active — أثناء الضغط.
  • :focus — عند التركيز على العنصر.
  • :visited — الرابط الذي تمت زيارته.
  • :link — الرابط الذي لم تتم زيارته.
  • :first-child — أول عنصر ابن.
  • :last-child — آخر عنصر ابن.
  • :nth-child() — عنصر حسب ترتيبه.
  • :not() — العناصر التي لا تطابق المحدد.
  • :checked — العنصر المحدد.
  • :disabled — العنصر المعطل.
  • :enabled — العنصر المتاح.
  • :empty — العنصر الفارغ.

32. Important Effects — أهم التأثيرات

  • transition — إنشاء انتقال تدريجي.
  • transform — تغيير شكل أو موضع العنصر.
  • scale() — تكبير أو تصغير العنصر.
  • rotate() — تدوير العنصر.
  • translate() — تحريك العنصر.
  • opacity — التحكم في الشفافية.
  • box-shadow — إضافة ظل للعنصر.

33. Try It Yourself — جرب بنفسك

قم بإنشاء زر باستخدام HTML، ثم استخدم :hover لتغيير لونه عند مرور مؤشر الفأرة عليه.

أضف transition لجعل التغيير تدريجيًا، ثم استخدم transform: scale() لجعل الزر يكبر قليلًا عند المرور عليه.

حاول أيضًا إنشاء عدة عناصر واستخدام :first-child و:last-child و:nth-child() لتغيير شكل عناصر معينة.

Lesson 1 : Introduction To CSS

1. What is CSS? — ما هي CSS؟

CSS هي اختصار للمصطلح Cascading Style Sheets أي أوراق الأنماط المتتالية. وهي اللغة المستخدمة لتنسيق وتصميم صفحات الويب والتحكم في مظهر العناصر الموجودة داخل صفحة HTML.

باستخدام CSS يمكننا تغيير ألوان النصوص والخلفيات، وتحديد أحجام العناصر، وتغيير نوع الخط، وإضافة الحدود والمسافات، والتحكم في طريقة ظهور العناصر داخل الصفحة.

2. What is the Purpose of CSS? — ما الهدف من CSS؟

الهدف الأساسي من CSS هو فصل Content — المحتوى عن Design — التصميم. حيث يتم استخدام HTML لإنشاء وتنظيم محتوى الصفحة، بينما يتم استخدام CSS لتحديد الشكل والمظهر الخاص بهذا المحتوى.

فبدلًا من كتابة خصائص التصميم داخل كل عنصر في HTML، يمكننا كتابة قواعد CSS والتحكم في عدد كبير من العناصر بسهولة.

3. CSS and HTML — العلاقة بين CSS و HTML

تعمل CSS مع HTML بشكل أساسي في تصميم صفحات الويب. حيث تقوم HTML ببناء Structure — هيكل الصفحة، بينما تقوم CSS بتنسيق هذا الهيكل وإعطائه الشكل المناسب.

HTML — Structure

تستخدم HTML لبناء هيكل الصفحة وتنظيم محتواها.

CSS — Style

تستخدم CSS لتنسيق الصفحة والتحكم في شكل ومظهر العناصر.

JavaScript — Interaction

تستخدم JavaScript لإضافة التفاعل والوظائف الديناميكية إلى الصفحة.

4. Why Do We Use CSS? — لماذا نستخدم CSS؟

نستخدم CSS للتحكم في المظهر الخارجي لصفحات الويب وجعلها أكثر تنظيمًا وجاذبية وسهولة في الاستخدام.

  • تغيير ألوان النصوص والعناصر.
  • تغيير نوع وحجم الخطوط.
  • إضافة ألوان وخلفيات للصفحة.
  • إضافة الحدود حول العناصر.
  • تحديد عرض وارتفاع العناصر.
  • التحكم في المسافات بين العناصر.
  • تحديد أماكن العناصر داخل الصفحة.
  • إنشاء تصميم مناسب للشاشات المختلفة.

5. Is CSS a Programming Language? — هل CSS لغة برمجة؟

لا، CSS ليست لغة برمجة. وإنما هي Style Sheet Language — لغة تنسيق تستخدم لتحديد طريقة ظهور عناصر HTML.

CSS لا تستخدم لتنفيذ الخوارزميات أو العمليات المنطقية مثل لغات البرمجة، وإنما تركز على تصميم وتنسيق واجهة المستخدم.

6. CSS Syntax — صياغة CSS

تتكون قاعدة CSS الأساسية من ثلاثة أجزاء رئيسية: Selector — المحدد، Property — الخاصية، وValue — القيمة.

h1 { color: blue; }

في المثال السابق: h1 هو Selector — المحدد، وcolor هي Property — الخاصية، وblue هي Value — القيمة.

7. Selector — المحدد

Selector — المحدد هو الجزء الذي نستخدمه لتحديد عنصر HTML الذي نريد تطبيق التنسيق عليه.

على سبيل المثال، إذا أردنا تغيير شكل جميع عناصر <p> في الصفحة، يمكننا استخدام اسم العنصر كمحدد.

p { color: red; }

8. Property — الخاصية

Property — الخاصية تحدد الشيء الذي نريد تغييره في العنصر. ومن أمثلة الخصائص: color، font-size، background-color وwidth.

h1 { color: blue; }

في المثال السابق تعتبر color هي الخاصية التي تحدد لون النص.

9. Value — القيمة

Value — القيمة هي القيمة التي نحددها للخاصية. وهي التي تحدد الشكل أو النتيجة التي نريد تطبيقها على العنصر.

h1 { color: blue; }

في المثال السابق تعتبر blue هي القيمة التي تم تحديدها للخاصية color.

10. CSS Declaration — تصريح CSS

Declaration — التصريح هو مجموعة Property وValue التي تحدد التنسيق المطلوب تطبيقه على العنصر.

color: blue;

في المثال السابق: color هي الخاصية، وblue هي القيمة، والاثنان معًا يمثلان Declaration — تصريح CSS.

11. CSS Rule — قاعدة CSS

CSS Rule — قاعدة CSS هي مجموعة كاملة تتكون من المحدد Selector ومجموعة من التصريحات Declarations.

h1 { color: blue; font-size: 30px; }

في المثال السابق تم تحديد عنصر h1 ثم تم تطبيق خاصيتين عليه وهما color وfont-size.

12. Three Ways to Add CSS — طرق إضافة CSS

توجد ثلاث طرق أساسية لإضافة CSS إلى صفحات HTML، وهي: Inline CSS، Internal CSS، وExternal CSS.

13. Inline CSS — CSS داخل العنصر

يتم كتابة Inline CSS داخل عنصر HTML نفسه باستخدام الخاصية style.

<h1 style="color: red;"> Welcome to CSS </h1>

في هذه الطريقة يتم تطبيق التنسيق مباشرة على العنصر الذي يحتوي على الخاصية style.

14. Internal CSS — CSS داخل الصفحة

يتم كتابة Internal CSS داخل وسم <style> الموجود عادةً داخل <head> في صفحة HTML.

<style> h1 { color: green; } </style>

15. External CSS — CSS خارجي

يتم كتابة External CSS في ملف CSS منفصل، ثم يتم ربطه بصفحة HTML باستخدام وسم <link>.

<link rel="stylesheet" href="style.css">

تعتبر هذه الطريقة من أفضل الطرق عند إنشاء المواقع الكبيرة، لأنها تسمح باستخدام ملف CSS واحد لتنسيق أكثر من صفحة HTML.

16. First CSS Example — أول مثال CSS

في المثال التالي سنقوم بتنسيق عنوان موجود داخل صفحة HTML، وتغيير لونه وحجم الخط الخاص به.

h1 { color: #6c63ff; font-size: 32px; }

يقوم الكود السابق بتغيير لون العنوان إلى اللون المحدد، كما يقوم بتحديد حجم الخط ليكون 32px.

17. Important CSS Terms — أهم مصطلحات CSS

  • CSS — Cascading Style Sheets — أوراق الأنماط المتتالية.
  • Selector — المحدد.
  • Property — الخاصية.
  • Value — القيمة.
  • Declaration — التصريح.
  • Rule — قاعدة CSS.
  • Style — تنسيق أو نمط.
  • External CSS — ملف CSS خارجي.

18. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة HTML تحتوي على عنوان باستخدام <h1> وفقرة باستخدام <p>. ثم استخدم CSS لتغيير لون العنوان وحجم الخط، وحاول أيضًا تغيير لون الفقرة.

  • HTML تستخدم لبناء هيكل الصفحة.
  • CSS تستخدم للتحكم في مظهر الصفحة.
  • Selector = المحدد.
  • Property = الخاصية.
  • Value = القيمة.
  • Declaration = التصريح.

  • Internal CSS = CSS داخل الصفحة.

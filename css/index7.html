Lesson 5 : Width, Height and Units

1. Width and Height — العرض والارتفاع

تستخدم CSS خصائص مختلفة للتحكم في أبعاد عناصر HTML، ومن أهم هذه الخصائص Width — العرض و Height — الارتفاع.

تساعد هذه الخصائص على تحديد المساحة التي يشغلها العنصر داخل صفحة الويب.

2. Width Property — خاصية Width

تستخدم الخاصية width لتحديد عرض العنصر.

div { width: 300px; }

في المثال السابق تم تحديد عرض العنصر ليكون 300px.

3. Height Property — خاصية Height

تستخدم الخاصية height لتحديد ارتفاع العنصر.

div { height: 200px; }

في المثال السابق تم تحديد ارتفاع العنصر ليكون 200px.

4. Width and Height Together — استخدام Width و Height معًا

يمكن استخدام الخاصيتين width و height معًا لتحديد أبعاد العنصر.

div { width: 400px; height: 200px; }

أصبح للعنصر في المثال السابق عرض مقداره 400px وارتفاع مقداره 200px.

5. CSS Units — وحدات القياس في CSS

تستخدم CSS وحدات مختلفة لتحديد الأحجام والمسافات. وتنقسم وحدات القياس إلى نوعين أساسيين:

  • Absolute Units — وحدات ثابتة.
  • Relative Units — وحدات نسبية.

6. Absolute Units — الوحدات الثابتة

Absolute Units — الوحدات الثابتة هي وحدات لا تعتمد بشكل مباشر على حجم العنصر الأب أو حجم الشاشة.

من أشهر الوحدات الثابتة المستخدمة في CSS: px.

div { width: 300px; height: 150px; }

7. Pixel (px) — البكسل

px — Pixel هي من أكثر وحدات القياس استخدامًا في CSS. وتستخدم لتحديد أحجام دقيقة نسبيًا مثل عرض العناصر وحجم الخطوط والحدود.

h1 { font-size: 32px; } div { width: 300px; }

8. Percentage (%) — النسبة المئوية

تستخدم وحدة % لتحديد حجم العنصر كنسبة من حجم العنصر الأب.

.box { width: 50%; }

إذا كان عرض العنصر الأب 1000px فإن عرض العنصر الذي يساوي 50% سيكون 500px.

9. Percentage Height — النسبة المئوية للارتفاع

يمكن استخدام النسبة المئوية أيضًا مع height، ولكن يجب أن يكون ارتفاع العنصر الأب محددًا حتى يكون الحساب واضحًا.

.parent { height: 400px; } .child { height: 50%; }

في المثال السابق سيكون ارتفاع العنصر الابن 200px لأنه يساوي 50% من ارتفاع العنصر الأب.

10. Viewport Units — وحدات الشاشة

Viewport Units هي وحدات تعتمد على حجم نافذة المتصفح Viewport — مساحة العرض.

من أشهر هذه الوحدات: vw و vh.

11. VW — عرض نافذة المتصفح

vw هي اختصار لـ Viewport Width. وتمثل نسبة من عرض نافذة المتصفح.

div { width: 50vw; }

القيمة 50vw تعني أن عرض العنصر يساوي 50% من عرض نافذة المتصفح.

12. VH — ارتفاع نافذة المتصفح

vh هي اختصار لـ Viewport Height. وتمثل نسبة من ارتفاع نافذة المتصفح.

div { height: 50vh; }

القيمة 50vh تعني أن ارتفاع العنصر يساوي 50% من ارتفاع نافذة المتصفح.

13. EM Unit — وحدة EM

em هي وحدة نسبية تعتمد بشكل أساسي على حجم خط العنصر أو العنصر الأب حسب الخاصية المستخدمة.

p { font-size: 2em; }

عند استخدام em مع حجم الخط، تكون القيمة مرتبطة بحجم الخط المرجعي.

14. REM Unit — وحدة REM

rem هي اختصار لـ Root EM. وتعتمد على حجم خط العنصر الجذر html.

html { font-size: 16px; } h1 { font-size: 2rem; }

إذا كان حجم خط العنصر html يساوي 16px، فإن 2rem تساوي 32px.

15. Difference Between EM and REM — الفرق بين EM و REM

كلاهما وحدات نسبية، ولكن هناك اختلاف في المرجع الذي تعتمد عليه كل وحدة.

  • em تعتمد على حجم الخط المرجعي للعنصر أو العنصر الأب.
  • rem تعتمد على حجم خط العنصر الجذر html.

16. Max-Width — أقصى عرض

تستخدم الخاصية max-width لتحديد أقصى عرض يمكن أن يصل إليه العنصر.

.container { width: 90%; max-width: 1000px; }

في المثال السابق يمكن أن يكون عرض العنصر 90% من المساحة المتاحة، ولكنه لن يتجاوز 1000px.

17. Min-Width — أقل عرض

تستخدم الخاصية min-width لتحديد أقل عرض يمكن أن يصل إليه العنصر.

div { min-width: 200px; }

لن يقل عرض العنصر عن 200px عند وجود مساحة كافية لتطبيق هذا الحد.

18. Max-Height — أقصى ارتفاع

تستخدم الخاصية max-height لتحديد أقصى ارتفاع يمكن أن يصل إليه العنصر.

div { max-height: 400px; }

19. Min-Height — أقل ارتفاع

تستخدم الخاصية min-height لتحديد أقل ارتفاع يمكن أن يصل إليه العنصر.

div { min-height: 200px; }

20. Auto Value — القيمة Auto

تستخدم القيمة auto للسماح للمتصفح بتحديد الحجم تلقائيًا وفقًا للمحتوى والمساحة المتاحة.

div { width: auto; height: auto; }

21. Width and Height with Box Model — الأبعاد مع Box Model

عند تحديد width وheight يجب الانتباه إلى طريقة حساب الحجم عند استخدام box-sizing.

div { width: 300px; height: 200px; padding: 20px; border: 5px solid #6c63ff; box-sizing: border-box; }

باستخدام border-box يتم احتساب الـ Padding والـ Border داخل العرض والارتفاع المحددين.

22. Choosing the Right Unit — اختيار وحدة القياس المناسبة

اختيار وحدة القياس يعتمد على نوع التصميم والهدف من استخدامها.

  • px مناسبة للأحجام التي تحتاج إلى قيمة محددة.
  • % مناسبة للأحجام المرتبطة بالعنصر الأب.
  • vw مناسبة للأحجام المرتبطة بعرض الشاشة.
  • vh مناسبة للأحجام المرتبطة بارتفاع الشاشة.
  • em مناسبة للأحجام المرتبطة بحجم الخط المرجعي.
  • rem مناسبة للأحجام المرتبطة بحجم خط العنصر الجذر.

23. Complete Example — مثال كامل

يمكن استخدام أكثر من وحدة قياس في نفس التصميم.

.container { width: 90%; max-width: 1000px; min-height: 300px; padding: 2rem; margin: auto; } .title { font-size: 2rem; }

في المثال السابق تم استخدام النسبة المئوية مع max-width للتحكم في عرض العنصر، واستخدام rem لحجم الخط والمسافات.

24. Important Width, Height and Units Properties — أهم الخصائص

  • width — تحديد عرض العنصر.
  • height — تحديد ارتفاع العنصر.
  • min-width — تحديد أقل عرض.
  • max-width — تحديد أقصى عرض.
  • min-height — تحديد أقل ارتفاع.
  • max-height — تحديد أقصى ارتفاع.
  • auto — تحديد الحجم تلقائيًا.
  • px — وحدة البكسل.
  • % — النسبة المئوية.
  • vw — نسبة من عرض نافذة المتصفح.
  • vh — نسبة من ارتفاع نافذة المتصفح.
  • em — وحدة نسبية مرتبطة بحجم الخط المرجعي.
  • rem — وحدة نسبية مرتبطة بحجم خط العنصر الجذر.

25. Try It Yourself — جرب بنفسك

قم بإنشاء عنصر <div> وحاول تغيير width وheight باستخدام وحدات مختلفة مثل px و% وvw وvh.

حاول أيضًا استخدام min-width وmax-width ولاحظ كيف يتغير حجم العنصر عند تغيير حجم نافذة المتصفح.

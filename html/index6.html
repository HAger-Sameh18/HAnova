Lesson 4 : HTML Tables

1. What is a Table? — ما هو الجدول؟

Table — الجدول هو طريقة تستخدم لعرض البيانات في صورة منظمة تتكون من صفوف وأعمدة. تستخدم الجداول عندما نريد عرض مجموعة من المعلومات بطريقة سهلة القراءة والمقارنة.

يمكن استخدام الجداول لعرض درجات الطلاب، بيانات الموظفين، أسعار المنتجات، مواعيد المحاضرات، نتائج المباريات، أو أي بيانات أخرى يمكن تنظيمها في صفوف وأعمدة.

2. Table Structure — تركيب الجدول

يتكون جدول HTML من مجموعة من العناصر الأساسية، ولكل عنصر وظيفة محددة. أهم هذه العناصر هي:

  • table — الجدول.
  • tr — صف الجدول.
  • th — خلية عنوان.
  • td — خلية بيانات.

3. The <table> Element — عنصر الجدول

يستخدم عنصر <table> لإنشاء الجدول نفسه، ويجب أن توضع جميع صفوف وخلايا الجدول داخله.

<table>   Table Content </table>

4. Table Row — صف الجدول

العنصر <tr> هو اختصار لـ Table Row — صف الجدول. ويستخدم لإنشاء صف جديد داخل الجدول.

<table>   <tr>     Row Content   </tr> </table>

5. Table Header — عنوان العمود

العنصر <th> هو اختصار لـ Table Header — عنوان الجدول أو عنوان العمود. ويستخدم لكتابة أسماء الأعمدة.

<tr>   <th>Name</th>   <th>Age</th>   <th>Grade</th> </tr>

في المثال السابق لدينا ثلاثة عناوين للأعمدة: Name و Age و Grade.

6. Table Data — بيانات الجدول

العنصر <td> هو اختصار لـ Table Data — بيانات الجدول. ويستخدم لإضافة البيانات داخل خلايا الجدول.

<tr>   <td>Ahmed</td>   <td>20</td>   <td>95</td> </tr>

7. Creating Your First Table — إنشاء أول جدول

يمكن الآن دمج العناصر السابقة لإنشاء جدول بسيط يحتوي على أسماء الطلاب ودرجاتهم.

<table>
  <tr>     <th>Name</th>     <th>Course</th>     <th>Grade</th>   </tr>
  <tr>     <td>Ahmed</td>     <td>HTML</td>     <td>95</td>   </tr>
  <tr>     <td>Mona</td>     <td>CSS</td>     <td>90</td>   </tr>
</table>

8. Caption — عنوان الجدول

يمكن استخدام العنصر <caption> لإضافة عنوان يصف محتوى الجدول.

Caption — عنوان توضيحي يساعد المستخدم على معرفة الغرض من الجدول قبل قراءة البيانات الموجودة بداخله.

<table>   <caption>Students Grades</caption>   <tr>     <th>Name</th>     <th>Grade</th>   </tr> </table>

9. Table Head — رأس الجدول

العنصر <thead> يعني Table Head — رأس الجدول. ويستخدم لتجميع الصفوف التي تحتوي على عناوين الأعمدة.

<table>   <thead>     <tr>       <th>Name</th>       <th>Grade</th>     </tr>   </thead> </table>

10. Table Body — جسم الجدول

العنصر <tbody> يعني Table Body — جسم الجدول. ويستخدم لتجميع صفوف البيانات الأساسية الموجودة داخل الجدول.

<tbody>   <tr>     <td>Ahmed</td>     <td>95</td>   </tr> </tbody>

11. Table Footer — تذييل الجدول

العنصر <tfoot> يعني Table Footer — تذييل الجدول. ويستخدم لعرض معلومات أو نتائج في نهاية الجدول.

<tfoot>   <tr>     <td>Total</td>     <td>185</td>   </tr> </tfoot>

12. Colspan — دمج الأعمدة

الخاصية colspan تستخدم لدمج خليتين أو أكثر من الخلايا في نفس الصف لتكوين خلية واحدة تمتد عبر عدة أعمدة.

إذا كانت قيمة colspan تساوي 2 فهذا يعني أن الخلية ستأخذ مساحة عمودين.

<tr>   <td colspan="2">     Student Information   </td> </tr>

13. Rowspan — دمج الصفوف

الخاصية rowspan تستخدم لدمج خلايا موجودة في صفوف مختلفة، بحيث تمتد الخلية رأسيًا عبر أكثر من صف.

<tr>   <td rowspan="2">     HTML   </td>   <td>Lesson 1</td> </tr> <tr>   <td>Lesson 2</td> </tr>

14. Complete Table Example — مثال جدول كامل

<table>
  <caption>Student Grades</caption>
  <thead>
    <tr>
      <th>Name</th>       <th>HTML</th>       <th>CSS</th>       <th>JavaScript</th>
    </tr>
  </thead>
  <tbody>
    <tr>       <td>Ahmed</td>       <td>95</td>       <td>90</td>       <td>88</td>     </tr>
    <tr>       <td>Mona</td>       <td>92</td>       <td>94</td>       <td>96</td>     </tr>
  </tbody>
</table>

15. When Should We Use Tables? — متى نستخدم الجداول؟

الجداول مناسبة عندما تكون البيانات بطبيعتها منظمة في صورة صفوف وأعمدة، مثل جداول الدرجات والأسعار والمواعيد والبيانات الإحصائية. لكن لا يفضل استخدام الجداول لتقسيم وتصميم صفحة الويب بالكامل؛ فالتنسيق والتخطيط يتم باستخدام CSS وأدوات التخطيط الحديثة.

16. Common Mistakes — الأخطاء الشائعة

  • نسيان وضع خلايا الجدول داخل صف <tr>.
  • استخدام <td> بدلًا من <th> لعناوين الأعمدة.
  • نسيان إغلاق العناصر.
  • استخدام colspan أو rowspan بقيمة غير مناسبة.
  • استخدام الجداول لتصميم الصفحة بدلًا من استخدامها للبيانات الجدولية.

17. Try It Yourself — جرب بنفسك

أنشئ جدولًا لثلاثة طلاب، ويحتوي الجدول على اسم الطالب وثلاث مواد ودرجة كل مادة. استخدم table وtr وth وtd. بعد ذلك حاول إضافة caption للجدول وتجربة colspan وrowspan.

Quick Review — مراجعة سريعة

  • Table = جدول.
  • Row = صف.
  • Cell = خلية.
  • Table Header = عنوان الجدول أو العمود.
  • Table Data = بيانات الجدول.
  • Caption = عنوان توضيحي للجدول.
  • Thead = رأس الجدول.
  • Tbody = جسم الجدول.
  • Tfoot = تذييل الجدول.
  • Colspan = دمج أعمدة.
  • Rowspan = دمج صفوف.

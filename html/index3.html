Lesson 1 : Introduction To HTML

1. What is HTML? — ما هي HTML؟

HTML هي اختصار للمصطلح HyperText Markup Language أي لغة ترميز النص التشعبي. وهي اللغة الأساسية المستخدمة في إنشاء وبناء صفحات الويب وتنظيم المحتوى الذي يظهر داخل المتصفح.

عندما نفتح أي موقع على الإنترنت، فإن الصفحة التي نراها تحتوي على عناوين وفقرات وصور وروابط وقوائم وغيرها من العناصر. يتم تحديد هيكل هذه العناصر وتنظيمها باستخدام HTML.

2. Meaning of HyperText — معنى HyperText

كلمة HyperText تعني النص التشعبي. وهو نص يحتوي على روابط تسمح للمستخدم بالانتقال من صفحة إلى صفحة أخرى أو من جزء إلى جزء آخر داخل الموقع.

على سبيل المثال، عندما نضغط على كلمة Learn HTML وتنتقل إلى صفحة أخرى، فإن هذه الكلمة تمثل رابطًا Link — رابط.

3. Meaning of Markup — معنى Markup

كلمة Markup تعني الترميز أو وضع علامات لتحديد وتنظيم المحتوى. تستخدم HTML مجموعة من العلامات تسمى Tags — الوسوم لتخبر المتصفح بنوع كل جزء من أجزاء الصفحة.

فمثلًا عندما نستخدم الوسم <h1> فإننا نخبر المتصفح أن النص الموجود بداخله يمثل Heading — عنوان.

4. Meaning of Language — معنى Language

كلمة Language تعني لغة. ولكن HTML ليست لغة برمجة بالمعنى التقليدي، وإنما هي Markup Language — لغة ترميز تستخدم لوصف وتنظيم محتوى صفحة الويب.

5. Is HTML a Programming Language?

هل HTML لغة برمجة؟ الإجابة هي: لا. HTML هي لغة ترميز وليست لغة برمجة، لأنها لا تستخدم لتنفيذ الخوارزميات والعمليات المنطقية مثل لغات البرمجة. وظيفتها الأساسية هي بناء Structure — هيكل صفحة الويب.

6. HTML and Front-End Development

تعتبر HTML واحدة من أهم أساسيات Front-End Development — تطوير الواجهة الأمامية. والـ Front-End هو الجزء من الموقع الذي يراه المستخدم ويتعامل معه مباشرة.

HTML — Structure

تستخدم لبناء هيكل الصفحة وتنظيم محتواها.

CSS — Style

تستخدم لتنسيق الصفحة والتحكم في الألوان والخطوط والأحجام.

JavaScript — Interaction

تستخدم لإضافة التفاعل والحركة والوظائف الديناميكية.

7. What is a Web Page? — ما هي صفحة الويب؟

Web Page — صفحة الويب هي مستند يمكن عرضه باستخدام Web Browser — متصفح الويب مثل Google Chrome أو Microsoft Edge أو Firefox.

8. What is a Website? — ما هو الموقع الإلكتروني؟

Website — موقع الويب هو مجموعة من صفحات الويب المرتبطة ببعضها، ويمكن الوصول إليها من خلال عنوان الموقع URL — Uniform Resource Locator.

9. What is an HTML Tag? — ما هو HTML Tag؟

الـ Tag — الوسم هو جزء من كود HTML يستخدم لتحديد نوع المحتوى الموجود في الصفحة.

<h1>Welcome to HAnova</h1>

في المثال السابق: <h1> هو Opening Tag — وسم الفتح، و</h1> هو Closing Tag — وسم الإغلاق، والنص الموجود بينهما يسمى Content — المحتوى.

10. What is an HTML Element? — ما هو HTML Element؟

HTML Element — عنصر HTML هو العنصر الكامل الذي يتكون عادةً من وسم الفتح والمحتوى ووسم الإغلاق.

<p>Welcome to my website</p>

العنصر السابق يحتوي على وسم الفتح <p> والمحتوى Welcome to my website ووسم الإغلاق </p>.

11. Attributes — الخصائص

Attribute — الخاصية هي معلومات إضافية يتم وضعها داخل Opening Tag لإضافة خصائص أو معلومات للعنصر.

<a href="https://example.com">Visit Website</a>

في المثال السابق تعتبر href خاصية تحدد عنوان الرابط الذي سينتقل إليه المستخدم.

12. Common HTML Tags — أشهر وسوم HTML

  • <h1> — عنوان رئيسي.
  • <h2> — عنوان فرعي.
  • <p> — فقرة نصية.
  • <a> — رابط.
  • <img> — صورة.
  • <br> — الانتقال إلى سطر جديد.
  • <hr> — خط أفقي.

13. First HTML Example — أول مثال HTML

<h1>My First Website</h1>
<p>Welcome to my first webpage.</p>

في المثال السابق قمنا بإنشاء عنوان رئيسي باستخدام h1 ثم أضفنا فقرة باستخدام p.

14. Important Rules — قواعد مهمة

  • يجب كتابة الوسوم بطريقة صحيحة.
  • يجب إغلاق العناصر التي تحتاج إلى Closing Tag.
  • يجب كتابة أسماء الملفات والمسارات بشكل صحيح.
  • يجب وضع قيم الخصائص بين علامات اقتباس.
  • يفضل تنظيم الكود باستخدام المسافات والتنسيق المناسب.

15. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة تحتوي على عنوان رئيسي باستخدام <h1> وفقرة باستخدام <p> ورابط باستخدام <a>. حاول أيضًا تغيير النص الموجود داخل كل عنصر ومشاهدة النتيجة في المتصفح.

Quick Review — مراجعة سريعة

  • HTML = HyperText Markup Language = لغة ترميز النص التشعبي.
  • HTML تستخدم لبناء هيكل صفحات الويب.
  • Tag = وسم.
  • Element = عنصر.
  • Attribute = خاصية.
  • Content = محتوى.
  • Front-End = الواجهة الأمامية.
  • Browser = متصفح الويب.
  • Website = موقع إلكتروني.
  • Web Page = صفحة ويب.

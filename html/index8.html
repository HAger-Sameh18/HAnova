Lesson 6 : Forms and User Input

1. What is a Form? — ما هو النموذج؟

Form — النموذج هو جزء من صفحة الويب يسمح للمستخدم بإدخال البيانات وإرسالها إلى الموقع. تستخدم النماذج في تسجيل الدخول، وإنشاء الحسابات، وإرسال الرسائل، والبحث، والتسجيل في المواقع التعليمية وغيرها من التطبيقات.

2. The <form> Element — عنصر النموذج

يستخدم العنصر <form> لإنشاء النموذج الذي يحتوي على عناصر إدخال البيانات المختلفة.

<form> Form Content </form>

3. Input Element — عنصر إدخال البيانات

العنصر <input> يستخدم لإنشاء حقول إدخال البيانات. ويمكن تغيير نوع الحقل باستخدام الخاصية type.

<input type="text">

4. Text Input — إدخال النص

يستخدم type="text" لإنشاء حقل يسمح للمستخدم بكتابة نص قصير، مثل الاسم أو اسم المستخدم.

<input type="text">

5. Label — تسمية الحقل

عنصر <label> يستخدم لكتابة وصف يوضح للمستخدم البيانات المطلوبة في كل حقل.

<label>Full Name</label> <input type="text">

6. For and ID — ربط التسمية بالحقل

يمكن ربط Label — التسمية بحقل الإدخال باستخدام الخاصية for مع الخاصية id. يجب أن تكون قيمة for مساوية لقيمة id.

<label for="name">Full Name</label> <input type="text" id="name">

7. Placeholder — النص الإرشادي

الخاصية placeholder تعرض نصًا إرشاديًا داخل حقل الإدخال، وتختفي عند بدء المستخدم في الكتابة.

<input type="text" placeholder="Enter your name">

8. Name Attribute — اسم الحقل

الخاصية name تعطي اسمًا للبيانات الموجودة داخل الحقل، وتكون مهمة عند إرسال بيانات النموذج.

<input type="text" name="username">

9. Required — الحقل المطلوب

الخاصية required تجعل إدخال البيانات في الحقل إلزاميًا قبل إرسال النموذج.

<input type="text" required>

10. Password Input — كلمة المرور

يستخدم type="password" لإنشاء حقل مخصص لكلمة المرور، ويقوم المتصفح بإخفاء الأحرف التي يكتبها المستخدم.

<label for="password">Password</label> <input type="password" id="password" name="password">

11. Email Input — البريد الإلكتروني

يستخدم type="email" لإدخال عنوان البريد الإلكتروني. ويساعد المتصفح في التحقق من أن البيانات تبدو كعنوان بريد إلكتروني.

<input type="email" placeholder="Enter your email">

12. Number Input — إدخال الأرقام

يستخدم type="number" لإنشاء حقل مخصص لإدخال الأرقام مثل العمر أو الدرجة.

<label for="age">Age</label> <input type="number" id="age">

13. Date Input — إدخال التاريخ

يستخدم type="date" للسماح للمستخدم باختيار تاريخ.

<label for="date">Birth Date</label> <input type="date" id="date">

14. Radio Button — زر الاختيار

Radio Button — زر الاختيار يستخدم عندما نريد السماح للمستخدم باختيار خيار واحد من مجموعة خيارات. ويجب أن تكون عناصر المجموعة لها نفس قيمة name.

<input type="radio" name="level" value="beginner"> Beginner <input type="radio" name="level" value="advanced"> Advanced

15. Checkbox — مربع الاختيار

Checkbox — مربع الاختيار يستخدم عندما يستطيع المستخدم اختيار أكثر من خيار.

<input type="checkbox" name="skill"> HTML <input type="checkbox" name="skill"> CSS <input type="checkbox" name="skill"> JavaScript

16. Radio Button vs Checkbox — الفرق بينهما

  • Radio Button = اختيار واحد من مجموعة.
  • Checkbox = اختيار واحد أو أكثر.

17. Textarea — مربع النص

يستخدم <textarea> لإدخال نصوص طويلة أو متعددة الأسطر، مثل الرسائل والتعليقات.

<label for="message">Message</label> <textarea id="message" placeholder="Write your message"> </textarea>

18. Select — القائمة المنسدلة

يستخدم العنصر <select> لإنشاء Dropdown List — قائمة منسدلة تسمح للمستخدم باختيار عنصر من مجموعة اختيارات.

<select> <option>HTML</option> <option>CSS</option> <option>JavaScript</option> </select>

19. Option — الاختيار

عنصر <option> يستخدم لإنشاء كل اختيار داخل القائمة المنسدلة.

<select> <option>HTML</option> <option>CSS</option> <option>JavaScript</option> </select>

20. Selected — الاختيار الافتراضي

الخاصية selected تجعل اختيارًا معينًا هو الاختيار المحدد افتراضيًا.

<select> <option>Choose Course</option> <option selected>HTML</option> <option>CSS</option> </select>

21. Submit Button — زر الإرسال

يستخدم زر Submit — إرسال لإرسال البيانات الموجودة داخل النموذج.

<button type="submit"> Submit </button>

22. Reset Button — زر إعادة التعيين

يستخدم Reset — إعادة التعيين لإعادة حقول النموذج إلى حالتها الأصلية.

<button type="reset"> Reset </button>

23. Fieldset and Legend — تجميع الحقول وعنوانها

يستخدم fieldset لتجميع مجموعة من الحقول المرتبطة ببعضها، بينما يستخدم legend لإضافة عنوان لهذه المجموعة.

<fieldset> <legend>Personal Information</legend> <input type="text"> <input type="email"> </fieldset>

24. Action — مكان إرسال البيانات

الخاصية action تحدد المكان الذي سيتم إرسال بيانات النموذج إليه عند الضغط على زر Submit.

<form action="submit.html"> Form Content </form>

25. Method — طريقة إرسال البيانات

الخاصية method تحدد طريقة إرسال بيانات النموذج. ومن أشهر الطرق GET وPOST.

<form action="submit.html" method="post"> Form Content </form>

26. Complete Form Example — مثال كامل

الآن سنجمع العناصر السابقة لإنشاء نموذج تسجيل لطالب في موقع تعليمي.

<form> <fieldset> <legend>Student Registration</legend> <label for="name">Full Name</label> <input type="text" id="name" placeholder="Enter your name" required> <br><br> <label for="email">Email</label> <input type="email" id="email" placeholder="Enter your email" required> <br><br> <label for="password">Password</label> <input type="password" id="password" required> <br><br> <label for="age">Age</label> <input type="number" id="age"> <br><br> <label>Choose your level:</label> <br> <input type="radio" name="level"> Beginner <input type="radio" name="level"> Advanced <br><br> <label>Choose your skills:</label> <br> <input type="checkbox"> HTML <input type="checkbox"> CSS <input type="checkbox"> JavaScript <br><br> <label for="course">Choose a Course:</label> <select id="course"> <option>HTML</option> <option>CSS</option> <option>JavaScript</option> </select> <br><br> <label for="message">Message</label> <br> <textarea id="message" placeholder="Write your message"> </textarea> <br><br> <button type="submit"> Submit </button> <button type="reset"> Reset </button> </fieldset> </form>

27. Common Mistakes — الأخطاء الشائعة

  • نسيان وضع عناصر الإدخال داخل form.
  • نسيان كتابة label لكل حقل.
  • استخدام نفس id لأكثر من عنصر.
  • نسيان ربط label بالحقل باستخدام for وid.
  • نسيان استخدام name عند الحاجة إلى إرسال البيانات.
  • استخدام Radio Buttons بأسماء مختلفة عندما نريد اختيارًا واحدًا.
  • نسيان وضع عناصر option داخل select.
  • استخدام placeholder بدلًا من label.

28. Try It Yourself — جرب بنفسك

أنشئ نموذج تسجيل في موقع تعليمي يحتوي على: اسم الطالب، البريد الإلكتروني، كلمة المرور، العمر، اختيار المستوى باستخدام Radio Buttons، واختيار المهارات باستخدام Checkboxes، واختيار المادة باستخدام قائمة منسدلة، بالإضافة إلى مربع لكتابة رسالة وزري Submit وReset.

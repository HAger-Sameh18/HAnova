Lesson 2 : HTML Structure

1. What is HTML Structure? — ما هو هيكل HTML؟

HTML Structure — هيكل HTML هو الطريقة التي يتم بها ترتيب وتنظيم عناصر صفحة الويب داخل مستند HTML. كل صفحة HTML تحتاج إلى هيكل أساسي يساعد المتصفح على قراءة الكود وفهم محتواه وعرضه بالشكل الصحيح.

2. Basic HTML Structure — الهيكل الأساسي

<!DOCTYPE html>
<html lang="en">

  <head>
    <meta charset="UTF-8">
    <title>HAnova</title>
  </head>

  <body>
    <h1>Welcome</h1>
    <p>My First Website</p>
  </body>

</html>

3. DOCTYPE — تعريف نوع المستند

DOCTYPE هو اختصار لفكرة Document Type Declaration — تعريف نوع المستند. ويستخدم هذا الأمر لإخبار المتصفح بأن المستند مكتوب باستخدام HTML5. وهو ليس عنصرًا عاديًا من عناصر الصفحة.

<!DOCTYPE html>

4. HTML Element — عنصر html

عنصر html هو العنصر الرئيسي الذي يحتوي على جميع عناصر صفحة HTML. أما الخاصية lang فهي اختصار لكلمة Language — اللغة، وتحدد اللغة الأساسية للصفحة.

<html lang="en">

</html>

5. Head — الرأس

عنصر head يحتوي على المعلومات الخاصة بالصفحة والتي يحتاج إليها المتصفح، ولكنها لا تظهر عادةً كمحتوى مباشر داخل الصفحة.

<head>
  ...
</head>

6. Meta Charset — ترميز الأحرف

Character Encoding — ترميز الأحرف يحدد الطريقة التي يتم بها تمثيل الأحرف داخل الصفحة. ويعتبر UTF-8 من أشهر أنواع الترميز، ويدعم عددًا كبيرًا من اللغات ومنها اللغة العربية والإنجليزية.

<meta charset="UTF-8">

7. Viewport — منطقة العرض

هذا السطر مهم لجعل الصفحة مناسبة لمختلف أحجام الشاشات. ويستخدم في تصميم المواقع Responsive Design — التصميم المتجاوب الذي يسمح للموقع بالظهور بصورة مناسبة على الهاتف والكمبيوتر والتابلت.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

8. Title — عنوان الصفحة

Title — العنوان هو النص الذي يظهر في علامة تبويب المتصفح، ويساعد المستخدم على معرفة اسم الصفحة المفتوحة.

<title>My Website</title>

9. Body — جسم الصفحة

Body — جسم الصفحة يحتوي على المحتوى الذي يظهر للمستخدم داخل صفحة الويب، مثل العناوين والفقرات والصور والروابط والقوائم.

<body>
  Website Content
</body>

10. Headings — العناوين

يوجد في HTML ستة مستويات للعناوين تبدأ من h1 وحتى h6. ويعتبر h1 العنوان الأعلى أهمية، بينما h6 هو الأقل.

<h1>Main Heading</h1>
<h2>Second Heading</h2>
<h3>Third Heading</h3>

11. Paragraph — الفقرة

يستخدم عنصر p لإنشاء Paragraph — فقرة. ويمكن أن تحتوي الفقرة على نصوص ومعلومات مختلفة.

<p>This is a paragraph.</p>

12. Line Break — الانتقال لسطر جديد

الوسم br يستخدم للانتقال إلى سطر جديد. وهو من العناصر التي لا تحتاج إلى Closing Tag.

Hello<br>World

13. Horizontal Rule — الخط الأفقي

يستخدم hr لإضافة خط أفقي يساعد على الفصل بين أجزاء مختلفة من محتوى الصفحة.

<hr>

14. Comments — التعليقات

Comment — التعليق هو نص يكتبه المبرمج داخل الكود لإضافة ملاحظات أو توضيحات. ولا يظهر التعليق للمستخدم داخل الصفحة.

<!-- This is a comment -->

15. Complete Example — مثال كامل

<!DOCTYPE html>
<html lang="en">

  <head>
    <meta charset="UTF-8">
    <title>HAnova</title>
  </head>

  <body>
    <h1>Welcome to HAnova</h1>
    <h2>Learn HTML</h2>
    <p>HTML is easy to learn.</p>
    <hr>
    <p>Start learning today!</p>
  </body>

</html>

16. Try It Yourself — جرب بنفسك

أنشئ صفحة HTML جديدة واكتب الهيكل الأساسي كاملًا. بعد ذلك أضف عنوانًا رئيسيًا، عنوانًا فرعيًا، فقرتين، وخطًا أفقيًا. ثم أضف Comment يوضح وظيفة أحد أجزاء الكود.

Quick Review — مراجعة سريعة

  • DOCTYPE = تعريف نوع المستند.
  • html = العنصر الرئيسي للصفحة.
  • head = يحتوي على معلومات الصفحة.
  • title = عنوان الصفحة في المتصفح.
  • body = المحتوى الظاهر للمستخدم.
  • h1 إلى h6 = العناوين.
  • p = الفقرة.
  • br = سطر جديد.
  • hr = خط أفقي.
  • comment = تعليق داخل الكود.

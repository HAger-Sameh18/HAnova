Lesson 8 : Semantic HTML

1. What is Semantic HTML? — ما هو HTML الدلالي؟

Semantic HTML — HTML الدلالي هو استخدام عناصر HTML التي توضح معنى ووظيفة الجزء الموجود داخل صفحة الويب. أي أن اسم العنصر نفسه يساعد المطور والمتصفح على فهم طبيعة المحتوى.

على سبيل المثال، عندما نستخدم <header> فإننا نوضح أن هذا الجزء يمثل رأس الصفحة أو رأس جزء معين منها، بينما <footer> يستخدم للدلالة على تذييل الصفحة أو القسم.

2. Semantic vs Non-Semantic Elements — العناصر الدلالية وغير الدلالية

العناصر الدلالية Semantic Elements تعطي معنى واضحًا للمحتوى، بينما العناصر غير الدلالية Non-Semantic Elements لا توضح معنى المحتوى من اسمها.

من أمثلة العناصر غير الدلالية: <div> و<span>. أما العناصر الدلالية فمن أمثلتها: <header> و<nav> و<main> و<article>.

3. Why Use Semantic HTML? — لماذا نستخدم HTML الدلالي؟

استخدام العناصر الدلالية يجعل كود HTML أكثر وضوحًا وتنظيمًا، ويساعد المطور على معرفة وظيفة كل جزء من الصفحة بسهولة.

كما تساعد العناصر الدلالية التقنيات المساعدة Assistive Technologies — التقنيات المساعدة على فهم بنية الصفحة والتنقل بين أجزائها بصورة أفضل.

4. Header — رأس الصفحة

العنصر <header> يعني Header — رأس الصفحة أو القسم. يستخدم لتمثيل الجزء التمهيدي من الصفحة أو من أحد أقسامها.

يمكن أن يحتوي الـ Header على عنوان الصفحة أو الشعار أو معلومات تمهيدية أو عناصر أخرى مرتبطة ببداية المحتوى.

<header> <h1>HAnova</h1> <p>Learn Web Development</p> </header>

5. Nav — قائمة التنقل

العنصر <nav> يعني Navigation — التنقل. يستخدم لتجميع روابط التنقل الرئيسية في الموقع.

يمكن استخدامه لروابط الانتقال إلى الصفحة الرئيسية أو الدروس أو الأقسام الأساسية في الموقع.

<nav> <a href="index.html">Home</a> <a href="lessons.html">Lessons</a> <a href="contact.html">Contact</a> </nav>

6. Main — المحتوى الرئيسي

العنصر <main> يعني Main Content — المحتوى الرئيسي. ويستخدم لتحديد المحتوى الأساسي في الصفحة.

يجب أن يمثل المحتوى الموجود داخل main الجزء الأساسي الذي تدور حوله الصفحة، مثل محتوى درس تعليمي أو مقال أو صفحة منتج.

<main> <h1>HTML Course</h1> <p>Welcome to our HTML course.</p> </main>

7. Section — القسم

العنصر <section> يعني Section — قسم. يستخدم لتجميع محتوى مرتبط بموضوع أو فكرة معينة داخل الصفحة.

غالبًا يحتوي القسم على عنوان يوضح الموضوع الذي يتحدث عنه.

<section> <h2>HTML Lessons</h2> <p>Learn the basics of HTML.</p> </section>

8. Article — المقال أو المحتوى المستقل

العنصر <article> يعني Article — مقال أو محتوى مستقل. يستخدم للمحتوى الذي يمكن أن يكون له معنى مستقل عن باقي الصفحة.

يمكن استخدامه للمقالات، المنشورات، الأخبار، أو أي محتوى مستقل يمكن قراءته أو استخدامه بشكل منفصل.

<article> <h2>Introduction to HTML</h2> <p>HTML is the foundation of web pages.</p> </article>

9. Aside — المحتوى الجانبي

العنصر <aside> يعني Aside — محتوى جانبي. يستخدم للمحتوى المرتبط بالمحتوى الرئيسي ولكنه ليس جزءًا أساسيًا منه.

يمكن استخدامه للمعلومات الإضافية أو الروابط المرتبطة بالموضوع أو الملاحظات الجانبية.

<aside> <h3>Useful Information</h3> <p>HTML was created for web documents.</p> </aside>

10. Footer — تذييل الصفحة

العنصر <footer> يعني Footer — تذييل الصفحة أو القسم. يستخدم للمعلومات الموجودة في نهاية الصفحة أو القسم.

يمكن أن يحتوي على معلومات حقوق النشر أو معلومات التواصل أو روابط إضافية.

<footer> <p>Copyright 2026 HAnova</p> </footer>

11. Figure — المحتوى المرئي المستقل

العنصر <figure> يستخدم لتمثيل محتوى مستقل مثل صورة أو رسم توضيحي أو مخطط أو مثال يمكن الرجوع إليه بشكل منفصل عن النص الأساسي.

<figure> <img src="HTML.jpeg" alt="HTML Logo"> </figure>

12. Figcaption — وصف المحتوى

العنصر <figcaption> يعني Figure Caption — وصف أو عنوان الشكل. يستخدم لإضافة وصف أو عنوان للمحتوى الموجود داخل <figure>.

<figure> <img src="HTML.jpeg" alt="HTML Logo"> <figcaption> HTML Logo </figcaption> </figure>

13. Details — تفاصيل قابلة للفتح

العنصر <details> يستخدم لإنشاء جزء من المحتوى يمكن للمستخدم فتحه وإخفاؤه.

يعتبر هذا العنصر مفيدًا عند وجود معلومات إضافية لا نريد عرضها بشكل كامل منذ بداية تحميل الصفحة.

<details> <p> HTML stands for HyperText Markup Language. </p> </details>

14. Summary — عنوان التفاصيل

العنصر <summary> يستخدم كعنوان أو وصف للجزء القابل للفتح داخل <details>.

<details> <summary> What is HTML? </summary> <p> HTML is the standard markup language for web pages. </p> </details>

15. Complete Semantic Structure — هيكل دلالي كامل

يمكن دمج العناصر الدلالية السابقة لإنشاء هيكل واضح ومنظم لصفحة ويب تعليمية.

<header> <h1>HAnova</h1> </header>
<nav> <a href="index.html">Home</a> <a href="lessons.html">Lessons</a> </nav>
<main> <section> <h2>HTML Course</h2> <p> Learn HTML step by step. </p> </section>
<article> <h2>Lesson 8</h2> <p> Learn Semantic HTML. </p> </article>
<aside> <p> Additional Information </p> </aside> </main>
<footer> <p> Copyright 2026 HAnova </p> </footer>

16. Semantic HTML and Accessibility — HTML الدلالي وإمكانية الوصول

Accessibility — إمكانية الوصول تعني تصميم صفحات يمكن لمختلف المستخدمين الوصول إلى محتواها وفهمه، بما في ذلك المستخدمون الذين يعتمدون على التقنيات المساعدة.

استخدام العناصر الدلالية يساعد في توضيح بنية الصفحة، مما يجعل فهم أجزاء الموقع أسهل بالنسبة للمستخدمين والتقنيات المساعدة.

17. Div vs Semantic Elements — الفرق بين div والعناصر الدلالية

العنصر <div> عنصر غير دلالي يستخدم كحاوية عامة لتجميع العناصر، ولكنه لا يخبرنا من اسمه عن طبيعة المحتوى.

أما العناصر مثل header وmain وsection وarticle فهي توضح معنى الجزء الذي تحتويه.

<div> <h2>HTML Course</h2> </div>

في المثال السابق لا نعرف من اسم div وظيفة المحتوى. بينما يمكن استخدام section إذا كان هذا المحتوى يمثل قسمًا واضحًا من الصفحة.

18. Semantic HTML Best Practices — أفضل الممارسات

  • استخدام العنصر الدلالي المناسب لمعنى المحتوى.
  • استخدام main للمحتوى الرئيسي للصفحة.
  • استخدام nav لمجموعة روابط التنقل الرئيسية.
  • استخدام article للمحتوى المستقل.
  • استخدام section لتقسيم المحتوى المرتبط بموضوع معين.
  • استخدام header وfooter في الأماكن المناسبة.
  • عدم استخدام العناصر الدلالية لمجرد استخدامها؛ يجب أن يكون العنصر مناسبًا لمعنى المحتوى.

19. Common Mistakes — الأخطاء الشائعة

  • استخدام div لكل أجزاء الصفحة دون التفكير في المعنى الدلالي للمحتوى.
  • استخدام main أكثر من مرة في الصفحة نفسها بطريقة غير صحيحة.
  • استخدام nav لأي مجموعة صغيرة من الروابط حتى لو لم تكن روابط تنقل رئيسية.
  • الخلط بين section وarticle.
  • استخدام العناصر الدلالية بطريقة لا تتناسب مع محتواها.

20. Try It Yourself — جرب بنفسك

أنشئ صفحة تعليمية بسيطة باستخدام العناصر الدلالية. اجعل الصفحة تحتوي على: header لعنوان الموقع، وnav لروابط التنقل، وmain للمحتوى الأساسي، وsection لقسم الدروس، وarticle لشرح درس، وaside لمعلومة إضافية، وfooter في نهاية الصفحة.

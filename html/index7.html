Lesson 5 : HTML Lists

1. What is a List? — ما هي القائمة؟

List — القائمة هي طريقة لتنظيم مجموعة من المعلومات أو العناصر بطريقة مرتبة وسهلة القراءة. وتستخدم القوائم في صفحات الويب لعرض الخطوات، أو الأدوات، أو المنتجات، أو الموضوعات، أو أي مجموعة من العناصر المرتبطة ببعضها.

تستخدم HTML ثلاثة أنواع رئيسية من القوائم: Unordered List، وOrdered List، وDescription List.

2. Types of Lists — أنواع القوائم

  • Unordered List — القائمة غير المرتبة
    تستخدم عندما لا يكون ترتيب العناصر مهمًا.
  • Ordered List — القائمة المرتبة
    تستخدم عندما يكون ترتيب العناصر مهمًا.
  • Description List — قائمة الوصف
    تستخدم لعرض مصطلحات مع وصف أو شرح لكل مصطلح.

3. Unordered List — القائمة غير المرتبة

العنصر <ul> هو اختصار لـ Unordered List، أي القائمة غير المرتبة. وتظهر عناصرها عادةً على شكل نقاط.

<ul>   <li>HTML</li>   <li>CSS</li>   <li>JavaScript</li> </ul>

العنصر <li> هو اختصار لـ List Item — عنصر في القائمة، ويستخدم لكتابة كل عنصر من عناصر القائمة.

4. List Item — عنصر القائمة

لا نكتب العناصر مباشرة داخل <ul> أو <ol>، وإنما نضع كل عنصر داخل <li>.

<ul>   <li>First Item</li>   <li>Second Item</li>   <li>Third Item</li> </ul>

5. Ordered List — القائمة المرتبة

العنصر <ol> هو اختصار لـ Ordered List — القائمة المرتبة. ويستخدم عندما يكون ترتيب العناصر مهمًا. وتظهر العناصر افتراضيًا بأرقام.

<ol>   <li>Open HTML file</li>   <li>Write the code</li>   <li>Save the file</li>   <li>Open it in the browser</li> </ol>

في المثال السابق تم استخدام القائمة المرتبة لعرض خطوات بالترتيب، لأن ترتيب الخطوات مهم.

6. Unordered vs Ordered List

الفرق الأساسي بين النوعين هو أن Unordered List تستخدم عندما لا يكون هناك ترتيب ضروري للعناصر، بينما Ordered List تستخدم عندما يكون ترتيب العناصر مهمًا.

<!-- Unordered List --> <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> <!-- Ordered List --> <ol> <li>Step One</li> <li>Step Two</li> <li>Step Three</li> </ol>

7. Ordered List Types — أنواع الترقيم

يمكن تغيير شكل الترقيم في القائمة المرتبة باستخدام الخاصية type.

يمكن أن تكون القيم:

  • 1 — أرقام.
  • A — حروف إنجليزية كبيرة.
  • a — حروف إنجليزية صغيرة.
  • I — أرقام رومانية كبيرة.
  • i — أرقام رومانية صغيرة.
<ol type="A"> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ol>

8. Start Attribute — تحديد بداية الترقيم

يمكن استخدام الخاصية start لتحديد الرقم الذي تبدأ منه القائمة المرتبة.

<ol start="5"> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ol>

في المثال السابق ستبدأ القائمة من الرقم 5 بدلًا من الرقم 1.

9. Reversed List — القائمة المعكوسة

يمكن استخدام الخاصية reversed لجعل القائمة المرتبة تبدأ من الرقم الأكبر ثم تنخفض تدريجيًا.

<ol reversed> <li>Third</li> <li>Second</li> <li>First</li> </ol>

10. Nested Lists — القوائم المتداخلة

Nested List — القائمة المتداخلة هي قائمة يتم وضعها داخل عنصر من عناصر قائمة أخرى. وتستخدم عندما نريد تقسيم المعلومات إلى أقسام رئيسية وفرعية.

<ul> <li>Front-End Development <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> </li> <li>Back-End Development</li> </ul>

11. Description List — قائمة الوصف

العنصر <dl> هو اختصار لـ Description List — قائمة الوصف. وتستخدم لعرض مصطلحات مع تعريف أو وصف لكل مصطلح.

وتتكون من عنصرين أساسيين:

  • <dt> = Description Term — المصطلح
  • <dd> = Description Details — وصف المصطلح
<dl> <dt>HTML</dt> <dd> HTML is used to create the structure of web pages. </dd> <dt>CSS</dt> <dd> CSS is used to style web pages. </dd> </dl>

12. Lists in Web Development — استخدام القوائم في المواقع

القوائم من أكثر العناصر استخدامًا في مواقع الويب. فيمكن استخدامها لإنشاء قائمة التنقل Navigation Menu، أو قائمة الخدمات، أو قائمة المنتجات، أو خطوات تنفيذ مهمة، أو قائمة بالمميزات.

على سبيل المثال، يمكن إنشاء قائمة لمحتويات موقع تعليمي:

<ul> <li>HTML Lessons</li> <li>CSS Lessons</li> <li>JavaScript Lessons</li> <li>Projects</li> </ul>

13. List With Links — قائمة تحتوي على روابط

يمكن وضع الروابط داخل عناصر القائمة لإنشاء قوائم تنقل في صفحات المواقع.

<ul> <li> <a href="index.html">Home</a> </li> <li> <a href="about.html">About</a> </li> <li> <a href="contact.html">Contact</a> </li> </ul>

14. Combining Different Lists — دمج أنواع القوائم

يمكن الجمع بين القوائم المرتبة وغير المرتبة لإنشاء هيكل أكثر تنظيمًا.

<ol> <li>Learn HTML <ul> <li>Headings</li> <li>Paragraphs</li> <li>Images</li> <li>Tables</li> </ul> </li> <li>Learn CSS</li> <li>Learn JavaScript</li> </ol>

15. Common Mistakes — الأخطاء الشائعة

  • نسيان وضع عناصر القائمة داخل <li>.
  • استخدام <ol> عندما لا يكون ترتيب العناصر مهمًا.
  • استخدام <ul> عندما يكون ترتيب الخطوات ضروريًا.
  • وضع القائمة المتداخلة خارج عنصر <li> بدلًا من وضعها داخله.
  • نسيان إغلاق عناصر القائمة.
  • استخدام القوائم بطريقة غير منظمة مما يجعل الكود صعب القراءة.

16. Try It Yourself — جرب بنفسك

أنشئ قائمة غير مرتبة تحتوي على لغات وتقنيات تطوير الويب: HTML وCSS وJavaScript. ثم أنشئ قائمة مرتبة تحتوي على خطوات إنشاء صفحة HTML. بعد ذلك حاول إنشاء قائمة متداخلة تحتوي على Front-End وتحتها HTML وCSS وJavaScript.

Quick Review — مراجعة سريعة

  • List = قائمة.
  • Unordered List = قائمة غير مرتبة.
  • Ordered List = قائمة مرتبة.
  • Description List = قائمة وصف.
  • ul = Unordered List.
  • ol = Ordered List.
  • li = List Item.
  • dl = Description List.
  • dt = Description Term.
  • dd = Description Details.
  • Nested List = قائمة متداخلة.
  • type = تحديد نوع الترقيم.
  • start = تحديد بداية الترقيم.
  • reversed = عكس ترتيب القائمة.

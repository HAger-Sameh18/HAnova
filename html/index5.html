Lesson 3 : Links And Images

1. What is a Link? — ما هو الرابط؟

Link — الرابط هو عنصر يسمح للمستخدم بالانتقال من صفحة إلى صفحة أخرى أو الانتقال إلى موقع آخر أو جزء مختلف من نفس الصفحة. وتعتبر الروابط من أهم عناصر مواقع الويب لأنها تربط صفحات الموقع ببعضها.

2. Anchor Element — عنصر الرابط

يستخدم العنصر a لإنشاء رابط، وهو اختصار لكلمة Anchor — مرساة. أما href فهي اختصار لفكرة Hypertext Reference — مرجع النص التشعبي وتحدد المكان الذي سينتقل إليه المستخدم.

<a href="https://www.google.com"> Visit Google </a>

3. Link Text — نص الرابط

النص الموجود بين وسم الفتح ووسم الإغلاق هو Link Text — نص الرابط. وهو النص الذي يراه المستخدم ويمكنه الضغط عليه.

<a href="lesson1.html"> Introduction To HTML </a>

4. External Link — رابط خارجي

External Link — الرابط الخارجي هو رابط ينقل المستخدم إلى موقع مختلف عن الموقع الحالي.

<a href="https://www.google.com"> Google </a>

5. Internal Link — رابط داخلي

Internal Link — الرابط الداخلي يستخدم للانتقال بين صفحات الموقع نفسه. وهذا النوع مهم جدًا في موقعنا لأنه يسمح للمستخدم بالتنقل بين الدروس.

<a href="lesson2.html"> HTML Structure </a>

6. Target Attribute — خاصية الهدف

الخاصية target تحدد المكان الذي سيتم فيه فتح الرابط. وعندما نستخدم القيمة _blank يتم فتح الرابط في علامة تبويب جديدة.

<a href="https://example.com" target="_blank"> Visit Website </a>

7. Email Link — رابط البريد الإلكتروني

يمكن إنشاء رابط لفتح تطبيق البريد الإلكتروني باستخدام mailto:. وعند الضغط عليه يستطيع المستخدم كتابة رسالة بريد إلكتروني.

<a href="mailto:example@gmail.com"> Send Email </a>

8. What is an Image? — ما هي الصورة؟

Image — الصورة هي عنصر مرئي يمكن إضافته إلى صفحة الويب لتوضيح المعلومات أو جعل الصفحة أكثر جاذبية.

9. Image Element — عنصر الصورة

نستخدم العنصر img لإضافة صورة إلى الصفحة. وهو عنصر لا يحتاج إلى Closing Tag.

<img src="image.jpg" alt="Beautiful Image">

10. src Attribute — خاصية مصدر الصورة

src اختصار لـ Source — المصدر. وتستخدم لتحديد مكان الصورة أو اسم ملف الصورة الذي نريد عرضه.

<img src="HTML.jpeg">

11. alt Attribute — النص البديل

alt اختصار لـ Alternative Text — النص البديل. وهو وصف مختصر لمحتوى الصورة. إذا لم يتم تحميل الصورة يستطيع المستخدم معرفة محتواها من النص البديل. كما يساعد أدوات قراءة الشاشة على فهم الصور.

<img src="HTML.jpeg" alt="HTML Logo">

12. Image Width and Height — عرض وارتفاع الصورة

يمكن تحديد أبعاد الصورة باستخدام width — العرض وheight — الارتفاع.

<img src="image.jpg" width="300" height="200" alt="Landscape">

13. Relative Path — المسار النسبي

Relative Path — المسار النسبي يستخدم للوصول إلى ملف موجود داخل ملفات المشروع. في المثال السابق توجد الصورة داخل مجلد يسمى images.

<img src="images/photo.jpg" alt="Photo">

14. Images Folder — مجلد الصور

من الأفضل تنظيم ملفات الموقع داخل مجلدات حتى يكون المشروع مرتبًا وسهل التعامل معه. يمكن إنشاء مجلد باسم images ووضع جميع الصور بداخله.

على سبيل المثال، إذا كان شكل المشروع كالتالي:

My Website
│ ├── index.html
├── lesson3.html
├── lesson.css
│ └── images
    ├── HTML.jpeg
    ├── CSS.jpeg
    └── JS.jpeg

فإننا نستخدم المسار النسبي للوصول إلى الصورة الموجودة داخل مجلد images.

<img src="images/HTML.jpeg" alt="HTML Logo">

كلمة images تعني اسم المجلد، وبعدها نكتب اسم الصورة وامتدادها. لذلك يجب أن يكون اسم الملف المكتوب في الكود مطابقًا لاسم الملف الحقيقي.

15. Absolute URL — العنوان الكامل

يمكن استخدام عنوان كامل للصورة يسمى Absolute URL — عنوان URL كامل للوصول إلى صورة موجودة على الإنترنت.

<img src="https://example.com/photo.jpg" alt="Photo">

16. Image as a Link — جعل الصورة رابطًا

يمكن وضع عنصر الصورة داخل عنصر الرابط. وبذلك تصبح الصورة قابلة للضغط، وعند الضغط عليها ينتقل المستخدم إلى الصفحة المحددة في href.

<a href="index.html">
  <img src="home.jpg" alt="Home">
</a>

17. Common Image Formats — أشهر صيغ الصور

  • JPG / JPEG — مناسبة للصور الفوتوغرافية.
  • PNG — تدعم الخلفية الشفافة.
  • GIF — يمكن استخدامها للصور المتحركة البسيطة.
  • SVG — مناسبة للرسومات والشعارات المتجهة.
  • WebP — صيغة حديثة تساعد على تقليل حجم الصور.

18. Common Mistakes — الأخطاء الشائعة

  • نسيان كتابة href في الرابط.
  • كتابة عنوان URL بطريقة خاطئة.
  • نسيان src في عنصر الصورة.
  • كتابة اسم ملف الصورة بطريقة مختلفة عن اسم الملف الحقيقي.
  • نسيان alt.
  • وضع الصورة في مجلد مختلف عن المسار المكتوب في الكود.

20. Try It Yourself — جرب بنفسك

أنشئ صفحة تحتوي على عنوان وفقرة وصورة. بعد ذلك أضف رابطًا داخليًا ينقلك إلى صفحة أخرى داخل موقعك، ثم أضف رابطًا خارجيًا يفتح موقعًا آخر في علامة تبويب جديدة. حاول أيضًا جعل الصورة نفسها رابطًا قابلًا للضغط.

Quick Review — مراجعة سريعة

  • Link = رابط.
  • Anchor = عنصر الرابط.
  • href = عنوان الرابط.
  • target = تحديد مكان فتح الرابط.
  • Image = صورة.
  • src = مصدر الصورة.
  • alt = النص البديل.
  • width = العرض.
  • height = الارتفاع.
  • Internal Link = رابط داخلي.
  • External Link = رابط خارجي.
  • URL = عنوان المورد على الإنترنت.

Lesson 9 : HTML Entities and Special Characters

1. What are HTML Entities? — ما هي كيانات HTML؟

HTML Entities — كيانات HTML هي طريقة تستخدم لكتابة بعض الرموز والحروف الخاصة داخل صفحة الويب بطريقة يفهمها المتصفح. بعض الرموز لا يمكن كتابتها بشكل مباشر داخل HTML لأنها قد تتعارض مع طريقة كتابة الكود أو يكون لها معنى خاص داخل HTML.

لذلك توفر HTML طريقة خاصة لتمثيل هذه الرموز باستخدام صيغة تبدأ غالبًا بالرمز & وتنتهي بالرمز ;.

2. Why Do We Need Entities? — لماذا نحتاج إلى Entities؟

بعض الرموز تستخدم أصلًا في كتابة HTML نفسها، لذلك إذا أردنا عرضها كنص على الصفحة يجب استخدام الكيان الخاص بها.

على سبيل المثال، الرمزان < و > يستخدمان في إنشاء HTML Tags. لذلك إذا أردنا عرضهما للمستخدم كرموز عادية نستخدم HTML Entities.

3. Entity Syntax — طريقة كتابة الكيان

الصيغة الأساسية لكيان HTML تكون عبارة عن علامة & ثم اسم الكيان أو رقمه، وبعد ذلك ;.

&entity_name;

يمكن أن تكون بعض الكيانات عبارة عن اسم معروف، ويمكن أيضًا استخدام رقم خاص يسمى Numeric Character Reference.

4. Less Than — رمز أصغر من

الرمز < يسمى Less Than — أصغر من. وهو يستخدم في HTML لبدء العناصر.

إذا أردنا عرضه على الصفحة كرمز عادي نستخدم:

&lt;

وسيظهر للمستخدم بالشكل: <

5. Greater Than — رمز أكبر من

الرمز > يسمى Greater Than — أكبر من. ويستخدم مع الرمز السابق في كتابة HTML Tags.

&gt;

وسيظهر: >

6. Ampersand — علامة &

الرمز & يسمى Ampersand — علامة العطف. وهو أيضًا الرمز الذي تبدأ به معظم HTML Entities.

لعرض علامة & نفسها داخل الصفحة يمكن استخدام:

&amp;

7. Non-Breaking Space — المسافة غير القابلة للكسر

الكيان &nbsp; يعني Non-Breaking Space — مسافة غير قابلة للكسر. ويستخدم لإضافة مسافة لا يريد المتصفح فصلها أو حذفها عند معالجة النص.

Hello&nbsp;World

ويمكن استخدامه عند الحاجة إلى وجود مسافة خاصة داخل النص.

8. Copyright — رمز حقوق النشر

رمز Copyright — حقوق النشر هو: ©.

ويمكن كتابته باستخدام:

&copy;

مثال:

HAnova &copy; 2026

9. Registered Trademark — العلامة التجارية المسجلة

الرمز ® يسمى Registered Trademark — علامة تجارية مسجلة.

&reg;

يستخدم هذا الرمز للدلالة على علامة تجارية مسجلة.

10. Trademark — العلامة التجارية

الرمز ™ يسمى Trademark — علامة تجارية.

&trade;

11. Quotation Mark — علامات الاقتباس

يمكن استخدام Entities لعرض علامات الاقتباس بطريقة واضحة داخل HTML.

&quot;

ويظهر الرمز: "

12. Apostrophe — علامة الاقتباس المفردة

الرمز ' يسمى Apostrophe — علامة الاقتباس المفردة.

&apos;

13. Currency Symbols — رموز العملات

يمكن أيضًا استخدام بعض Entities لعرض رموز العملات المختلفة.

  • &dollar; = $ — الدولار.
  • &euro; = € — اليورو.
  • &pound; = £ — الجنيه الإسترليني.
  • &yen; = ¥ — الين.
Price: &dollar;100
Price: &euro;80

14. Mathematical Symbols — الرموز الرياضية

توفر HTML أيضًا Entities لبعض الرموز الرياضية التي يمكن استخدامها داخل النصوص.

  • &plusmn; = ±
  • &times; = ×
  • &divide; = ÷
  • &ne; = ≠
  • &le; = ≤
  • &ge; = ≥
10 &times; 5 = 50
20 &divide; 4 = 5
5 &lt; 10

15. Arrows — الأسهم

يمكن استخدام Entities لعرض بعض الأسهم داخل صفحات HTML.

  • &larr; = ←
  • &rarr; = →
  • &uarr; = ↑
  • &darr; = ↓
Home &rarr; HTML &rarr; Lesson 9

16. Currency and Special Symbols Example — مثال على الرموز

يمكن استخدام أكثر من Entity داخل نفس النص.

HAnova &copy; 2026
Price: &dollar;50
10 &times; 5 = 50
5 &lt; 10

17. HTML Tags as Text — عرض Tags كالنص

من أهم استخدامات Entities في HTML هو شرح أكواد HTML نفسها. فإذا أردنا أن نعرض Tag مثل <p> داخل الصفحة بدلًا من أن يقوم المتصفح بتنفيذه، نستخدم Entities.

&lt;p&gt;

وسيظهر للمستخدم: <p>

18. Example of Explaining HTML Code — مثال لشرح كود HTML

عند إنشاء موقع تعليمي مثل HAnova نحتاج إلى عرض الأكواد للطلاب حتى يستطيعوا قراءتها وفهمها. لذلك لا يمكن كتابة بعض Tags بشكل مباشر داخل الصفحة، لأن المتصفح قد يحاول تفسيرها كعناصر HTML.

&lt;h1&gt;Hello World&lt;/h1&gt;

سيظهر الكود للطالب كما هو:

<h1>Hello World</h1>

19. Named Entities vs Numeric Entities — الكيانات الاسمية والرقمية

يمكن تمثيل بعض الرموز بطريقتين: Named Entity — كيان اسمي أو Numeric Character Reference — مرجع حرفي رقمي.

الكيان الاسمي يستخدم اسمًا معروفًا للرمز، بينما الطريقة الرقمية تستخدم رقمًا خاصًا يمثل الحرف أو الرمز.

&copy;
&#169;

الطريقتان تستخدمان لتمثيل رمز حقوق النشر.

20. Unicode — يونيكود

Unicode — يونيكود هو معيار عالمي يستخدم لتمثيل الحروف والرموز من لغات مختلفة بطريقة موحدة يمكن للأجهزة والبرامج التعامل معها.

بفضل Unicode يمكن لصفحات الويب التعامل مع اللغة العربية والإنجليزية والعديد من اللغات والرموز المختلفة.

ولهذا نستخدم في بداية صفحة HTML:

<meta charset="UTF-8">

حيث UTF-8 هو ترميز شائع يسمح للصفحة بعرض مجموعة كبيرة جدًا من الحروف والرموز.

21. Emoji — الرموز التعبيرية

يمكن لصفحات HTML عرض الرموز التعبيرية Emoji — الرموز التعبيرية باستخدام Unicode.

&#128512;

ويمكن استخدام الرموز التعبيرية لإضافة عناصر بصرية بسيطة إلى النصوص، بشرط استخدامها بطريقة مناسبة لمحتوى الموقع.

22. Common HTML Entities — أشهر HTML Entities

  • &lt; = <
  • &gt; = >
  • &amp; = &
  • &nbsp; = مسافة غير قابلة للكسر.
  • &quot; = "
  • &apos; = '
  • &copy; = ©
  • &reg; = ®
  • &trade; = ™
  • &euro; = €
  • &pound; = £
  • &yen; = ¥
  • &times; = ×
  • &divide; = ÷

23. Complete Example — مثال كامل

المثال التالي يجمع مجموعة من Entities داخل صفحة HTML.

<h1>HAnova &copy; 2026</h1>

<p>
HTML uses &lt; and &gt; to write special symbols.
</p>

<p> Price: &dollar;100
10 &times; 5 = 50
</p>

24. Common Mistakes — الأخطاء الشائعة

  • كتابة الرمز الخاص مباشرة عندما يكون له معنى داخل HTML.
  • نسيان وضع & في بداية Entity.
  • نسيان وضع ; في نهاية Entity.
  • كتابة اسم Entity بطريقة خاطئة.
  • عدم استخدام UTF-8 عند الحاجة إلى دعم الحروف والرموز المختلفة.
  • استخدام Entities بدون الحاجة إليها في كل النصوص.

25. When Should We Use HTML Entities? — متى نستخدمها؟

نستخدم HTML Entities عندما نحتاج إلى عرض رمز له معنى خاص داخل HTML، أو عندما نريد كتابة رمز بطريقة موحدة يمكن للمتصفح تفسيرها بشكل صحيح.

وهي مفيدة بشكل خاص في المواقع التعليمية التي تشرح البرمجة، لأننا نحتاج إلى عرض Tags وأجزاء من الأكواد داخل الصفحة دون أن يقوم المتصفح بتفسيرها كعناصر HTML.

26. Try It Yourself — جرب بنفسك

أنشئ صفحة HTML بسيطة تحتوي على عنوان باسم موقعك. أضف فقرة تعرض الرموز < و> و&. ثم أضف رمز حقوق النشر ورمز العملة ورمزًا رياضيًا. حاول أيضًا كتابة Tag مثل <h1> داخل الصفحة بحيث يظهر كنص وليس كعنصر HTML.

  • Special Character = حرف أو رمز خاص.
  • &lt; = رمز أصغر من.
  • &gt; = رمز أكبر من.
  • &amp; = علامة &.
  • &nbsp; = مسافة غير قابلة للكسر.
  • &copy; = حقوق النشر.
  • &reg; = علامة تجارية مسجلة.
  • &trade; = علامة تجارية.
  • Unicode = معيار لتمثيل الحروف والرموز.
  • UTF-8 = ترميز يدعم مجموعة كبيرة من الحروف والرموز.

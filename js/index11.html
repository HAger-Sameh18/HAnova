Lesson 9 : DOM and HTML Manipulation

1. What is the DOM? — ما هو DOM؟

DOM هي اختصار للمصطلح Document Object Model أي نموذج كائن المستند.

الـ DOM هو الطريقة التي يستخدمها المتصفح لتمثيل صفحة HTML على شكل مجموعة من العناصر والكائنات التي يمكن لـ JavaScript الوصول إليها والتعامل معها.

باستخدام DOM يمكننا تغيير محتوى الصفحة، وتغيير خصائص العناصر، وإضافة عناصر جديدة أو حذف عناصر موجودة، والتعامل مع الأحداث.

2. HTML and DOM — العلاقة بين HTML و DOM

عندما يقوم المتصفح بتحميل صفحة HTML فإنه يقوم بإنشاء DOM Tree — شجرة DOM تمثل عناصر الصفحة وعلاقتها ببعضها.

<html> <body> <h1>Welcome</h1> <p>Hello</p> </body> </html>

يقوم المتصفح بتمثيل العناصر السابقة داخل DOM بحيث تستطيع JavaScript الوصول إليها والتعامل معها.

3. document Object — كائن document

يوفر JavaScript كائنًا يسمى document يمثل صفحة HTML الحالية.

من خلال document يمكننا الوصول إلى عناصر الصفحة وتعديلها.

console.log(document);

4. Selecting Elements — تحديد العناصر

يمكننا استخدام JavaScript لتحديد عناصر HTML الموجودة داخل الصفحة حتى نستطيع التعامل معها.

توجد عدة طرق لتحديد العناصر، ومن أهمها: getElementById()، getElementsByClassName()، getElementsByTagName()، وquerySelector().

5. getElementById() — تحديد عنصر باستخدام ID

تستخدم getElementById() للوصول إلى عنصر HTML باستخدام قيمة id.

<h1 id="title">Welcome</h1> <script> let title = document.getElementById("title"); console.log(title); </script>

في المثال السابق تم تحديد العنصر الذي يحمل id="title".

6. getElementsByClassName() — تحديد العناصر باستخدام Class

تستخدم getElementsByClassName() للوصول إلى العناصر التي تحمل Class معين.

<p class="text">First Paragraph</p> <p class="text">Second Paragraph</p> <script> let paragraphs = document.getElementsByClassName("text"); console.log(paragraphs); </script>

يمكن أن تعيد هذه الطريقة مجموعة من العناصر التي تحمل نفس الـ Class.

7. getElementsByTagName() — تحديد العناصر باستخدام Tag

تستخدم getElementsByTagName() للوصول إلى جميع العناصر التي تحمل اسم Tag معين.

let paragraphs = document.getElementsByTagName("p"); console.log(paragraphs);

في المثال السابق يتم تحديد جميع عناصر <p> الموجودة في الصفحة.

8. querySelector() — تحديد أول عنصر

تستخدم querySelector() لتحديد أول عنصر يطابق الـ CSS Selector الذي نكتبه.

let title = document.querySelector("#title"); console.log(title);

يمكن استخدامها مع ID أو Class أو اسم عنصر HTML.

document.querySelector("#title"); document.querySelector(".text"); document.querySelector("p");

9. querySelectorAll() — تحديد جميع العناصر

تستخدم querySelectorAll() لتحديد جميع العناصر التي تطابق الـ Selector المحدد.

let paragraphs = document.querySelectorAll("p"); console.log(paragraphs);

سيتم تحديد جميع عناصر <p> الموجودة في الصفحة.

10. Changing HTML Content — تغيير محتوى HTML

يمكن تغيير محتوى عنصر HTML باستخدام الخاصية innerHTML.

<h1 id="title">Hello</h1> <script> let title = document.getElementById("title"); title.innerHTML = "Welcome to JavaScript"; </script>

سيتم استبدال محتوى العنوان بالنص الجديد.

11. textContent — تغيير النص

تستخدم الخاصية textContent للوصول إلى النص الموجود داخل العنصر أو تغييره.

let title = document.getElementById("title"); title.textContent = "Hello JavaScript";

12. innerHTML vs textContent — الفرق بينهما

يمكن استخدام innerHTML لإضافة HTML داخل العنصر، بينما textContent تتعامل مع المحتوى كنص.

title.innerHTML = "<strong>Hello</strong>";

في المثال السابق يتم تفسير <strong> كعنصر HTML.

title.textContent = "<strong>Hello</strong>";

هنا يتم التعامل مع العلامات كنص وليس كعنصر HTML.

13. Changing Styles — تغيير تنسيق العنصر

يمكن تغيير تنسيق عنصر HTML باستخدام الخاصية style.

let title = document.getElementById("title"); title.style.color = "blue"; title.style.fontSize = "30px";

سيتم تغيير لون العنوان وحجم الخط باستخدام JavaScript.

14. Changing Background — تغيير الخلفية

يمكن تغيير لون خلفية العنصر باستخدام backgroundColor.

let box = document.getElementById("box"); box.style.backgroundColor = "purple";

15. Changing Attributes — تغيير خصائص العناصر

يمكن استخدام JavaScript لتغيير خصائص HTML مثل src وhref وalt.

let image = document.getElementById("photo"); image.src = "new-image.jpg";

في المثال السابق تم تغيير مصدر الصورة باستخدام src.

16. getAttribute() — الحصول على Attribute

تستخدم getAttribute() للحصول على قيمة Attribute موجودة في عنصر HTML.

let link = document.getElementById("link"); console.log(link.getAttribute("href"));

17. setAttribute() — إضافة أو تغيير Attribute

تستخدم setAttribute() لإضافة Attribute أو تغيير قيمته.

let link = document.getElementById("link"); link.setAttribute("href", "https://example.com");

18. classList — التعامل مع Classes

توفر الخاصية classList مجموعة من الأدوات للتعامل مع Classes الخاصة بعنصر HTML.

let box = document.getElementById("box"); console.log(box.classList);

19. classList.add() — إضافة Class

تستخدم classList.add() لإضافة Class إلى عنصر.

let box = document.getElementById("box"); box.classList.add("active");

20. classList.remove() — حذف Class

تستخدم classList.remove() لحذف Class من العنصر.

let box = document.getElementById("box"); box.classList.remove("active");

21. classList.toggle() — تبديل Class

تستخدم classList.toggle() لإضافة Class إذا لم يكن موجودًا أو حذفه إذا كان موجودًا.

let box = document.getElementById("box"); box.classList.toggle("active");

22. Creating Elements — إنشاء عناصر جديدة

يمكن إنشاء عنصر HTML جديد باستخدام createElement().

let paragraph = document.createElement("p"); paragraph.textContent = "New Paragraph";

في المثال السابق تم إنشاء عنصر <p> جديد باستخدام JavaScript.

23. appendChild() — إضافة عنصر

تستخدم appendChild() لإضافة عنصر جديد داخل عنصر آخر.

let paragraph = document.createElement("p"); paragraph.textContent = "Hello"; document.body.appendChild(paragraph);

سيتم إضافة الفقرة الجديدة إلى نهاية body.

24. remove() — حذف عنصر

يمكن حذف عنصر من الصفحة باستخدام remove().

let paragraph = document.getElementById("text"); paragraph.remove();

سيتم حذف العنصر من الصفحة.

25. Changing Form Values — تغيير قيم النماذج

يمكن استخدام JavaScript للوصول إلى قيم عناصر النماذج Forms وتغييرها.

<input id="name" type="text"> <script> let input = document.getElementById("name"); input.value = "Hager"; </script>

سيتم وضع النص Hager داخل مربع الإدخال.

26. DOM Navigation — التنقل داخل DOM

يمكن التنقل بين العناصر الموجودة داخل DOM باستخدام خصائص مثل: parentElement، children، وnextElementSibling.

let element = document.getElementById("title"); console.log(element.parentElement);

يقوم parentElement بالوصول إلى العنصر الأب للعنصر الحالي.

27. DOM and JavaScript — العلاقة بين DOM و JavaScript

باستخدام JavaScript وDOM يمكننا إنشاء صفحات ويب تفاعلية تتغير أثناء تشغيل الصفحة دون الحاجة إلى إعادة تحميلها بالكامل.

HTML — Structure

HTML تنشئ هيكل ومحتوى الصفحة.

CSS — Style

CSS تتحكم في شكل وتنسيق الصفحة.

JavaScript + DOM — Interaction

JavaScript باستخدام DOM تتحكم في محتوى وعناصر الصفحة وتجعلها تفاعلية.

28. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة HTML تحتوي على عنوان وفقرة وزر. أعطِ كل عنصر ID مناسبًا.

ثم استخدم JavaScript لتحديد العناصر وتغيير نص العنوان، وتغيير لون الفقرة، وتغيير لون خلفية الصفحة.

حاول أيضًا إنشاء عنصر جديد باستخدام createElement() وإضافته إلى الصفحة باستخدام appendChild().

  • querySelectorAll() = تحديد جميع العناصر المطابقة.
  • innerHTML = قراءة أو تغيير محتوى HTML.
  • textContent = قراءة أو تغيير النص.
  • style = تغيير تنسيق العنصر.
  • getAttribute() = الحصول على قيمة Attribute.
  • setAttribute() = إضافة أو تغيير Attribute.
  • classList = التعامل مع Classes.
  • createElement() = إنشاء عنصر جديد.
  • appendChild() = إضافة عنصر.
  • remove() = حذف عنصر.
  • parentElement = الوصول إلى العنصر الأب.

Lesson 7 : Arrays

1. What is an Array? — ما هي المصفوفة؟

Array — المصفوفة هي نوع من أنواع البيانات في JavaScript يستخدم لتخزين مجموعة من القيم داخل متغير واحد.

يمكن أن تحتوي المصفوفة على أرقام أو نصوص أو قيم منطقية أو أنواع أخرى من البيانات.

let fruits = ["Apple", "Banana", "Orange"];

في المثال السابق يحتوي المتغير fruits على ثلاثة عناصر: Apple، Banana، وOrange.

2. Why Do We Use Arrays? — لماذا نستخدم المصفوفات؟

نستخدم المصفوفات عندما نحتاج إلى تخزين مجموعة من القيم المرتبطة ببعضها بدلًا من إنشاء متغير منفصل لكل قيمة.

let student1 = "Ahmed"; let student2 = "Mona"; let student3 = "Hager";

يمكن بدلًا من ذلك تخزين الأسماء كلها داخل Array واحدة.

let students = ["Ahmed", "Mona", "Hager"];

3. Creating an Array — إنشاء المصفوفة

يمكن إنشاء المصفوفة باستخدام الأقواس المربعة [ ].

let numbers = [10, 20, 30, 40, 50];

يتم الفصل بين عناصر المصفوفة باستخدام الفاصلة ,.

4. Array Elements — عناصر المصفوفة

Array Elements — عناصر المصفوفة هي القيم الموجودة داخل الـ Array.

let colors = ["Red", "Blue", "Green"];

في المثال السابق: Red وBlue وGreen هي عناصر المصفوفة.

5. Array Index — فهرس المصفوفة

كل عنصر داخل المصفوفة له رقم يسمى Index — الفهرس.

تبدأ الفهارس في JavaScript من الرقم 0 وليس من الرقم 1.

let fruits = ["Apple", "Banana", "Orange"];
  • Apple → Index 0
  • Banana → Index 1
  • Orange → Index 2

6. Accessing Array Elements — الوصول إلى عناصر المصفوفة

يمكن الوصول إلى عنصر معين باستخدام رقم الـ Index الخاص به.

let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits[0]);

ستكون النتيجة: Apple.

7. Changing Array Elements — تغيير عناصر المصفوفة

يمكن تغيير قيمة عنصر معين عن طريق الوصول إليه باستخدام الـ Index ثم إعطائه قيمة جديدة.

let fruits = ["Apple", "Banana", "Orange"]; fruits[1] = "Mango"; console.log(fruits);

سيتم تغيير العنصر الموجود في الفهرس 1 من Banana إلى Mango.

8. Array length — عدد عناصر المصفوفة

تستخدم الخاصية length لمعرفة عدد العناصر الموجودة داخل المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits.length);

ستكون النتيجة: 3.

9. Adding Elements with push() — إضافة عناصر باستخدام push()

تستخدم الدالة push() لإضافة عنصر جديد إلى نهاية المصفوفة.

let fruits = ["Apple", "Banana"]; fruits.push("Orange"); console.log(fruits);

أصبحت المصفوفة تحتوي على: Apple، Banana، وOrange.

10. Removing Elements with pop() — حذف العناصر باستخدام pop()

تستخدم الدالة pop() لحذف آخر عنصر من المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; fruits.pop(); console.log(fruits);

سيتم حذف العنصر Orange.

11. Adding Elements with unshift() — الإضافة في البداية

تستخدم الدالة unshift() لإضافة عنصر في بداية المصفوفة.

let fruits = ["Banana", "Orange"]; fruits.unshift("Apple"); console.log(fruits);

12. Removing Elements with shift() — الحذف من البداية

تستخدم الدالة shift() لحذف أول عنصر من المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; fruits.shift(); console.log(fruits);

سيتم حذف العنصر الأول Apple.

13. indexOf() — البحث عن فهرس عنصر

تستخدم الدالة indexOf() لمعرفة فهرس عنصر معين داخل المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits.indexOf("Banana"));

ستكون النتيجة: 1.

14. includes() — التحقق من وجود عنصر

تستخدم الدالة includes() للتحقق مما إذا كانت المصفوفة تحتوي على قيمة معينة.

let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits.includes("Apple"));

ستكون النتيجة true لأن العنصر موجود داخل المصفوفة.

15. join() — تحويل عناصر المصفوفة إلى نص

تستخدم الدالة join() لدمج عناصر المصفوفة وتحويلها إلى نص واحد.

let fruits = ["Apple", "Banana", "Orange"]; console.log(fruits.join(", "));

ستكون النتيجة نصًا يحتوي على العناصر مفصولة بفواصل.

16. slice() — استخراج جزء من المصفوفة

تستخدم الدالة slice() للحصول على جزء من المصفوفة دون تغيير المصفوفة الأصلية.

let numbers = [10, 20, 30, 40, 50]; let result = numbers.slice(1, 4); console.log(result);

سيتم الحصول على العناصر الموجودة من الفهرس 1 وحتى قبل الفهرس 4.

17. splice() — إضافة أو حذف عناصر

تستخدم الدالة splice() لإضافة أو حذف أو استبدال عناصر داخل المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; fruits.splice(1, 1); console.log(fruits);

في المثال السابق تم حذف عنصر واحد بدايةً من الفهرس 1.

18. Sorting Arrays with sort() — ترتيب المصفوفة

تستخدم الدالة sort() لترتيب عناصر المصفوفة.

let fruits = ["Orange", "Apple", "Banana"]; fruits.sort(); console.log(fruits);

سيتم ترتيب العناصر أبجديًا في هذا المثال.

19. reverse() — عكس ترتيب العناصر

تستخدم الدالة reverse() لعكس ترتيب عناصر المصفوفة.

let numbers = [1, 2, 3, 4, 5]; numbers.reverse(); console.log(numbers);

سيصبح ترتيب العناصر: 5, 4, 3, 2, 1.

20. Loop Through an Array — المرور على عناصر المصفوفة

يمكن استخدام الحلقات للمرور على جميع عناصر المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

يقوم البرنامج بطباعة كل عنصر في المصفوفة بدايةً من الفهرس 0.

21. for...of with Arrays — استخدام for...of مع المصفوفات

يمكن استخدام for...of للمرور على قيم عناصر المصفوفة بطريقة أبسط.

let fruits = ["Apple", "Banana", "Orange"]; for (let fruit of fruits) { console.log(fruit); }

في كل تكرار يتم تخزين قيمة العنصر الحالي داخل المتغير fruit.

22. Arrays with Functions — المصفوفات مع الدوال

يمكن إرسال المصفوفة إلى دالة كـ Argument ثم التعامل مع عناصرها داخل الدالة.

function showFruits(fruits) { for (let fruit of fruits) { console.log(fruit); } } let fruits = ["Apple", "Banana", "Orange"]; showFruits(fruits);

23. Multidimensional Arrays — المصفوفات متعددة الأبعاد

يمكن أن تحتوي المصفوفة على مصفوفات أخرى بداخلها، وتسمى Multidimensional Array — مصفوفة متعددة الأبعاد.

let numbers = [ [1, 2, 3], [4, 5, 6] ]; console.log(numbers[0][1]);

في المثال السابق يتم الوصول إلى العنصر 2 باستخدام الفهرسين 0 و1.

24. Array Methods — دوال المصفوفات

توفر JavaScript العديد من Array Methods — دوال المصفوفات التي تساعدنا على إضافة العناصر وحذفها والبحث عنها والتعامل معها.

  • push() — إضافة عنصر في النهاية.
  • pop() — حذف آخر عنصر.
  • unshift() — إضافة عنصر في البداية.
  • shift() — حذف أول عنصر.
  • indexOf() — معرفة فهرس عنصر.
  • includes() — التحقق من وجود عنصر.
  • join() — دمج العناصر في نص.
  • slice() — استخراج جزء من المصفوفة.
  • splice() — إضافة أو حذف أو استبدال عناصر.
  • sort() — ترتيب العناصر.
  • reverse() — عكس ترتيب العناصر.

25. Try It Yourself — جرب بنفسك

قم بإنشاء Array تحتوي على خمسة أسماء، ثم:

  • اطبع أول عنصر في المصفوفة.
  • اطبع عدد العناصر باستخدام length.
  • أضف اسمًا جديدًا باستخدام push().
  • احذف آخر عنصر باستخدام pop().
  • استخدم for...of لطباعة جميع الأسماء.
  • تحقق من وجود اسم معين باستخدام includes().

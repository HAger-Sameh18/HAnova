Lesson 8 : Objects

1. What is an Object? — ما هو الكائن؟

Object — الكائن هو نوع من أنواع البيانات في JavaScript يستخدم لتخزين مجموعة من البيانات المرتبطة ببعضها.

يتم تخزين البيانات داخل الـ Object في صورة Key — مفتاح و Value — قيمة.

let student = { name: "Hager", age: 20, grade: 95 };

في المثال السابق يمثل student كائنًا يحتوي على بيانات الطالب مثل الاسم والعمر والدرجة.

2. Why Do We Use Objects? — لماذا نستخدم Objects؟

نستخدم الـ Objects عندما نحتاج إلى تجميع بيانات مختلفة مرتبطة بشيء واحد داخل متغير واحد.

على سبيل المثال، بدلًا من إنشاء متغير منفصل لكل معلومة عن الطالب، يمكن جمع جميع البيانات داخل Object واحد.

let name = "Hager"; let age = 20; let grade = 95;

يمكن تنظيم هذه البيانات بشكل أفضل باستخدام Object.

let student = { name: "Hager", age: 20, grade: 95 };

3. Creating an Object — إنشاء Object

يتم إنشاء الـ Object باستخدام الأقواس المعقوفة { }.

let person = { name: "Ahmed", age: 21 };

يحتوي الكائن السابق على خاصيتين هما name و age.

4. Properties — الخصائص

Property — الخاصية هي البيانات التي تصف الكائن.

let student = { name: "Hager", age: 20, grade: 95 };

في المثال السابق: name وage وgrade هي خصائص الكائن.

5. Key and Value — المفتاح والقيمة

تتكون كل خاصية داخل الـ Object من جزأين: Key — المفتاح و Value — القيمة.

name: "Hager"

في المثال السابق: name هو الـ Key، بينما "Hager" هي الـ Value.

6. Accessing Object Properties — الوصول إلى خصائص Object

يمكن الوصول إلى خصائص الـ Object باستخدام اسم الكائن ثم النقطة . ثم اسم الخاصية.

let student = { name: "Hager", age: 20 }; console.log(student.name);

ستكون النتيجة: Hager.

7. Dot Notation — طريقة النقطة

Dot Notation — طريقة النقطة هي إحدى الطرق المستخدمة للوصول إلى خصائص الـ Object.

let car = { brand: "BMW", model: "X5" }; console.log(car.brand); console.log(car.model);

8. Bracket Notation — طريقة الأقواس المربعة

يمكن أيضًا الوصول إلى خصائص الـ Object باستخدام Bracket Notation — طريقة الأقواس المربعة.

let student = { name: "Hager", age: 20 }; console.log(student["name"]); console.log(student["age"]);

هذه الطريقة مفيدة عندما يكون اسم الخاصية موجودًا داخل متغير.

9. Changing Object Properties — تغيير خصائص Object

يمكن تغيير قيمة خاصية موجودة داخل Object عن طريق إعطائها قيمة جديدة.

let student = { name: "Hager", grade: 90 }; student.grade = 95; console.log(student.grade);

تم تغيير قيمة grade من 90 إلى 95.

10. Adding New Properties — إضافة خصائص جديدة

يمكن إضافة خاصية جديدة إلى Object بعد إنشائه.

let student = { name: "Hager", age: 20 }; student.grade = 95; console.log(student);

تمت إضافة الخاصية grade إلى الكائن.

11. Deleting Properties — حذف الخصائص

يمكن حذف خاصية من Object باستخدام الكلمة المفتاحية delete.

let student = { name: "Hager", age: 20, grade: 95 }; delete student.grade; console.log(student);

سيتم حذف الخاصية grade من الكائن.

12. Objects with Different Data Types — أنواع بيانات مختلفة

يمكن أن يحتوي Object على أنواع مختلفة من البيانات في نفس الوقت.

let student = { name: "Hager", age: 20, grade: 95, passed: true };

يحتوي الكائن السابق على: String، Number، وBoolean.

13. Object with Array — Object يحتوي على Array

يمكن أن تحتوي إحدى خصائص الـ Object على Array.

let student = { name: "Hager", subjects: ["HTML", "CSS", "JavaScript"] };

يمكن الوصول إلى المصفوفة الموجودة داخل الكائن باستخدام:

console.log(student.subjects);

14. Accessing Array Inside Object — الوصول إلى Array داخل Object

يمكن الوصول إلى عنصر معين داخل Array الموجودة داخل Object باستخدام أكثر من Index.

let student = { name: "Hager", subjects: ["HTML", "CSS", "JavaScript"] }; console.log(student.subjects[0]);

ستكون النتيجة: HTML.

15. Nested Objects — الكائنات المتداخلة

يمكن أن يحتوي Object على Object آخر بداخله، ويسمى ذلك Nested Object — كائن متداخل.

let student = { name: "Hager", address: { city: "Banha", country: "Egypt" } };

للوصول إلى المدينة يمكن كتابة:

console.log(student.address.city);

16. Object Methods — دوال الكائن

يمكن أن يحتوي Object على دالة، وعندما تكون الدالة داخل Object تسمى Method — دالة كائن.

let person = { name: "Hager", sayHello: function() { console.log("Hello"); } }; person.sayHello();

17. Using this — استخدام this

الكلمة المفتاحية this تستخدم للإشارة إلى الكائن الحالي في كثير من سياقات التعامل مع Objects.

let person = { name: "Hager", sayHello: function() { console.log("Hello " + this.name); } }; person.sayHello();

في المثال السابق تشير this.name إلى الخاصية name الموجودة داخل الكائن الحالي.

18. Object.keys() — الحصول على المفاتيح

تستخدم Object.keys() للحصول على Array تحتوي على جميع مفاتيح الـ Object.

let student = { name: "Hager", age: 20, grade: 95 }; console.log(Object.keys(student));

19. Object.values() — الحصول على القيم

تستخدم Object.values() للحصول على Array تحتوي على جميع القيم الموجودة داخل Object.

let student = { name: "Hager", age: 20, grade: 95 }; console.log(Object.values(student));

20. Object.entries() — الحصول على المفاتيح والقيم

تستخدم Object.entries() للحصول على Array تحتوي على أزواج من المفاتيح والقيم.

let student = { name: "Hager", age: 20 }; console.log(Object.entries(student));

21. for...in — المرور على خصائص Object

يمكن استخدام for...in للمرور على جميع خصائص Object.

let student = { name: "Hager", age: 20, grade: 95 }; for (let key in student) { console.log(key); }

في كل تكرار يتم الحصول على اسم خاصية من خصائص الكائن.

22. Objects with Functions — Objects مع الدوال

يمكن استخدام الدوال مع Objects لتنفيذ عمليات تعتمد على البيانات الموجودة داخل الكائن.

let calculator = { number1: 10, number2: 5, add: function() { return this.number1 + this.number2; } }; console.log(calculator.add());

23. Objects as Function Arguments — إرسال Object إلى دالة

يمكن إرسال Object إلى دالة كـ Argument والتعامل مع خصائصه داخل الدالة.

function showStudent(student) { console.log(student.name); console.log(student.grade); } let student = { name: "Hager", grade: 95 }; showStudent(student);

24. Array of Objects — Array من Objects

يمكن إنشاء Array تحتوي على مجموعة من Objects، وهذا أسلوب شائع جدًا في JavaScript لتخزين مجموعة من البيانات المتشابهة.

let students = [ { name: "Hager", grade: 95 }, { name: "Ahmed", grade: 90 }, { name: "Mona", grade: 93 } ];

يحتوي الـ Array السابق على ثلاثة Objects، وكل Object يمثل طالبًا وبياناته.

25. Accessing Objects in an Array — الوصول إلى Objects داخل Array

يمكن الوصول إلى Object معين داخل Array باستخدام الـ Index، ثم الوصول إلى الخاصية المطلوبة.

console.log(students[0].name); console.log(students[1].grade);

في المثال السابق تم الوصول إلى اسم الطالب الأول ودرجة الطالب الثاني.

26. Try It Yourself — جرب بنفسك

قم بإنشاء Object باسم student يحتوي على:

  • اسم الطالب باستخدام name.
  • عمر الطالب باستخدام age.
  • درجة الطالب باستخدام grade.
  • مادة دراسية باستخدام subject.

بعد ذلك قم بطباعة اسم الطالب ودرجته، ثم قم بتغيير الدرجة وإضافة خاصية جديدة للكائن.

وأخيرًا أنشئ Array تحتوي على ثلاثة Objects يمثل كل منها طالبًا مختلفًا.

Quick Review — مراجعة سريعة

  • Object = الكائن.
  • Property = الخاصية.
  • Key = المفتاح.
  • Value = القيمة.
  • Dot Notation = طريقة النقطة.
  • Bracket Notation = طريقة الأقواس المربعة.
  • Method = دالة داخل Object.
  • this = الإشارة إلى الكائن الحالي.
  • Object.keys() = الحصول على مفاتيح الكائن.
  • Object.values() = الحصول على قيم الكائن.
  • Object.entries() = الحصول على المفاتيح والقيم.
  • for...in = المرور على خصائص Object.
  • Nested Object = كائن متداخل.
  • Array of Objects = مصفوفة تحتوي على Objects.

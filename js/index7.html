Lesson 5 : Loops

1. What are Loops? — ما هي الحلقات التكرارية؟

Loops — الحلقات التكرارية هي طريقة تستخدم في JavaScript لتكرار تنفيذ مجموعة من التعليمات أكثر من مرة، بدلًا من كتابة نفس الكود عدة مرات.

يمكن التحكم في عدد مرات التكرار باستخدام شرط أو عدد محدد من المرات.

console.log("Hello"); console.log("Hello"); console.log("Hello");

بدلًا من تكرار نفس السطر عدة مرات، يمكننا استخدام Loop لتنفيذ الكود بشكل أسهل وأكثر تنظيمًا.

2. Why Do We Use Loops? — لماذا نستخدم الحلقات؟

نستخدم الحلقات عندما نحتاج إلى تنفيذ نفس التعليمات عدة مرات.

  • تكرار طباعة مجموعة من القيم.
  • المرور على عناصر Array.
  • تنفيذ عملية عددًا معينًا من المرات.
  • البحث عن قيمة داخل مجموعة من البيانات.
  • تكرار تنفيذ كود حتى يتحقق شرط معين.

3. for Loop — حلقة for

for Loop — حلقة for تستخدم عندما نعرف غالبًا عدد مرات التكرار التي نريد تنفيذها.

for (let i = 1; i <= 5; i++) { console.log(i); }

سيقوم الكود السابق بطباعة الأرقام من 1 إلى 5.

4. Parts of a for Loop — أجزاء حلقة for

تتكون حلقة for من ثلاثة أجزاء رئيسية:

  • Initialization — التهيئة.
  • Condition — الشرط.
  • Update — التحديث.
for (let i = 1; i <= 5; i++) { console.log(i); }

في المثال السابق: let i = 1 هي التهيئة، وi <= 5 هو الشرط، وi++ هو التحديث.

5. Initialization — التهيئة

Initialization — التهيئة هي الخطوة التي يتم فيها إنشاء المتغير الذي سنستخدمه للتحكم في الحلقة وتحديد قيمته الابتدائية.

for (let i = 1; i <= 5; i++) { console.log(i); }

في المثال السابق تبدأ قيمة i من 1.

6. Condition — شرط الحلقة

Condition — الشرط يحدد ما إذا كانت الحلقة ستستمر في التكرار أم ستتوقف.

for (let i = 1; i <= 5; i++) { console.log(i); }

طالما أن i <= 5 صحيحة، تستمر الحلقة في التنفيذ. وعندما يصبح الشرط غير صحيح تتوقف الحلقة.

7. Update — التحديث

Update — التحديث هو الجزء الذي يغير قيمة المتغير بعد كل تكرار.

for (let i = 1; i <= 5; i++) { console.log(i); }

العامل ++ يزيد قيمة i بمقدار واحد بعد كل تكرار.

8. Counting with for Loop — العد باستخدام for

يمكن استخدام حلقة for لطباعة الأرقام بالتتابع.

for (let i = 1; i <= 10; i++) { console.log(i); }

سيقوم البرنامج بطباعة الأرقام من 1 إلى 10.

9. Counting Backwards — العد التنازلي

يمكن استخدام الحلقة للعد من رقم كبير إلى رقم أصغر باستخدام العامل --.

for (let i = 5; i >= 1; i--) { console.log(i); }

ستتم طباعة الأرقام: 5، 4، 3، 2، 1.

10. while Loop — حلقة while

while Loop — حلقة while تستخدم لتكرار تنفيذ مجموعة من التعليمات طالما أن شرطًا معينًا صحيح.

let i = 1; while (i <= 5) { console.log(i); i++; }

تستمر الحلقة في التنفيذ طالما أن i <= 5 صحيحة.

11. Difference Between for and while — الفرق بين for و while

تستخدم for غالبًا عندما يكون عدد مرات التكرار معروفًا أو يمكن تحديده، بينما تستخدم while عندما يعتمد استمرار الحلقة بشكل أساسي على شرط.

for Loop

مناسبة عندما نعرف عدد مرات التكرار.

while Loop

مناسبة عندما يعتمد التكرار على شرط معين.

12. do...while Loop — حلقة do...while

do...while Loop — حلقة do...while تشبه حلقة while، ولكنها تنفذ الكود الموجود داخلها مرة واحدة على الأقل قبل اختبار الشرط.

let i = 1; do { console.log(i); i++; } while (i <= 5);

13. Difference Between while and do...while — الفرق بين while و do...while

في حلقة while يتم فحص الشرط أولًا، لذلك قد لا يتم تنفيذ الكود حتى مرة واحدة.

أما في do...while يتم تنفيذ الكود أولًا ثم يتم فحص الشرط.

let x = 10; do { console.log(x); } while (x < 5);

رغم أن الشرط غير صحيح، سيتم تنفيذ الكود مرة واحدة على الأقل.

14. break Statement — جملة break

تستخدم break لإيقاف الحلقة فورًا حتى لو كان شرط الحلقة ما زال صحيحًا.

for (let i = 1; i <= 10; i++) { if (i === 5) { break; } console.log(i); }

ستتوقف الحلقة عندما تصل قيمة i إلى 5.

15. continue Statement — جملة continue

تستخدم continue لتخطي التكرار الحالي والانتقال مباشرةً إلى التكرار التالي.

for (let i = 1; i <= 5; i++) { if (i === 3) { continue; } console.log(i); }

سيتم تخطي الرقم 3 ولن تتم طباعته، ثم تستمر الحلقة في باقي التكرارات.

16. Nested Loops — الحلقات المتداخلة

Nested Loops — الحلقات المتداخلة تعني وضع حلقة داخل حلقة أخرى.

for (let i = 1; i <= 3; i++) { for (let j = 1; j <= 2; j++) { console.log(i, j); } }

في المثال السابق توجد حلقة for داخل حلقة for. ويتم تنفيذ الحلقة الداخلية مع كل تكرار للحلقة الخارجية.

17. Loops with Conditions — الحلقات مع الشروط

يمكن دمج الحلقات مع if Statement لتنفيذ تعليمات معينة عند تحقق شرط أثناء التكرار.

for (let i = 1; i <= 10; i++) { if (i % 2 === 0) { console.log(i); } }

يقوم الكود السابق بطباعة الأرقام الزوجية فقط من 1 إلى 10.

18. Infinite Loop — الحلقة اللانهائية

Infinite Loop — الحلقة اللانهائية هي حلقة تستمر في التنفيذ دون توقف لأن شرطها يظل صحيحًا.

let i = 1; while (i <= 5) { console.log(i); }

في المثال السابق لم يتم تغيير قيمة i، لذلك سيظل الشرط صحيحًا وتستمر الحلقة.

لذلك يجب التأكد دائمًا من وجود طريقة تجعل شرط الحلقة يصبح غير صحيح في الوقت المناسب.

19. Looping Through an Array — المرور على عناصر Array

يمكن استخدام الحلقات للمرور على العناصر الموجودة داخل Array — المصفوفة.

let fruits = ["Apple", "Banana", "Orange"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

يقوم البرنامج بالمرور على كل عنصر داخل المصفوفة وطباعته.

20. for...of Loop — حلقة for...of

تستخدم for...of للمرور على القيم الموجودة داخل العناصر القابلة للتكرار، مثل Array.

let fruits = ["Apple", "Banana", "Orange"]; for (let fruit of fruits) { console.log(fruit); }

في كل تكرار يتم وضع قيمة عنصر من المصفوفة داخل المتغير fruit.

21. for...in Loop — حلقة for...in

تستخدم for...in للمرور على أسماء الخصائص أو المفاتيح Keys الموجودة داخل الكائن Object.

let student = { name: "Hager", age: 20 }; for (let key in student) { console.log(key); }

يقوم الكود السابق بالمرور على مفاتيح الكائن مثل name وage.

22. Loop Counter — عداد الحلقة

Loop Counter — عداد الحلقة هو المتغير الذي نستخدمه لتتبع عدد مرات التكرار.

for (let i = 0; i < 5; i++) { console.log("Iteration:", i); }

في المثال السابق يستخدم المتغير i كعداد للحلقة.

23. Try It Yourself — جرب بنفسك

قم بإنشاء حلقة for تطبع الأرقام من 1 إلى 20.

بعد ذلك حاول تعديل الكود ليطبع الأرقام الزوجية فقط، ثم جرب استخدام while وdo...while لتنفيذ نفس الفكرة.

وأخيرًا أنشئ Array تحتوي على مجموعة من الأسماء، واستخدم for...of لطباعة كل اسم.

Quick Review — مراجعة سريعة

  • Loop = حلقة تكرارية.
  • for Loop = حلقة تستخدم غالبًا عندما يكون عدد التكرارات معروفًا.
  • while Loop = حلقة تستمر طالما أن الشرط صحيح.
  • do...while = تنفذ الكود مرة واحدة على الأقل قبل فحص الشرط.
  • Initialization = التهيئة.
  • Condition = الشرط.
  • Update = التحديث.
  • break = إيقاف الحلقة.
  • continue = تخطي التكرار الحالي.
  • Nested Loop = حلقة متداخلة.
  • Infinite Loop = حلقة لا نهائية.
  • Loop Counter = عداد الحلقة.
  • for...of = المرور على القيم.
  • for...in = المرور على المفاتيح أو الخصائص.

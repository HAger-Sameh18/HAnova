Lesson 4 : Conditions

1. What are Conditions? — ما هي الشروط؟

Conditions — الشروط هي طريقة تستخدم في JavaScript لاتخاذ قرارات مختلفة بناءً على نتيجة اختبار أو مقارنة معينة.

بمعنى آخر، يمكن للبرنامج أن يتحقق من شرط معين، وإذا كان الشرط صحيحًا ينفذ مجموعة من التعليمات، وإذا كان غير صحيح يمكنه تنفيذ تعليمات أخرى.

let age = 20; if (age >= 18) { console.log("Adult"); }

2. Why Do We Use Conditions? — لماذا نستخدم الشروط؟

نستخدم الشروط عندما نريد أن يتصرف البرنامج بطريقة مختلفة حسب البيانات أو الموقف.

  • التحقق من عمر المستخدم.
  • التحقق من صحة كلمة المرور.
  • تحديد نجاح أو رسوب الطالب.
  • معرفة إذا كان الرقم موجبًا أو سالبًا.
  • إظهار رسالة مختلفة حسب حالة المستخدم.
  • تنفيذ تعليمات معينة عند تحقق شرط معين.

3. if Statement — جملة if

if Statement — جملة if تستخدم لتنفيذ مجموعة من التعليمات إذا كان الشرط صحيحًا true.

let age = 20; if (age >= 18) { console.log("You are an adult"); }

في المثال السابق يتحقق البرنامج من أن قيمة age أكبر من أو تساوي 18. إذا كان الشرط صحيحًا، يتم تنفيذ الرسالة الموجودة داخل الأقواس المعقوفة.

4. Condition — الشرط

Condition — الشرط هو التعبير الذي يتم اختباره لمعرفة هل نتيجته true أم false.

let age = 20; age >= 18

في المثال السابق: age >= 18 هو الشرط الذي يتم اختباره.

5. Curly Brackets — الأقواس المعقوفة

تستخدم الأقواس المعقوفة { } لتحديد مجموعة التعليمات التي سيتم تنفيذها عندما يكون الشرط صحيحًا.

if (age >= 18) { console.log("Allowed"); console.log("Welcome"); }

جميع التعليمات الموجودة داخل الأقواس سيتم تنفيذها إذا كان الشرط صحيحًا.

6. if...else Statement — جملة if...else

تستخدم if...else عندما نريد تنفيذ مجموعة من التعليمات إذا كان الشرط صحيحًا، ومجموعة أخرى إذا كان الشرط غير صحيح.

let age = 16; if (age >= 18) { console.log("Adult"); } else { console.log("Not Adult"); }

إذا كان العمر أكبر من أو يساوي 18 سيتم تنفيذ الجزء الموجود داخل if، وإلا سيتم تنفيذ الجزء الموجود داخل else.

7. else Statement — جملة else

else Statement — جملة else تستخدم لتنفيذ تعليمات عندما يكون شرط if غير صحيح.

let number = 5; if (number > 10) { console.log("Number is greater than 10"); } else { console.log("Number is not greater than 10"); }

8. else if Statement — جملة else if

تستخدم else if عندما يكون لدينا أكثر من شرط ونريد اختبارها بالترتيب.

let mark = 85; if (mark >= 90) { console.log("Excellent"); } else if (mark >= 80) { console.log("Very Good"); } else { console.log("Good"); }

يقوم البرنامج باختبار الشروط بالترتيب، وعندما يجد أول شرط صحيح ينفذ التعليمات الخاصة به ويتوقف عن اختبار باقي الشروط.

9. Multiple Conditions — الشروط المتعددة

يمكن استخدام أكثر من شرط داخل البرنامج، ويمكن دمج الشروط باستخدام Logical Operators — العوامل المنطقية.

let age = 20; let hasID = true; if (age >= 18 && hasID === true) { console.log("Access Allowed"); }

في المثال السابق يجب أن يكون العمر مناسبًا وأن تكون قيمة hasID صحيحة حتى يتم تنفيذ الكود.

10. Using Comparison Operators — استخدام عوامل المقارنة

تعتمد الشروط بشكل كبير على Comparison Operators — عوامل المقارنة مثل: ==، ===، !=، !==، >، <، >=، و<=.

let age = 20; if (age > 18) { console.log("Age is greater than 18"); }

11. Strict Comparison — المقارنة الصارمة

يمكن استخدام === و!== في الشروط لمقارنة القيمة والنوع معًا.

let number = 10; if (number === 10) { console.log("Correct"); }

تعتبر المقارنة باستخدام === مفيدة عندما نريد التأكد من أن القيمة والنوع متطابقان.

12. Logical AND (&&) — العامل AND

يستخدم && عندما نريد أن تكون جميع الشروط المطلوبة صحيحة.

let age = 20; let student = true; if (age >= 18 && student === true) { console.log("Allowed"); }

يجب أن يكون الشرطان صحيحين حتى يتم تنفيذ الكود.

13. Logical OR (||) — العامل OR

يستخدم || عندما يكفي أن يكون أحد الشروط صحيحًا.

let day = "Friday"; if (day === "Friday" || day === "Saturday") { console.log("Weekend"); }

في المثال السابق إذا كان اليوم Friday أو Saturday، فسيتم تنفيذ الكود.

14. Logical NOT (!) — العامل NOT

يستخدم العامل ! لعكس القيمة المنطقية للشرط.

let loggedIn = false; if (!loggedIn) { console.log("Please Login"); }

لأن قيمة loggedIn تساوي false، فإن !loggedIn تصبح true.

15. Nested if — الشروط المتداخلة

Nested if — الشرط المتداخل يعني وضع جملة if داخل جملة if أخرى.

let age = 20; let hasID = true; if (age >= 18) { if (hasID === true) { console.log("Access Allowed"); } }

في المثال السابق يجب أولًا أن يكون العمر مناسبًا، ثم يتم التحقق من وجود بطاقة الهوية.

16. Ternary Operator — العامل الثلاثي

Ternary Operator — العامل الثلاثي هو طريقة مختصرة لكتابة شرط بسيط بدلًا من استخدام if...else.

let age = 20; let result = age >= 18 ? "Adult" : "Not Adult"; console.log(result);

إذا كان الشرط صحيحًا يتم استخدام القيمة الموجودة بعد ?، وإذا كان غير صحيح يتم استخدام القيمة الموجودة بعد :.

17. switch Statement — جملة switch

تستخدم switch Statement — جملة switch عندما نريد مقارنة قيمة واحدة بعدة قيم محتملة.

let day = "Friday"; switch (day) { case "Friday": console.log("Weekend"); break; case "Saturday": console.log("Weekend"); break; default: console.log("Working Day"); }

تقوم switch بمقارنة قيمة المتغير مع الحالات case. وإذا تطابقت القيمة يتم تنفيذ التعليمات الخاصة بهذه الحالة.

18. break Statement — جملة break

تستخدم break لإيقاف تنفيذ جملة switch بعد الوصول إلى الحالة المطلوبة.

let number = 2; switch (number) { case 1: console.log("One"); break; case 2: console.log("Two"); break; default: console.log("Other"); }

19. default Statement — الحالة الافتراضية

تستخدم default داخل switch لتنفيذ كود عندما لا تتطابق القيمة مع أي case.

let color = "black"; switch (color) { case "red": console.log("Red"); break; case "blue": console.log("Blue"); break; default: console.log("Unknown Color"); }

20. Truthy and Falsy Values — القيم التي تعتبر صحيحة أو خاطئة

في JavaScript توجد بعض القيم التي يتم التعامل معها داخل الشروط على أنها true أو false.

من أشهر القيم التي تعتبر Falsy: false، 0، ""، null، وundefined.

let name = ""; if (name) { console.log("Name exists"); } else { console.log("Name is empty"); }

21. Conditions with Variables — الشروط مع المتغيرات

يمكن استخدام المتغيرات داخل الشروط لاتخاذ قرارات بناءً على القيم المخزنة فيها.

let mark = 95; if (mark >= 90) { console.log("Excellent"); } else if (mark >= 80) { console.log("Very Good"); } else if (mark >= 70) { console.log("Good"); } else { console.log("Try Again"); }

22. Conditions and User Interaction — الشروط وتفاعل المستخدم

يمكن استخدام الشروط مع البيانات التي يدخلها المستخدم، مثل التحقق من العمر أو كلمة المرور أو البيانات الموجودة داخل نموذج.

let password = "12345"; if (password === "12345") { console.log("Correct Password"); } else { console.log("Wrong Password"); }

23. Try It Yourself — جرب بنفسك

قم بإنشاء متغير يحتوي على درجة طالب، ثم استخدم if وelse if وelse لتحديد التقدير حسب الدرجة.

بعد ذلك جرب استخدام switch لإنشاء برنامج يعرض اسم يوم معين بناءً على رقم اليوم.

Quick Review — مراجعة سريعة

  • Condition = الشرط.
  • if = تنفيذ كود عند تحقق الشرط.
  • else = تنفيذ كود عندما يكون الشرط غير صحيح.
  • else if = اختبار شرط إضافي.
  • Nested if = الشروط المتداخلة.
  • && = AND.
  • || = OR.
  • ! = NOT.
  • switch = مقارنة قيمة بعدة حالات.
  • case = حالة داخل switch.
  • break = إيقاف تنفيذ الحالة.
  • default = الحالة الافتراضية.
  • Ternary Operator = العامل الثلاثي.
  • Truthy = قيمة تعامل كـ true.
  • Falsy = قيمة تعامل كـ false.

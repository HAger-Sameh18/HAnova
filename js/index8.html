Lesson 6 : Functions

1. What is a Function? — ما هي الدالة؟

Function — الدالة هي مجموعة من التعليمات البرمجية يتم تجميعها معًا لتنفيذ مهمة معينة.

يمكننا إنشاء الدالة مرة واحدة ثم استدعاؤها Call كلما احتجنا إلى تنفيذ نفس المهمة، بدلًا من كتابة نفس الكود أكثر من مرة.

function sayHello() { console.log("Hello"); } sayHello();

في المثال السابق تم إنشاء دالة باسم sayHello ثم تم استدعاؤها لتنفيذ الكود الموجود بداخلها.

2. Why Do We Use Functions? — لماذا نستخدم الدوال؟

تساعدنا الدوال على تنظيم الكود وجعله أكثر سهولة في القراءة وإعادة الاستخدام.

  • تقليل تكرار الكود.
  • تنظيم البرنامج إلى أجزاء صغيرة.
  • إعادة استخدام نفس الكود أكثر من مرة.
  • تسهيل اكتشاف الأخطاء وتعديلها.
  • جعل البرنامج أكثر وضوحًا وتنظيمًا.

3. Function Declaration — تعريف الدالة

Function Declaration — تعريف الدالة هو إنشاء دالة باستخدام الكلمة المفتاحية function.

function greet() { console.log("Welcome to JavaScript"); }

في المثال السابق قمنا بإنشاء دالة باسم greet. ولكن الدالة لن تنفذ حتى نقوم باستدعائها.

4. Function Call — استدعاء الدالة

Function Call — استدعاء الدالة يعني تشغيل الدالة وتنفيذ التعليمات الموجودة بداخلها.

function greet() { console.log("Hello"); } greet();

يتم استدعاء الدالة عن طريق كتابة اسمها ثم الأقواس ( ).

5. Function Name — اسم الدالة

Function Name — اسم الدالة هو الاسم الذي نستخدمه للتعرف على الدالة واستدعائها.

function showMessage() { console.log("Welcome"); } showMessage();

اسم الدالة في المثال السابق هو showMessage.

6. Parameters — المعاملات

Parameters — المعاملات هي المتغيرات التي نضعها داخل أقواس الدالة لاستقبال البيانات التي سيتم إرسالها إليها.

function greet(name) { console.log("Hello " + name); }

في المثال السابق يعتبر name معاملًا للدالة.

7. Arguments — القيم المرسلة

Arguments — القيم المرسلة هي القيم التي نرسلها إلى الدالة عند استدعائها.

function greet(name) { console.log("Hello " + name); } greet("Hager");

في المثال السابق تم إرسال القيمة "Hager" إلى المعامل name.

8. Multiple Parameters — معاملات متعددة

يمكن للدالة أن تحتوي على أكثر من معامل.

function add(a, b) { console.log(a + b); } add(10, 5);

تستقبل الدالة قيمتين هما a وb ثم تقوم بجمعهما.

9. Return Statement — جملة return

تستخدم return لإرجاع نتيجة من الدالة إلى المكان الذي تم فيه استدعاء الدالة.

function add(a, b) { return a + b; } let result = add(10, 5); console.log(result);

تقوم الدالة بإرجاع نتيجة الجمع، ثم يتم تخزين النتيجة في المتغير result.

10. Function with No Return — دالة بدون return

ليست كل الدوال بحاجة إلى استخدام return. يمكن للدالة تنفيذ مهمة مباشرة مثل طباعة رسالة.

function welcome() { console.log("Welcome"); } welcome();

11. Function with Return Value — دالة ترجع قيمة

يمكن للدالة تنفيذ عملية ثم إرجاع النتيجة باستخدام return.

function square(number) { return number * number; } let result = square(5); console.log(result);

تقوم الدالة بحساب مربع الرقم وإرجاع النتيجة.

12. Default Parameters — المعاملات الافتراضية

يمكن تحديد قيمة افتراضية للمعامل في حالة عدم إرسال قيمة عند استدعاء الدالة.

function greet(name = "Guest") { console.log("Hello " + name); } greet();

إذا لم يتم إرسال قيمة إلى name، سيتم استخدام القيمة الافتراضية "Guest".

13. Function Expressions — تعبيرات الدوال

يمكن تخزين الدالة داخل متغير، وتسمى هذه الطريقة Function Expression — تعبير الدالة.

const greet = function() { console.log("Hello"); }; greet();

في المثال السابق تم تخزين الدالة داخل المتغير greet ثم تم استدعاؤها باستخدام اسم المتغير.

14. Arrow Functions — الدوال السهمية

Arrow Function — الدالة السهمية هي طريقة مختصرة لكتابة الدوال، وتم تقديمها في ES6.

const greet = () => { console.log("Hello"); }; greet();

تستخدم الدوال السهمية بكثرة في JavaScript الحديثة، خاصة عند التعامل مع المصفوفات والعمليات المختلفة.

15. Arrow Function with Parameters — الدالة السهمية مع معاملات

يمكن أن تحتوي الدوال السهمية على معاملات مثل الدوال العادية.

const add = (a, b) => { return a + b; }; console.log(add(10, 5));

16. Short Arrow Function — الدالة السهمية المختصرة

عندما تحتوي الدالة السهمية على تعبير واحد فقط يعيد قيمة، يمكن اختصار كتابتها.

const square = number => number * number; console.log(square(5));

في هذه الحالة يتم إرجاع النتيجة تلقائيًا دون الحاجة إلى كتابة return.

17. Local Variables — المتغيرات المحلية

المتغير الذي يتم إنشاؤه داخل الدالة يكون متاحًا داخل الدالة نفسها فقط، ويسمى Local Variable — متغير محلي.

function test() { let message = "Hello"; console.log(message); } test();

المتغير message تم إنشاؤه داخل الدالة، لذلك لا يمكن استخدامه خارج نطاقها.

18. Global Variables — المتغيرات العامة

المتغير الذي يتم تعريفه خارج الدوال يمكن الوصول إليه من أجزاء مختلفة من البرنامج حسب نطاقه، ويسمى Global Variable — متغير عام.

let name = "Hager"; function showName() { console.log(name); } showName();

19. Function Scope — نطاق الدالة

Function Scope — نطاق الدالة يحدد الأماكن التي يمكن من خلالها الوصول إلى المتغيرات الموجودة داخل الدالة.

function calculate() { let x = 10; console.log(x); } calculate();

المتغير x يمكن استخدامه داخل الدالة calculate.

20. Calling a Function Multiple Times — استدعاء الدالة عدة مرات

من أهم مميزات الدوال إمكانية استدعائها أكثر من مرة باستخدام قيم مختلفة.

function greet(name) { console.log("Hello " + name); } greet("Hager"); greet("Ahmed"); greet("Mona");

تم استخدام نفس الدالة ثلاث مرات، ولكن كل مرة تم إرسال قيمة مختلفة.

21. Function with Conditions — الدوال مع الشروط

يمكن استخدام if داخل الدوال لتنفيذ تعليمات مختلفة حسب البيانات التي تستقبلها الدالة.

function checkAge(age) { if (age >= 18) { return "Adult"; } else { return "Not Adult"; } } console.log(checkAge(20));

22. Function with Loops — الدوال مع الحلقات

يمكن أيضًا استخدام Loops داخل الدوال لتنفيذ عمليات متكررة.

function printNumbers() { for (let i = 1; i <= 5; i++) { console.log(i); } } printNumbers();

23. Function Naming — تسمية الدوال

يفضل اختيار أسماء واضحة تصف المهمة التي تقوم بها الدالة.

function calculateTotal() { // Code } function showMessage() { // Code } function checkPassword() { // Code }

الأسماء مثل calculateTotal وshowMessage وcheckPassword توضح وظيفة كل دالة.

24. Functions and Reusability — إعادة استخدام الكود

تساعد الدوال على Code Reusability — إعادة استخدام الكود، حيث يمكن كتابة الكود مرة واحدة ثم استخدامه عدة مرات.

function add(a, b) { return a + b; } console.log(add(5, 3)); console.log(add(10, 7)); console.log(add(20, 4));

تم استخدام نفس الدالة لإجراء عمليات جمع مختلفة دون الحاجة إلى كتابة عملية الجمع من جديد.

25. Try It Yourself — جرب بنفسك

قم بإنشاء دالة باسم calculateSum تستقبل رقمين وتعيد ناتج جمعهما باستخدام return.

بعد ذلك أنشئ دالة أخرى تستقبل درجة طالب، وتستخدم if...else لتحديد ما إذا كان الطالب ناجحًا أم لا.

وأخيرًا جرب كتابة إحدى الدوال باستخدام Arrow Function.

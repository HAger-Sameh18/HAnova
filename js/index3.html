Lesson 1 : Introduction To JavaScript

1. What is JavaScript? — ما هي JavaScript؟

JavaScript هي لغة برمجة تستخدم لإضافة Interactivity — التفاعل والوظائف الديناميكية إلى صفحات الويب. وهي واحدة من أهم التقنيات الأساسية المستخدمة في تطوير مواقع الويب إلى جانب HTML وCSS.

باستخدام JavaScript يمكننا جعل صفحة الويب تتفاعل مع المستخدم، مثل تغيير محتوى الصفحة، وإظهار الرسائل، والاستجابة للضغط على الأزرار، والتحقق من البيانات، وإنشاء تأثيرات وحركات مختلفة.

2. What is the Purpose of JavaScript? — ما الهدف من JavaScript؟

الهدف الأساسي من JavaScript هو إضافة Behavior — السلوك والتفاعل إلى صفحات الويب.

فبينما تستخدم HTML لإنشاء هيكل الصفحة، وتستخدم CSS لتنسيق هذا الهيكل، تستخدم JavaScript لإضافة الوظائف والتفاعل مع المستخدم.

3. HTML, CSS and JavaScript — العلاقة بين HTML و CSS و JavaScript

تعمل التقنيات الثلاث معًا لإنشاء صفحات ويب متكاملة. لكل تقنية وظيفة أساسية مختلفة.

HTML — Structure

تستخدم HTML لبناء هيكل الصفحة وتنظيم محتواها، مثل العناوين والفقرات والصور والأزرار.

CSS — Style

تستخدم CSS لتنسيق الصفحة والتحكم في الألوان والخطوط والأحجام والمسافات ومظهر العناصر.

JavaScript — Behavior

تستخدم JavaScript لإضافة التفاعل والوظائف الديناميكية والاستجابة لأفعال المستخدم.

4. Why Do We Use JavaScript? — لماذا نستخدم JavaScript؟

نستخدم JavaScript لجعل صفحات الويب أكثر تفاعلًا وديناميكية، بحيث لا تكون الصفحة مجرد محتوى ثابت.

  • إظهار الرسائل والتنبيهات للمستخدم.
  • تغيير محتوى الصفحة.
  • تغيير ألوان أو خصائص العناصر.
  • التفاعل مع الأزرار.
  • التحقق من البيانات التي يدخلها المستخدم.
  • إظهار وإخفاء عناصر الصفحة.
  • إنشاء تأثيرات وحركات تفاعلية.
  • التعامل مع النماذج Forms.
  • التعامل مع عناصر HTML باستخدام DOM.

5. Is JavaScript a Programming Language? — هل JavaScript لغة برمجة؟

نعم، JavaScript هي Programming Language — لغة برمجة تستخدم لكتابة التعليمات البرمجية وتنفيذ العمليات المنطقية والتعامل مع البيانات.

يمكن باستخدام JavaScript إنشاء Variables — متغيرات، واستخدام Conditions — شروط، وLoops — حلقات تكرار، وFunctions — دوال، بالإضافة إلى التعامل مع عناصر صفحات الويب.

6. JavaScript Syntax — صياغة JavaScript

Syntax — الصياغة هي مجموعة القواعد التي يجب اتباعها عند كتابة كود JavaScript بطريقة صحيحة.

على سبيل المثال، يمكننا استخدام الأمر console.log() لعرض قيمة أو رسالة داخل Console — وحدة التحكم.

console.log("Hello JavaScript");

في المثال السابق يقوم console.log() بعرض النص الموجود داخل الأقواس في وحدة التحكم.

7. Statement — التعليمة

Statement — التعليمة هي أمر برمجي يخبر JavaScript بتنفيذ عملية معينة.

console.log("Welcome to HAnova");

التعليمة السابقة تطلب من JavaScript عرض الرسالة Welcome to HAnova داخل وحدة التحكم.

8. Comments — التعليقات

تستخدم Comments — التعليقات لكتابة ملاحظات داخل الكود. ولا يتم تنفيذ التعليقات بواسطة JavaScript.

يمكن كتابة تعليق في سطر واحد باستخدام //.

// This is a comment console.log("Hello");

يمكن أيضًا كتابة تعليق يمتد إلى أكثر من سطر باستخدام /* */.

/* This is a multi-line comment. */ console.log("Hello");

9. Where Can We Write JavaScript? — أين نكتب JavaScript؟

يمكن كتابة JavaScript داخل صفحة HTML باستخدام وسم <script>.

ويمكن وضع JavaScript داخل الصفحة نفسها، أو في ملف JavaScript خارجي.

10. Internal JavaScript — JavaScript داخل الصفحة

يمكن كتابة كود JavaScript مباشرة داخل ملف HTML باستخدام وسم <script>.

<script> console.log("Hello JavaScript"); </script>

في هذه الطريقة يكون كود JavaScript موجودًا داخل ملف HTML نفسه.

11. External JavaScript — JavaScript خارجي

يمكن أيضًا كتابة JavaScript في ملف منفصل بامتداد .js ثم ربطه بصفحة HTML.

يتم ربط ملف JavaScript باستخدام وسم <script> مع الخاصية src.

<script src="script.js"></script>

تعتبر هذه الطريقة مناسبة للمشروعات الكبيرة، لأنها تساعد على تنظيم الكود وفصل JavaScript عن HTML.

12. JavaScript in the Browser — JavaScript في المتصفح

يمكن تشغيل JavaScript داخل Web Browser — متصفح الويب مثل Chrome وFirefox وEdge.

عندما يقوم المتصفح بتحميل صفحة HTML تحتوي على JavaScript، يقوم بتنفيذ الكود البرمجي وفقًا للتعليمات الموجودة فيه.

13. Console — وحدة التحكم

Console — وحدة التحكم هي جزء موجود داخل أدوات المطور Developer Tools في المتصفح.

تستخدم الـ Console لعرض النتائج والرسائل، كما تساعد المبرمج في اكتشاف الأخطاء أثناء كتابة الكود.

console.log("Hello from JavaScript");

14. JavaScript Example — مثال على JavaScript

في المثال التالي سنستخدم JavaScript لعرض رسالة داخل Console.

<script> console.log("Welcome to HAnova"); </script>

عند تشغيل الصفحة وفتح الـ Console، ستظهر الرسالة الموجودة داخل console.log().

15. JavaScript and User Interaction — JavaScript وتفاعل المستخدم

من أهم مميزات JavaScript قدرتها على الاستجابة لتفاعل المستخدم مع الصفحة.

على سبيل المثال، يمكن تنفيذ كود معين عندما يقوم المستخدم بالضغط على زر باستخدام Click Event — حدث النقر.

<button onclick="alert('Hello!')"> Click Me </button>

في المثال السابق، عند الضغط على الزر تظهر رسالة للمستخدم.

16. JavaScript Features — مميزات JavaScript

  • إضافة التفاعل إلى صفحات الويب.
  • سهلة التعلم بالنسبة للمبتدئين.
  • تعمل مباشرة داخل متصفحات الويب.
  • تتعامل مع عناصر HTML.
  • تتعامل مع بيانات المستخدم.
  • تستخدم لإنشاء صفحات ويب ديناميكية.
  • يمكن استخدامها مع HTML وCSS.

17. Important JavaScript Terms — أهم مصطلحات JavaScript

  • JavaScript — لغة برمجة لإضافة التفاعل إلى صفحات الويب.
  • Programming Language — لغة برمجة.
  • Syntax — صياغة الكود.
  • Statement — تعليمة برمجية.
  • Comment — تعليق.
  • Console — وحدة التحكم.
  • Browser — متصفح الويب.
  • Script — كود برمجي.
  • Interaction — تفاعل.
  • Event — حدث.

18. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة HTML بسيطة، ثم أضف وسم <script> واكتب بداخله أمر console.log() لعرض رسالة من اختيارك داخل Console.

بعد ذلك جرّب إنشاء زر <button> واستخدم JavaScript لجعل الزر يعرض رسالة عند الضغط عليه.

  • HTML تستخدم لبناء هيكل الصفحة.
  • CSS تستخدم لتنسيق وتصميم الصفحة.
  • JavaScript تستخدم لإضافة السلوك والتفاعل.
  • Syntax = صياغة الكود.
  • Statement = تعليمة برمجية.
  • Comment = تعليق لا يتم تنفيذه.
  • Console = وحدة التحكم.
  • يمكن كتابة JavaScript داخل HTML باستخدام <script>.
  • يمكن وضع JavaScript في ملف خارجي بامتداد .js.
  • console.log() تستخدم لعرض الرسائل والقيم في Console.
  • JavaScript يمكنها الاستجابة لتفاعل المستخدم مع الصفحة.

Lesson 3 : Operators and Expressions

1. What is an Operator? — ما هو العامل؟

Operator — العامل هو رمز أو كلمة تستخدم لتنفيذ عملية معينة على قيمة واحدة أو أكثر داخل JavaScript.

تستخدم العوامل في العمليات الحسابية والمقارنات والعمليات المنطقية وإسناد القيم إلى المتغيرات.

let result = 10 + 5;

في المثال السابق تم استخدام العامل + لإجراء عملية الجمع بين الرقمين 10 و5.

2. What is an Expression? — ما هو التعبير؟

Expression — التعبير هو مجموعة من القيم والمتغيرات والعوامل تنتج عنها قيمة معينة.

10 + 5

التعبير السابق ينتج عنه القيمة 15.

ويمكن أن تحتوي الـ Expression على متغيرات أيضًا.

let x = 10; let y = 5; let result = x + y;

3. Arithmetic Operators — العوامل الحسابية

Arithmetic Operators — العوامل الحسابية تستخدم لإجراء العمليات الحسابية على الأرقام.

  • + — Addition — الجمع.
  • - — Subtraction — الطرح.
  • * — Multiplication — الضرب.
  • / — Division — القسمة.
  • % — Modulus — باقي القسمة.
  • ** — Exponentiation — الأس.

4. Addition Operator (+) — عامل الجمع

يستخدم العامل + لإجراء عملية الجمع بين القيم.

let x = 10; let y = 5; let result = x + y; console.log(result);

ستكون النتيجة: 15.

5. Subtraction Operator (-) — عامل الطرح

يستخدم العامل - لإجراء عملية الطرح.

let x = 10; let y = 5; let result = x - y; console.log(result);

ستكون النتيجة: 5.

6. Multiplication Operator (*) — عامل الضرب

يستخدم العامل * لإجراء عملية الضرب.

let x = 10; let y = 5; let result = x * y; console.log(result);

ستكون النتيجة: 50.

7. Division Operator (/) — عامل القسمة

يستخدم العامل / لإجراء عملية القسمة.

let x = 10; let y = 5; let result = x / y; console.log(result);

ستكون النتيجة: 2.

8. Modulus Operator (%) — باقي القسمة

يستخدم العامل % للحصول على باقي عملية القسمة.

let result = 10 % 3; console.log(result);

عند قسمة 10 على 3 يكون باقي القسمة 1.

9. Exponentiation Operator (**) — عامل الأس

يستخدم العامل ** لحساب قوة رقم معين.

let result = 2 ** 3; console.log(result);

في المثال السابق يتم حساب 2 أس 3، ولذلك تكون النتيجة 8.

10. Assignment Operator (=) — عامل الإسناد

Assignment Operator — عامل الإسناد يستخدم لإعطاء قيمة لمتغير.

let age = 20;

في المثال السابق تم إسناد القيمة 20 إلى المتغير age.

11. Compound Assignment Operators — عوامل الإسناد المركبة

يمكن استخدام عوامل مختصرة لتعديل قيمة المتغير وإسناد النتيجة إليه في نفس الوقت.

  • += — الجمع ثم الإسناد.
  • -= — الطرح ثم الإسناد.
  • *= — الضرب ثم الإسناد.
  • /= — القسمة ثم الإسناد.
  • %= — باقي القسمة ثم الإسناد.
let x = 10; x += 5; console.log(x);

أصبحت قيمة x تساوي 15.

12. Increment Operator (++) — عامل الزيادة

يستخدم العامل ++ لزيادة قيمة المتغير بمقدار واحد.

let x = 5; x++; console.log(x);

بعد تنفيذ العملية تصبح قيمة x تساوي 6.

13. Decrement Operator (--) — عامل النقصان

يستخدم العامل -- لتقليل قيمة المتغير بمقدار واحد.

let x = 5; x--; console.log(x);

بعد تنفيذ العملية تصبح قيمة x تساوي 4.

14. Comparison Operators — عوامل المقارنة

Comparison Operators — عوامل المقارنة تستخدم لمقارنة قيمتين، وتكون النتيجة عادةً قيمة منطقية true أو false.

  • == — Equal — يساوي مع مقارنة القيمة.
  • === — Strict Equal — يساوي في القيمة والنوع.
  • != — Not Equal — لا يساوي.
  • !== — Strict Not Equal — لا يساوي في القيمة أو النوع.
  • > — Greater Than — أكبر من.
  • < — Less Than — أصغر من.
  • >= — Greater Than or Equal — أكبر من أو يساوي.
  • <= — Less Than or Equal — أصغر من أو يساوي.

15. Equal Operator (==) — عامل المساواة

يستخدم العامل == لمقارنة قيمتين مع السماح بتحويل النوع عند الحاجة.

console.log(5 == "5");

تكون النتيجة true لأن العامل == يقارن القيمة مع إمكانية تحويل النوع.

16. Strict Equal Operator (===) — المساواة الصارمة

يستخدم العامل === للمقارنة بين القيمة والنوع معًا.

console.log(5 === "5");

تكون النتيجة false لأن الرقم 5 والنص "5" لهما نوعان مختلفان.

17. Greater Than and Less Than — أكبر من وأصغر من

يمكن استخدام > لمعرفة إذا كانت قيمة أكبر من قيمة أخرى، واستخدام < لمعرفة إذا كانت قيمة أصغر من قيمة أخرى.

console.log(10 > 5); console.log(10 < 5);

النتيجة الأولى ستكون true، بينما النتيجة الثانية ستكون false.

18. Logical Operators — العوامل المنطقية

Logical Operators — العوامل المنطقية تستخدم لدمج أو عكس القيم المنطقية true وfalse.

  • && — AND — و.
  • || — OR — أو.
  • ! — NOT — عكس القيمة.

19. AND Operator (&&) — العامل AND

يرجع العامل && قيمة صحيحة عندما تكون الشروط المستخدمة معه صحيحة.

let age = 20; let hasCard = true; console.log(age >= 18 && hasCard);

في المثال السابق الشرطان صحيحان، لذلك تكون النتيجة true.

20. OR Operator (||) — العامل OR

يستخدم العامل || عندما نريد أن يكون أحد الشروط على الأقل صحيحًا.

let isStudent = true; let isTeacher = false; console.log(isStudent || isTeacher);

تكون النتيجة true لأن الشرط الأول صحيح.

21. NOT Operator (!) — العامل NOT

يستخدم العامل ! لعكس القيمة المنطقية.

let isOnline = true; console.log(!isOnline);

ستكون النتيجة false لأن العامل ! عكس القيمة من true إلى false.

22. Operator Precedence — أولوية العمليات

عند وجود أكثر من عملية في تعبير واحد، تقوم JavaScript بتنفيذ العمليات وفق ترتيب معين يسمى Operator Precedence — أولوية العمليات.

let result = 10 + 5 * 2; console.log(result);

يتم تنفيذ الضرب أولًا، لذلك تكون النتيجة 20 وليس 30.

ويمكن استخدام الأقواس ( ) لتحديد العملية التي نريد تنفيذها أولًا.

let result = (10 + 5) * 2; console.log(result);

في هذه الحالة يتم تنفيذ الجمع أولًا، ولذلك تكون النتيجة 30.

23. Combining Operators — دمج العوامل

يمكن استخدام أكثر من نوع من العوامل داخل نفس البرنامج للوصول إلى النتيجة المطلوبة.

let age = 20; let result = age + 5; console.log(result > 20);

في المثال السابق تم استخدام عامل حسابي ثم عامل مقارنة للحصول على نتيجة منطقية.

24. Try It Yourself — جرب بنفسك

قم بإنشاء متغيرين يحتويان على رقمين، ثم استخدم العوامل الحسابية لتنفيذ عمليات الجمع والطرح والضرب والقسمة وباقي القسمة.

بعد ذلك جرب استخدام عوامل المقارنة والعوامل المنطقية، ولاحظ النتائج التي تظهر في الـ Console.

  • % = باقي القسمة.
  • ** = الأس.
  • = = الإسناد.
  • ++ = زيادة القيمة بمقدار واحد.
  • -- = تقليل القيمة بمقدار واحد.

  • === = مقارنة القيمة والنوع.
  • > و < = أكبر من وأصغر من.
  • && = AND.
  • || = OR.
  • ! = NOT.
  • Operator Precedence = أولوية العمليات.

Lesson 10 : JavaScript Events

1. What are Events? — ما هي الأحداث؟

Event — الحدث هو شيء يحدث داخل صفحة الويب نتيجة تفاعل المستخدم مع الصفحة أو نتيجة حدوث شيء معين في المتصفح.

من أمثلة الأحداث:

  • الضغط على زر.
  • تحريك مؤشر الماوس.
  • الكتابة داخل مربع نص.
  • إرسال نموذج.
  • تحميل الصفحة.
  • الضغط على لوحة المفاتيح.

2. Why Do We Use Events? — لماذا نستخدم Events؟

نستخدم الأحداث لجعل صفحات الويب Interactive — تفاعلية.

فعلى سبيل المثال يمكننا جعل زر يقوم بتغيير النص عند الضغط عليه، أو تغيير لون عنصر عندما يمر فوقه المستخدم بالماوس.

3. Event Handler — معالج الحدث

Event Handler — معالج الحدث هو الكود الذي يتم تنفيذه عندما يحدث Event معين.

button.onclick = function() { alert("Hello!"); };

في المثال السابق يتم تنفيذ الكود الموجود داخل الدالة عندما يتم الضغط على الزر.

4. onclick — حدث الضغط

onclick يحدث عندما يقوم المستخدم بالضغط على عنصر.

<button id="btn">Click Me</button> <script> let button = document.getElementById("btn"); button.onclick = function() { alert("Button Clicked"); }; </script>

عند الضغط على الزر ستظهر رسالة.

5. addEventListener() — إضافة مستمع للحدث

من أفضل الطرق للتعامل مع الأحداث استخدام addEventListener().

تسمح هذه الطريقة بتحديد الحدث والدالة التي سيتم تنفيذها عند حدوثه.

button.addEventListener("click", function() { alert("Button Clicked"); });

6. click Event — حدث النقر

يستخدم click عندما نريد تنفيذ كود عند الضغط على عنصر.

let button = document.getElementById("btn"); button.addEventListener("click", function() { console.log("Clicked"); });

7. mouseover Event — مرور الماوس

يحدث mouseover عندما يمر مؤشر الماوس فوق عنصر.

let box = document.getElementById("box"); box.addEventListener("mouseover", function() { box.style.backgroundColor = "purple"; });

8. mouseout Event — خروج الماوس

يحدث mouseout عندما يخرج مؤشر الماوس من فوق العنصر.

box.addEventListener("mouseout", function() { box.style.backgroundColor = "white"; });

9. mousemove Event — تحريك الماوس

يحدث mousemove عند تحريك مؤشر الماوس داخل العنصر.

box.addEventListener("mousemove", function() { console.log("Mouse is moving"); });

10. mousedown Event — الضغط على زر الماوس

يحدث mousedown عندما يبدأ المستخدم بالضغط على أحد أزرار الماوس.

button.addEventListener("mousedown", function() { console.log("Mouse Down"); });

11. mouseup Event — رفع زر الماوس

يحدث mouseup عندما يرفع المستخدم إصبعه بعد الضغط على زر الماوس.

button.addEventListener("mouseup", function() { console.log("Mouse Up"); });

12. mouseenter Event — دخول الماوس

يحدث mouseenter عندما يدخل مؤشر الماوس إلى منطقة العنصر.

box.addEventListener("mouseenter", function() { console.log("Mouse Entered"); });

13. mouseleave Event — مغادرة العنصر

يحدث mouseleave عندما يغادر مؤشر الماوس منطقة العنصر.

box.addEventListener("mouseleave", function() { console.log("Mouse Left"); });

14. keydown Event — الضغط على لوحة المفاتيح

يحدث keydown عندما يضغط المستخدم على أحد مفاتيح لوحة المفاتيح.

document.addEventListener("keydown", function() { console.log("Key Pressed"); });

15. keyup Event — رفع المفتاح

يحدث keyup عندما يرفع المستخدم إصبعه عن المفتاح.

document.addEventListener("keyup", function() { console.log("Key Released"); });

16. input Event — الكتابة داخل Input

يحدث input عندما تتغير قيمة عنصر الإدخال أثناء الكتابة.

let input = document.getElementById("name"); input.addEventListener("input", function() { console.log(input.value); });

في المثال السابق يتم الحصول على القيمة الجديدة كلما قام المستخدم بالكتابة داخل مربع الإدخال.

17. change Event — تغيير القيمة

يحدث change عندما تتغير قيمة عنصر معين ويتم تأكيد التغيير.

let input = document.getElementById("name"); input.addEventListener("change", function() { console.log(input.value); });

18. focus Event — التركيز على العنصر

يحدث focus عندما يصبح عنصر الإدخال في حالة تركيز، مثل الضغط داخل مربع النص.

input.addEventListener("focus", function() { input.style.backgroundColor = "lightblue"; });

19. blur Event — فقدان التركيز

يحدث blur عندما يفقد عنصر الإدخال التركيز.

input.addEventListener("blur", function() { input.style.backgroundColor = "white"; });

20. submit Event — إرسال Form

يحدث submit عندما يقوم المستخدم بإرسال نموذج Form.

let form = document.getElementById("form"); form.addEventListener("submit", function(event) { console.log("Form Submitted"); });

21. preventDefault() — منع السلوك الافتراضي

بعض الأحداث لها سلوك افتراضي في المتصفح. يمكن استخدام preventDefault() لمنع هذا السلوك.

form.addEventListener("submit", function(event) { event.preventDefault(); console.log("Form submission stopped"); });

في المثال السابق تم منع النموذج من تنفيذ السلوك الافتراضي للإرسال.

22. The Event Object — كائن الحدث

عند حدوث Event يمكن لـ JavaScript الحصول على معلومات عن هذا الحدث من خلال Event Object — كائن الحدث.

button.addEventListener("click", function(event) { console.log(event); });

23. event.target — العنصر الذي حدث عليه Event

تستخدم event.target لمعرفة العنصر الذي حدث عليه الحدث.

button.addEventListener("click", function(event) { console.log(event.target); });

24. Event Listener with Function — Event مع Function

يمكن كتابة الدالة بشكل منفصل ثم تمرير اسمها إلى addEventListener().

function showMessage() { alert("Hello HAnova"); } button.addEventListener("click", showMessage);

عند الضغط على الزر سيتم استدعاء الدالة showMessage.

25. Multiple Events — أكثر من Event

يمكن إضافة أكثر من Event إلى نفس العنصر.

button.addEventListener("click", function() { console.log("Clicked"); }); button.addEventListener("mouseover", function() { console.log("Mouse Over"); });

26. Events and DOM — العلاقة بين Events و DOM

عند الجمع بين DOM و Events يمكن إنشاء صفحات تفاعلية بشكل كبير.

let button = document.getElementById("btn"); let title = document.getElementById("title"); button.addEventListener("click", function() { title.textContent = "Welcome to JavaScript"; title.style.color = "purple"; });

عند الضغط على الزر سيتم تغيير نص العنوان ولونه.

  • click — الضغط على العنصر.
  • dblclick — الضغط مرتين.
  • mouseover — مرور الماوس فوق العنصر.
  • mouseout — خروج الماوس من العنصر.
  • mousemove — تحريك الماوس.
  • mousedown — الضغط على زر الماوس.
  • mouseup — رفع زر الماوس.
  • keydown — الضغط على مفتاح.
  • keyup — رفع المفتاح.
  • input — تغيير قيمة Input أثناء الكتابة.
  • change — تغيير قيمة العنصر.
  • focus — الحصول على التركيز.
  • blur — فقدان التركيز.
  • submit — إرسال Form.

28. Try It Yourself — جرب بنفسك

قم بإنشاء صفحة HTML تحتوي على عنوان وزر ومربع إدخال.

استخدم click لتغيير نص العنوان عند الضغط على الزر.

ثم استخدم mouseover لتغيير لون العنوان عندما يمر الماوس فوقه.

وأخيرًا استخدم input لعرض النص الذي يكتبه المستخدم داخل مربع الإدخال.

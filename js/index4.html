Lesson 2 : Variables and Data Types

1. What is a Variable? — ما هو المتغير؟

Variable — المتغير هو مكان في الذاكرة يستخدم لتخزين البيانات التي يمكن للبرنامج استخدامها أثناء تنفيذ الكود.

يمكن أن يحتوي المتغير على أنواع مختلفة من البيانات، مثل النصوص والأرقام والقيم المنطقية، ويمكن استخدام قيمة المتغير في العمليات المختلفة داخل البرنامج.

let name = "Hager";

في المثال السابق تم إنشاء متغير باسم name وتخزين القيمة "Hager" بداخله.

2. Why Do We Use Variables? — لماذا نستخدم المتغيرات؟

نستخدم المتغيرات لتخزين البيانات وإعادة استخدامها داخل البرنامج بدلًا من كتابة نفس البيانات أكثر من مرة.

  • تخزين أسماء المستخدمين.
  • تخزين الأرقام والقيم الحسابية.
  • تخزين البيانات التي يدخلها المستخدم.
  • تخزين النتائج أثناء تنفيذ البرنامج.
  • تسهيل التعامل مع البيانات وتغييرها.

3. Declaring a Variable — تعريف المتغير

Declaring a Variable — تعريف المتغير يعني إنشاء متغير جديد في JavaScript.

يمكن تعريف المتغيرات باستخدام الكلمات المفتاحية: let، const، وvar.

4. let — تعريف متغير قابل للتغيير

تستخدم كلمة let لإنشاء متغير يمكن تغيير قيمته بعد تعريفه.

let age = 20; age = 21;

في المثال السابق تم إنشاء المتغير age بقيمة 20، ثم تم تغيير قيمته إلى 21.

5. const — تعريف ثابت

تستخدم كلمة const لإنشاء متغير لا يمكن إعادة إسناد قيمة جديدة له بعد تعريفه.

const country = "Egypt";

في المثال السابق تم إنشاء متغير ثابت باسم country. لا يمكن بعد ذلك إعطاؤه قيمة جديدة باستخدام إعادة الإسناد.

const country = "Egypt"; country = "USA";

الكود السابق يؤدي إلى حدوث خطأ لأن المتغير الذي تم تعريفه باستخدام const لا يمكن إعادة إسناد قيمة جديدة له.

6. var — الطريقة القديمة لتعريف المتغيرات

var هي طريقة قديمة لإنشاء المتغيرات في JavaScript. وكانت تستخدم بشكل كبير في الإصدارات القديمة من JavaScript.

var name = "Hager";

في JavaScript الحديثة يفضل استخدام let وconst بدلًا من var في معظم الحالات بسبب طريقة تعاملها المختلفة مع نطاق المتغيرات.

7. let vs const vs var — الفرق بين طرق تعريف المتغير

let age = 20; const name = "Hager"; var city = "Banha";
  • let — يمكن تغيير قيمة المتغير.
  • const — لا يمكن إعادة إسناد قيمة جديدة للمتغير.
  • var — طريقة قديمة لتعريف المتغيرات.

8. Variable Naming Rules — قواعد تسمية المتغيرات

عند إنشاء متغير في JavaScript يجب اتباع بعض القواعد الخاصة بتسمية المتغير.

  • يمكن أن يحتوي الاسم على حروف وأرقام و_ و$.
  • لا يمكن أن يبدأ اسم المتغير برقم.
  • لا يمكن استخدام الكلمات المحجوزة كأسماء للمتغيرات.
  • JavaScript تفرق بين الحروف الكبيرة والصغيرة.
  • يفضل استخدام أسماء واضحة تصف البيانات التي يخزنها المتغير.
let userName = "Hager"; let age2 = 20; let user_city = "Banha";

9. Case Sensitivity — حساسية حالة الأحرف

JavaScript هي لغة Case Sensitive — حساسة لحالة الأحرف. وهذا يعني أن الحروف الكبيرة والصغيرة تعتبر مختلفة.

let name = "Hager"; let Name = "Sara";

في المثال السابق يعتبر name وName متغيرين مختلفين لأن حرف n مكتوب بحالة مختلفة.

10. Data Types — أنواع البيانات

Data Types — أنواع البيانات تحدد نوع القيمة التي يتم تخزينها داخل المتغير.

توفر JavaScript عدة أنواع من البيانات، ومن أهمها: String، Number، Boolean، Undefined، Null، بالإضافة إلى أنواع أخرى مثل Object وArray.

11. String — النص

String — النص يستخدم لتخزين مجموعة من الأحرف والكلمات.

يتم كتابة النصوص بين علامات اقتباس مثل " " أو ' '.

let name = "Hager"; let message = "Welcome to JavaScript";

12. Number — الرقم

Number — الرقم يستخدم لتخزين القيم الرقمية، سواء كانت أعدادًا صحيحة أو أعدادًا عشرية.

let age = 20; let price = 99.5;

في المثال السابق: 20 عدد صحيح، بينما 99.5 عدد عشري.

13. Boolean — القيمة المنطقية

Boolean — القيمة المنطقية تستخدم لتخزين إحدى قيمتين فقط: true أو false.

let isStudent = true; let isAdmin = false;

تستخدم القيم المنطقية بشكل كبير في الشروط واتخاذ القرارات داخل البرامج.

14. Undefined — قيمة غير محددة

Undefined تعني أن المتغير تم تعريفه ولكن لم يتم إعطاؤه قيمة بعد.

let result; console.log(result);

في المثال السابق تم إنشاء المتغير result بدون إعطائه قيمة، لذلك تكون قيمته undefined.

15. Null — قيمة فارغة

Null تستخدم للتعبير عن عدم وجود قيمة بشكل مقصود.

let user = null;

في المثال السابق تم إعطاء المتغير قيمة null بشكل صريح للدلالة على عدم وجود قيمة حاليًا.

16. Object — الكائن

Object — الكائن يستخدم لتجميع مجموعة من البيانات المرتبطة ببعضها في مكان واحد.

let student = { name: "Hager", age: 20 };

في المثال السابق يحتوي الكائن student على بيانات مختلفة مثل الاسم والعمر.

17. Array — المصفوفة

Array — المصفوفة تستخدم لتخزين مجموعة من القيم داخل متغير واحد.

let colors = ["red", "blue", "green"];

في المثال السابق يحتوي المتغير colors على مجموعة من الألوان.

18. typeof Operator — معرفة نوع البيانات

يمكن استخدام typeof لمعرفة نوع البيانات المخزنة داخل متغير.

let name = "Hager"; console.log(typeof name);

سيقوم الكود السابق بإظهار string في الـ Console لأن القيمة المخزنة داخل المتغير عبارة عن نص.

19. Multiple Variables — إنشاء أكثر من متغير

يمكننا إنشاء أكثر من متغير لتخزين بيانات مختلفة داخل البرنامج.

let name = "Hager"; let age = 20; let city = "Banha"; let isStudent = true;

في المثال السابق تم إنشاء أربعة متغيرات، وكل متغير يحتوي على نوع مختلف من البيانات.

20. Try It Yourself — جرب بنفسك

قم بإنشاء أربعة متغيرات باستخدام let وconst لتخزين اسم، وعمر، ومدينة، وقيمة منطقية.

بعد ذلك استخدم console.log() لعرض القيم داخل الـ Console، وجرب استخدام typeof لمعرفة نوع كل قيمة.
